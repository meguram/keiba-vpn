§1+補正 — 斤量補正タイム (adjusted_time_sec) 算出NB-01
騎手の斤量差が走破タイムに与える影響を OLS（レース内偏差）で推定し、全馬のタイムを固定基準斤量に換算する。
基準斤量: 牡・セン 55 kg / 牝 53 kg（年齢・月によらず固定）。 この固定基準により、すべての馬のタイムが「55/53 kg で走った場合の能力」として統一され、年齢・クラスを跨いだ公平な比較が可能になる。
5着以内のデータで surface × distance × sex_group ごとに weight_sec_per_kg（sec/kg）を OLS 推定。
adjusted_time_sec = time_sec − weight_dev_kg × weight_sec_per_kg
weight_dev_kg = jockey_weight − base_weight　（牡・セン 55 kg / 牝 53 kg）
weight_sec_per_kg ≈ 0.18 sec/kg（芝1800m 牡） ← OLS 推定
フォールバック: セルサンプル不足時 → 理論値 0.2 sec/kg × (distance / 2000)
最終利用フロー: この adjusted_time_sec の過去履歴から「55/53 kg 基準での想定パフォーマンス」を推定し、 当日の実斤量との差分 (actual_weight − 55 or 53) × weight_sec_per_kg だけ補正して最終予測値とする。
斤量補正の例（芝1800m 牡2歳・実斤量54kg → 基準55kgへ換算）

§3 — 馬場速度指数 (tsi_raw) 算出NB-01
学習期（2020〜2024）の 2着馬 adjusted_time_sec の平均を「基準2着タイム（par_2nd_adj_sec）」として、 当日・競馬場・馬場種別のタイム乖離を推定する。 1日あたりのレース数が少ない条件では外れ値・小サンプルの両方に対処するため、 3層設計（ペースフィルタ → 中央値 → 収縮推定）で tsi_raw を算出する。
Layer 1
ペース異常レースの除外
▸ ハイペース／スローペース展開による最終タイムの歪みは馬場情報ではなく展開ノイズ
front_split_dev = front_split_sec − front_split_median[distance, surface]
除外条件 : |front_split_dev| > 2 × front_split_sigma[distance, surface]
front_split_median・front_split_sigma は学習期（2020–2024）の distance × surface 別に事前計算（§3 冒頭）。
§2 で算出済みの front_split_sec をそのまま参照するため、処理の重複なし。
除外後の有効レース数を n_valid_races として記録する。
n_valid_races 件が通過 → race_track_dev_sec の集計へ
Layer 2
ロバスト集計（中央値）
▸ 平均では残った1件の外れ値にも引っ張られるため、中央値を使う
race_track_dev_observed = median(race_track_dev_sec)　— 有効レース n_valid_races 件の中央値
※ n_valid_races = 0 の場合は Layer 3 の tsi_prior をそのまま使用
観測値確定 → 小サンプル安定化へ
Layer 3
収縮推定（小サンプル安定化）
▸ n_valid_races が 3〜5 件では中央値も統計的に不安定。過去の実績値に寄せて安定させる
w = n_valid_races ÷ (n_valid_races + k)
track_dev_sec = w × race_track_dev_observed + (1−w) × tsi_prior
tsi_raw = −track_dev_sec　（正 = 速い馬場）
k（収縮強度）= σ²_within ÷ σ²_between（学習期の日内・日間ばらつき比から推定、目安 4〜6）
tsi_prior = 学習期における同 venue × surface の平均 track_dev_sec（未設定時は 0）
k・tsi_prior はいずれも学習期データから自動推定。手動チューニング不要。
収縮重み w の参考値（k=5 の場合）
n_valid_races（有効レース数） w（当日への重み） 振る舞い
0（全レース除外）0.00tsi_prior のみ使用
20.29prior 寄り（データ不足）
40.44prior・当日ほぼ半々
60.55当日データがやや優勢
100.67当日主体
変数定義
変数名意味・定義
class_group レースのクラスグループ（6区分）：G1orG2（G1・G2）/ G3orOP（G3・L・OP）/ 3勝 / 2勝 / 1勝 / 未勝利。
par_2nd_adj_sec を算出する際のグルーピング単位。
新馬 および 2歳・3歳世代限定戦 は除外（class_group = NaN）。 これらは絶対タイムが古馬混合戦と比較できないため、基準タイムの計算プールから外す。
par_2nd_adj_sec 「基準2着タイム」。学習期（2020〜2024）の2着馬 adjusted_time_sec を
class_group × 距離 × 競馬場 × 馬場種別（芝/ダート） 別に集計した平均タイム。
馬場の速さを比較するときの「ものさし」となる基準値。
※ 馬場状態（良/稍重/重/不良）は含まない。良→稍重でタイムが改善するケースもあり、 良馬場が必ずしも速いとは限らないため。
race_t2nd_sec 当レースの2着馬 adjusted_time_sec（斤量補正済みタイム）の実測値。
1着ではなく2着を使うのは、1着はペース戦術・展開の影響を受けやすく外れ値になりやすいため。
race_track_dev_sec 当レースの2着タイムと基準の差（= race_t2nd_sec − par_2nd_adj_sec）。
正 = 基準より遅い（馬場が重い・渋い）、負 = 基準より速い（馬場が軽い・良い）。
Layer 1 フィルタ通過後の値のみ Layer 2・3 の集計に使用される。
front_split_dev 当レースのペース偏差（= front_split_sec − front_split_median[distance, surface]）。
正 = 前半が遅かった（スロー）、負 = 前半が速かった（ハイ）。
Layer 1 の除外判定に使用。|front_split_dev| > 2σ のレースは集計から除外する。
n_valid_races Layer 1 のペースフィルタ通過後の有効レース数。
収縮重み w = n_valid_races ÷ (n_valid_races + k) の分子になる。
小さいほど tsi_prior への収縮が強くなり、推定が保守的になる。
track_dev_sec 日×競馬場×馬場種別の馬場乖離（収縮推定後の最終値）。
Layer 2 の中央値（race_track_dev_observed）を Layer 3 で tsi_prior へ収縮させた値。
正 = 全体的に遅い馬場、負 = 速い馬場。
tsi_raw 馬場速度指数の生値（= − track_dev_sec）。track_dev_sec の符号を反転させることで
「正 = 時計が出やすい（速い）馬場、負 = 時計が出にくい（遅い）馬場」と直感的な向きに変換する。
下流でクリッピング・正規化して最終的な馬場指数に加工される。

§5 — front_split_dev 算出（ペース偏差）NB-03

NB-01 §6 で保存済みの par_front_split_sec（OLS 連続モデルによる基準前半スプリット）と、 実測値 front_split_sec の差を計算する。

front_split_dev = front_split_sec − par_front_split_sec
正 = 基準より遅いペース（後半型）／ 負 = 基準より速いペース（前傾型）
欠損（front_split_sec 未取得レース）→ 0.0 補完（ペース補正なし扱い）
⚠️ NB-01 §3 の front_split_dev（ペースフィルタ用の生偏差）とは別物。 こちらは OLS モデルによる基準値との偏差（ペース補正に使用）。

§6 — Δpace 適用 → time_after_paceNB-03

ペース偏差 front_split_dev を係数 coeff_pace でタイム換算し、 斤量補正後タイムから差し引いてペース補正後タイムを得る。

Δpace_sec = coeff_pace × front_split_dev
time_after_pace = adjusted_time_sec − Δpace_sec
ハイペース（front_split_dev < 0）→ Δpace_sec < 0 → time_after_pace が増加（遅く補正）
スローペース（front_split_dev > 0）→ Δpace_sec > 0 → time_after_pace が減少（速く補正）
  • coeff_pace 欠損時は 0.0 補完 → ペース補正なし
  • coeff_pace ∈ [0.3, 1.5] にクリップ済み（NB-02 §3）

§7 — Δtrack 算出（日 × 会場 × 馬場種別）NB-03
7-1 対象レースフィルタ（G1 除外）

G1 レースは特殊な馬場整備・出走馬層のため馬場差推定対象から除外する。 class_rank ≤ 7（未勝利〜G2）を track_target として使用。

track_target = df_valid[ class_rank ≤ 7 ]
NB-01 定義: G3=6, G2=7, G1=8 → <=7 で G1 のみ除外
7-2 日 × 会場 × 馬場種別で集計

date × venue × surface グループ内で全出走馬の time_after_pace と par_time_sec の平均をそれぞれ計算し、差を馬場差とする。

Δtrack_sec = mean(time_after_pace) − mean(par_time_sec)
正 = 遅い馬場 / 負 = 速い馬場
全出走馬（着順不問）を使用 ← tsi_raw（NB-01）の 2着馬基準と異なる点
7-3 Sparse 対策

当日のレース数が少ない場合（例: 開催場が1〜2レースのみ）は推定が不安定になる。

n_races < 3 → Δtrack_sec = 0, is_fallback = True
0 = 「馬場差なし（標準）」とみなす簡素化。tsi_raw の収縮推定（Layer 3）とは非対称だが意図的な簡素化。
is_fallback フラグを後段で参照して扱いを変えることが可能。

§4 — 実測めぐ指数 (megu_index) 算出NB-04
クラス基準タイムとの差を指数化。1勝クラスの2着馬相当で 50。0.1秒速い = +1点のスケール。
megu_index = 50.0 + ( par_time_class_sec − corrected_time ) × 10.0
基準: 1勝クラス 2着馬が par_time_class_sec と同タイムで走った場合 → corrected_time ≈ par_time_class_sec → megu_index ≈ 50
解釈： megu_index > 50 → クラス基準より速い（上位クラス相当）。 megu_index < 50 → クラス基準より遅い。 0.5秒の差 = 5ポイント差。
