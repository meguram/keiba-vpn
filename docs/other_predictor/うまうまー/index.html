1対象と前提

note.com のプロフィール https://note.com/yupo1004（表示名「うまうまー」）は、2019年から競馬の重賞予想note（主に「穴馬」＝人気薄で好走する馬の発掘）を投稿している。全投稿69件のうち2025年1月以降の投稿は27件しかなく、2023年1月〜2025年1月には約2年間の投稿空白期間がある。

ユーザーの指示により、「2025年以降の記事」27件に加えて、2023年以前の直近23件を遡って合計50件を分析対象とした（2021-09-09〜2023-01-12の23件 ＋ 2025-01-10〜2026-09-25の27件）。

本文取得は note.com の公開APIを利用し、HTMLタグを除去したテキストとして50記事すべてを取得した。うち7記事は有料note（¥100〜250）のため、課金の壁より先の本文は取得できず、無料プレビュー部分のみを分析対象とした。

2予想手法の全体像

基本フレームワーク：「穴馬共通点」分析

特に2025年以降の記事で完全に定型化されている中核ロジックは以下の通り。

  1. 対象レースの過去10〜15年分を遡り、「6番人気以下（レースにより4〜5番人気以下）から3着以内に好走した馬」を全頭リストアップする（穴馬プール、多くは9〜24頭程度）。
  2. それら穴馬に共通する特徴を4〜8項目抽出する。項目は主に：前走の4角（コーナー）通過順位、前走の上がり3F順位・秒数、対象コース／類似コースでの実績、距離実績、年齢、斤量比、鞍上（乗り替わりか継続騎乗か）、馬体重（増減・馬格）、生産牧場（ノーザンファーム／社台系か否か）など。
  3. 各項目に⭕️（合格）／🔺（一部合格）／❌（不合格）を割り当て、全項目クリア（オールクリア）の馬を「今年の推奨穴馬・本命」として選出する。
  4. 各項目の設定根拠は必ず「コース形状（坂の位置・数、コーナー角度、直線の長さ）から逆算したラップの前傾／後傾傾向」に紐づけて説明される（後述③）。
時代による違い： 2021〜2023年の記事では、上記の定量的「共通点」分析と、個々の馬のレース映像を見て「不利を受けた／能力を出し切れていない」ことを評価する定性的な「推し馬・小言」分析（前走を度外視する手法）が混在していた。特に3歳限定戦・トライアル競走（クイーンC、共同通信杯、チューリップ賞、皐月賞、秋華賞、オークスなど）では、サンプル数が少ないため定量分析が使えず、映像ベースの個別評価が中心になる傾向がある。2025年以降はほぼ全レースで定量「共通点」方式に統一されている。

3舞台別の予想手法

「舞台」（芝／ダート・距離帯・コースの坂やコーナー構造）によって、著者がどのような着眼点を設定しているかを整理した。共通するのは、必ず「コースのラップ特性（前半が速いか、中盤が緩むか、直線に坂があるか）」から逆算して「前走のどんな内容の馬が向くか」を導く、という論理展開である。

芝・短距離（〜1400m前後）

代表例： スプリンターズS（中山1200）、阪急杯（阪神1200）、オーシャンS（中山1200）、アイビスサマーダッシュ（新潟1000直線）

  • 共通して「スタート直後が下り坂で前半が速い（前傾ラップ）→中盤も減速しない→直線の急坂で上がりがかかる」という3段構成でレースを分解し、スピードだけでなく持続力・スタミナが必要な「タフな短距離戦」という結論を導くパターンが多い（スプリンターズS、阪急杯）。
  • 短距離は決着パターンが「前有利（4角1〜5番手）」か「大外一気の後方一気（11番手以下）」の二極化しやすいと分析（阪急杯）。
  • アイビスSD（新潟1000m直線）は特殊コースとして別枠扱い：枠順（外枠が複勝率3〜4倍高い）と前走千直実績の秒差を最重視し、枠確定後に追記する2段階公開構成をとる。「前走ダート使用馬は全滅」という珍しいネガティブ条件も特徴的。

芝・マイル（1500〜1700m）

代表例： 京成杯AH、東京新聞杯、チューリップ賞、クイーンC、シンザン記念、フェアリーS、ダービー卿CT、中京記念、ヴィクトリアマイル

  • 同じ「1600m」でも競馬場ごとにロジックが大きく異なる点を強調するのが特徴。例：中山1600m（ダービー卿CT）は「下り坂スタート＋外回り」で中山1800/2000m（上り坂スタート＋内回り）とは別物、東京ダート1400mは「砂スタート＋前後半とも脚を使う国内最長級の直線」など、同一競馬場・同一距離帯でも大きく区別する。
  • 中京記念は「通常の中京マイルは前半ゆったり」なのに「中京記念だけは前傾ラップになる罠」があると指摘し、短距離実績よりも阪神外回り実績を代替指標として使うなど、コース類似性による転用ロジックが目立つ。
  • 血統（ディープインパクト産駒の東京新聞杯における人気薄での複勝率0%等）に言及する例もある。

芝・中距離（1800〜2200m）

代表例： ローズS、紫苑S、中山記念、弥生賞、新潟大賞典、中山牝馬S、福島牝馬S、宝塚記念、小倉記念、新潟記念、クイーンS

  • 「非根幹距離（1800m・2200m等）」という概念を重視し、日本のG1でも非根幹距離（宝塚記念・エリザベス女王杯・有馬記念・菊花賞・チャンピオンズC）は総じて「荒れる・タフ・持続力型」という共通仮説を持つ。
  • 直線が長い競馬場（新潟外回り・東京・京都外）では「瞬発力ではなく直線後半の失速をどこまで防げるかという“スピードの持続力”」を求め、逆に小回りローカル（札幌・函館・福島・小倉）実績も同じ持続力の裏付けとして両方を評価軸に採用するのが新潟大賞典型のロジック。
  • 新潟記念・新潟大賞典では「前走馬体重470kg以上」という馬格基準を、開催後半で荒れた馬場に対応するパワー要件として導入している点が特徴的。

芝・長距離（2400m以上）

代表例： 天皇賞・春（阪神3200／京都3200）、有馬記念（2500）、オークス（2400）、阪神大賞典（3000）

  • 「3角からの下り坂を起点に4F以上のロングスパート合戦が始まる」ため、前半から異常にペースが速くなるのが長距離戦の共通認識（天皇賞・春の平均1000m通過が同条件の他レースより明確に速いことをデータで示す）。
  • そのため「瞬発力の速さ」ではなく「前半から脚を使わされても最後まで踏ん張れる持続力」を求め、4角での位置取り（前優勢）が短距離以上に重要という結論になりやすい。
  • 阪神大賞典（3000m）では内枠絶対有利（過去10年の③着馬の馬番が①〜⑥に集中）という物理的なコース形状論も加わる。
  • 同じ「阪神3200m」でも開催が変則（京都改修時のみ阪神施行）だと過去データが使えないため、類似コース（阪神大賞典・松籟S）からゼロベースで基準を再構築する、という応用力も見られる。

ダート全般

代表例： 根岸S（東京1400）、川崎記念／エンプレス杯（川崎2100）、アンタレスS（阪神1800）、チャンピオンズC（中京1800）、フェブラリーS（東京1600）、レパードS（新潟1800）、プロキオンS（京都1800）

  • ダートは芝以上にコーナー角度と内外枠の有利不利への言及が具体的（川崎2100mは「コーナー角が日本一急」で内枠絶対有利、複勝率データまで提示）。
  • 東京ダート（1400m・1600m）は「芝スタート＋下り坂」で前傾ラップになりやすいうえ、直線が501m（国内ダート最長）で上り坂発端という「前後半とも脚を使わされるタフな設計」という説明が繰り返される。
  • 阪神ダート1800m（アンタレスS）は「坂を2回登る」難コースで、レースによって平均的な阪神ダート戦より明確に速い前傾ラップになるといった、レース固有の“罠”を毎回検証する姿勢が特徴。
  • ダートは芝に比べて所属（関東馬／関西馬）や生産牧場の相性差への言及が多い（東西の輸送・馬場適性の違いが大きいという前提）。

3歳限定・トライアル戦（芝マイル〜中距離）

代表例： クイーンC、共同通信杯、チューリップ賞、皐月賞、秋華賞、オークス

  • 過去の対戦成績が少ないため定量「共通点」分析が使えず、前走のレース映像を逐次読み解く個別評価（不利・進路・展開を能力とは別に評価する「度外視法」）が中心になる。
  • 「前走で不利を受けたが着順以上に強かった」「4角で壁になって進路がなかった」といった展開・トラックバイアスの再評価を多用し、桜花賞・オークスの間では「桜花賞で外を回して詰めた馬はオークスで上方修正すべき」といった路線間のバイアス連鎖分析も行う。
  • 関西馬と関東馬の成績差（秋華賞で過去10年 関西9-7-9-81 vs 関東1-3-1-66等）のような、所属厩舎・地域差への言及もこの路線で目立つ。

4的中レベル（9段階）の傾向分析

データ取得方針の変更： note本文の自己申告（結果報告の追記文）は着順が曖昧・省略されているケースが多く、また「前号や別レースの振り返りとの混同」も複数見つかった。そのため、各記事の予想印（◉○▲△等）に対応する馬名を、実際にnetkeiba.comのレース結果ページで検索・照合し、確認済みの着順・単勝人気を正解データの根拠として採用する方式に切り替えた。note本文は「どの馬に印を付けたか」の同定にのみ使用し、着順の根拠にはしていない。

あわせて的中レベルの定義を、本命（◉相当）の着順を軸に、他の印馬が何頭絡んだかで細分化した9段階（Lv.0〜Lv.8）に再設計した。データは data/research/other_predictor_umauma/predictions_ground_truth.json（marks_verified にnetkeiba確認済みの着順・人気、hit_level に9段階評価を格納）に永続化している。

本命（honmei）の同定ルール: ①◉/◎の記号がある馬 → ②「本命」「本命格」と明示された馬 → ③「イチ推し」「推し馬」等で単独名指しされた馬 → ④本文で最初に言及される印馬、の優先順位で判定（詳細は _meta.json の honmei_identification_rule）。この切り替えにより、旧版で「判定不能」としていた9件のうち8件（阪神ジュベナイルフィリーズ・愛知杯・共同通信杯2022・クイーンカップ2022・京都記念2022・マイルCS・七夕賞・ホープフルS等）で実際の的中レベルを確定できた。

5信頼度スコア化への示唆

「予測結果に対する信頼度を統計的に計算する」という今後の方針に向けて、今回のデータから読み取れる材料を整理する。

① 最も強い予測因子：レースグレード

  • G1（Lv.3以上41%）とG2/G3（68〜71%）の差は、今回の全指標の中で最も大きい。信頼度スコアの最重要変数として「グレード」を採用すべき。特に「G1では推奨馬の信頼度を大きく割り引く」というルールは、サンプルが少ない現状でも導入する価値がある。

② 芝／ダートは「中程度」の補助因子、距離帯はグレードと交絡

  • 芝（67%）＞ダート（30%）の差はnetkeiba実データ検証後に拡大しており、グレード以外では最も明確な差。距離帯（短距離・マイル＞中距離・長距離）はグレードとの交絡（長距離＝G1が多い等）が疑われるため、グレードで調整した後の残差としてどれだけ効くかを今後さらにデータを積んでから判断すべき。

③ 有料／無料や手法の定型化は、今のところ的中率に大差なし

  • 有料記事（本命度が高いはずのプレミアム予想）と無料記事の的中率に明確な差は見られなかった。「課金＝信頼度が高い」という前提は、現時点のデータでは支持されない。
  • 2025年以降の定型化された「⭕️🔺❌共通点スコアリング」も、2021-23年の混合手法期と比べて的中率が大きく向上したわけではない。手法自体の精度よりも、対象レースの選び方（掲載するレースの荒れやすさ）が結果を左右している可能性が高い。

④ 次のステップとして使える定量特徴量

  • 本文中で毎回言及される「⭕️（共通点クリア数）」の数は、記事ごとに定量抽出できる特徴量である。「全項目オールクリア」か「1〜2項目未達」かで信頼度が変わる可能性が高く、今後は本文（有料記事は購入前提）から共通点の⭕️🔺❌スコアを自動抽出し、的中レベルとの相関を検証する価値がある。
  • 同様に「推奨馬の想定人気（オッズ帯）」「共通点母数（過去N年で何頭が該当したか）」も、著者が毎回明記する定量情報であり、特徴量として使える。predictions_ground_truth.json の marks_verified にnetkeiba確認済みの人気が既に含まれている。
  • モデル化する場合の候補特徴量：グレード・芝/ダート・距離帯・非根幹距離か否か・推奨馬の人気帯・共通点クリア率（⭕️数／全項目数）・有料/無料・開催時期。目的変数は本節の9段階hit_level（0-8、または連続値化したLv./8）を使うと、単純な的中/不的中の2値分類より情報量が多く回帰・順序ロジットにも展開しやすい。
残る制約： サンプルが判定可能58件と少なく、netkeiba実データで検証済みとはいえ的中レベルの「本命（honmei）」の同定はルールベースの判断（_meta.json の honmei_identification_rule）に依存している。信頼度スコアを本格的に運用するなら、①記事数をさらに積む（毎週継続的に本文を取得・記録する仕組み）、②race_idを正式に解決してnetkeiba照合を自動化する仕組み、の2点が次の優先課題になる。

  • 実データ検証により、note本文の自己申告と実際の結果が食い違うケースが複数見つかった（例: スプリンターズS2026は本文で「▲が2着」と記載されていたが実際は1着、フェブラリーS2026は本命が「上位人気決着」とだけ記載され具体的な着順は書かれていなかった等）。的中レベルは常にnetkeiba側の実データを優先している。
  • 本命（honmei）の同定はルールベースの判断（◉/◎の記号 → 「本命」明示 → 「イチ推し」等の単独名指し → 本文最初の言及、の優先順位。詳細は _meta.json）。複数の印が同格で言及されるレースでは解釈の余地が残る。
