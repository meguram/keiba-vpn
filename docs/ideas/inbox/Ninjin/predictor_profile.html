保存した16レース分の予想見解から、この予想家の「予想軸」と「馬の選び方」を言語化したもの。作成日: 2026-11-10 / 元資料: 同じフォルダの *_予想家見解.txt 16件（画像を書き起こして整理したもの）。

ひとことで言うと
  • 「馬場とペースを数字で測り、そのレースの『勝ち方』を先に決めてから、それに合う馬を選ぶ」型。馬の能力や血統より、その日・そのコース・その展開に何が向くかの説明に文章の大半を使っている。
  • 馬場は「良・稍重」の表示では済ませず、同クラス・同距離の別の日との前後半ラップの差、含水率、降雨・気温・風で測る。そのうえで脚質の偏りはペースで切り分けてから馬場のせいにする。
  • 馬は、逃げそのものではなく「その直後で流れに乗れる」「好位後ろ〜中団で脚を溜め、周りの動きに合わせて進出できる」「追走で余力を残し最後まで脚を保てる」タイプを好む傾向がある。
  • 断定を避け、事前の想定と、当日の結果を見た修正を分けて持つ。「前有利と決めつけない」が口癖。

1. 考え方の流れ（7段）

文章はほぼ毎回、次の順に進む。馬の話は最後の方で、前半は馬場・展開の説明に使われる。

  1. 馬場の「水準」を測る（速いのか、重いのか） 文面同クラス・同距離の別の日（昨年の同レース、先週、夏開催終盤など）の前後半ラップ・走破時計と比べる。
    • 「入りが遅い・全体も遅い」＝重い。「入りが遅いのに全体は速い」＝水分を含み脚抜きが良い（福島11R・福島8R）。
    • 勝ち馬だけでなく2着の時計も見て、勝ち馬の強さを割り引く（中京7R）。比べる相手が揃わないとき（牝馬限定と混合など）は時計差をそのまま馬場差にしない（阪神9R 新涼特別）。
    • ダートは含水率（0.2%・2%台・7〜8%・14%台など）を数字で使う。降雨量はミリを足し上げる（札幌7R: 38.0+2.5+1.5=42.0ミリ）。
  2. 馬場の「偏り」（前有利・外有利など）を結果から読む。ただしペースで切り分ける 文面
    • 前残りが出ても、道中が緩んだレースの前残りは馬場傾向と断定しない。前傾ラップなのに逃げ馬が粘ったときだけ「馬場が前有利」の根拠にする（阪神9R 新涼特別）。
    • スローなのに最速の上がりが速くならない＝雨で軽さが薄れた（東京8R）。「時計は速いが終盤は減速」＝軽い馬場ではなくパワーと持続力が問われる（中京7R）。
    • 枠の偏りは「枠だけで外有利と決めつけ（ない）」（福島11R。本文が途切れており続きは未確認）。
  3. 当日・翌日の馬場の「変化」を予想する 文面降雨の有無、晴れ間、気温、風速・風向、散水、馬場発表（稍重のまま）と実際の水分の差を使う。
    • 同じ日でも午前と午後は別の馬場（昼過ぎに良→稍重／7R頃には稍重発表のままでも朝より水分が抜ける）。
    • 雨の日からの回復の途中と回復後も別の馬場（東京10R 秋峯S）。
    • コース替わり・使用週数（A→B、Aコース4週目、芝の張り替え直後）と、内柵沿い・向正面などの傷みの場所を見る。
  4. レースの展開を「隊列 → 道中 → 3〜4角 → 直線」で組み立てる 文面馬名を挙げて、誰がハナを主張し、誰が番手で運べ、誰が向正面から動くかを描く（阪神12R／阪神6R／中山9R習志野特別／阪神9R瀬戸内海特別／中京6R）。
    • 番手で運べる馬が多い → 競り合いは長引きにくい → 隊列が決まれば道中は落ち着く。ただし「前を射程に入れて運びたい馬が揃う」と道中は大きく緩まない。
    • 後ろから動く馬（向正面で位置を上げる／3角過ぎから動く）がいると、逃げ・番手勢は直線を待たずに脚を使わされ、好位勢が先に抜け出す。
    • 後半が加速し続ける形は瞬発力ではなく持続力勝負（東京9R、中山9R習志野特別）。
  5. その馬場・展開で「勝ち方」を決め、向く馬のタイプを選ぶ 文面
    • 狙いの中心は逃げ馬そのものより、その直後で流れに乗れる馬（中京6R）。
    • 最内を避けつつ、中ほどの進路へ持ち出せる好位後ろ〜中団（札幌7R。最内の傷みと、外を回す距離損の折衷）。
    • 外で風を受け続けず、前を射程圏に入れながら馬群の中で脚を溜め、道中の動きに合わせて進出できる馬（阪神6R）。
    • 追走で余力を残し、直線まで脚を保てる馬（東京10R電話50周年）／前で流れに乗りながら最後まで脚を使える馬（京都3R）。
    • 道悪では外を回しながら進出する負担があるので、前半に余力を残し、逃げ・好位から運べる馬に寄る（中山9R習志野特別。途切れあり）。
  6. 個別の馬は、前走の「内容」で評価を直す（着順をそのまま信じない） 文面
    • 前が詰まって追い出しを待たされたが、上がり33.3・0.6差の9着 → 「昇級初戦の着順だけで評価を下げない」（阪神9R 瀬戸内海特別）。
    • 昨年8月の中京1900mで中団から上がり37.6で追い上げ、クビ差2着。道中で後方から一気に先頭まで（阪神6R。途切れあり）→ 位置取りの動きを評価。
  7. 事前の想定と、開催中の修正を分ける 文面
    • 「午前のレースから時計と先行馬の止まり方を確認し、雨が強まった場合はさらに前寄りへ修正」（中京6R）。
    • 「時計の出方は開幕後のレースを見ながら判断したい」（京都3R。砂洗浄後）。

3. 馬の選び方に見える癖

好む傾向 推測

  • レース → 馬の順。先に「このレースの勝ち方」を決め、それに合う馬を拾う。
  • 位置は極端を避ける。逃げ・最後方より「逃げの直後」「番手」「好位後ろ〜中団」。
  • 求めるのは瞬発力より余力・持続力・機動力（直線まで脚を保つ／周りの動きに合わせて進出）。
  • 内の傷みは避けるが、外を回す損も認める折衷。強風なら外を回し続けない。
  • 着順の悪い前走でも、上がり・着差・不利が良ければ評価する。

避ける傾向 推測

  • 「枠だけで外有利」「雨だから差し」「前残りだから前有利」のような単一原因の決めつけ。
  • 勝ち馬1頭の時計だけで馬場を決めること。
  • 逃げ切り一辺倒の見立て（脚抜きが良くなっても、狙いは逃げの直後）。
  • 道悪で外から長く脚を使う進出（負担が大きい）。

見えている範囲では、一度も出てこないもの 文面

オッズ・人気、血統、調教、騎手、馬体重、斤量、回収率・期待値。印は ◎○▲ の3頭のみ。（本文が途切れた箇所に出る可能性はある。）

→ 「どのタイプの馬が来やすいか」を、レース・馬場・展開の側から決める部分に特化した見方、と読める。馬を点数化する手法というより、条件から勝ち方を逆算する手法。

6-2. 層ごとの作り方

A-1. 馬場の「水準」：別の日との時計差を日単位の指標にする

  • 既存の基準時計（コース別 par タイム。src/pipeline/megu_index/build_par_time.py。2着の行を扱う処理もある）を使い、勝ち馬と2着の par 差の平均を「日 × 場 × 面」の馬場差とする。勝ち馬1頭では決めない、という観点の再現。
  • par 差を前半（入り）と上がりに分けて持ち、「入り遅い×全体速い（水分で時計が出る）」「入り遅い×全体遅い（重い）」「全体は速いが終盤は減速（パワー・持続力）」を、2軸（全体の速さ・終盤の減速）の4象限に落とす。
  • 比べる相手は「同クラス・同距離の別の日」。サンプル不足のセルは par にまとめる（セルごとの最小件数を先に決める）。牝馬限定と混合のような条件違いは、par 側の条件に含めるか除外する。

A-2. 水分と乾き方：含水率の朝値 ＋ 気象から、レース番号別の水分を予測

  • 入力: JRA 馬場情報（data/jra_baba/cushion_*.json。クッション値・芝/ダートの含水率（ゴール前・4角）・使用コース A/B・開催回・開催日目）と、気象庁の時別値（src/scraper/jma_weather.py。風向・風速・気温・降水量）。
  • 作るもの: 前日までの降水（ミリ）の積算、当日の気温・風速、散水の有無から、「朝の含水率 → 7R 頃の水分」を予測する式。教師は実測の時計差（A-1 をレース番号別に出したもの）。含水率の実測は日に1〜数点しかないので、午後の水分は時計差で間接的に当てる（直接の正解は無い）。
  • 発表の馬場状態と実際の水分のずれ（「稍重のままでも朝より抜けている」）は、含水率の実測値 − その発表の平均的な含水率で表す。
  • 欠け: 散水の記録（有無・量）は取れていない可能性が高い。未取得なら、朝値が急に上がった日を散水の代理にする。

A-3. コースの傷みと開催週

  • 使えるもの: 使用コース A/B、開催回、開催日目（上記 JSON）。
  • 欠け: 芝の張り替え時期、内柵沿いの傷みの場所（向正面・3〜4角）、砂洗浄。直接のデータは無い。代理として、「開催日目 × 通過した内外位置（枠・コーナー通過の内外）」ごとの par 偏差を作り、傷みが進む週に内を通った馬が実際に損をしているかを測る。張り替え・砂洗浄は、JRA の開催前ニュースなどからの手入力リスト（年数回分）を別表にするのが現実的。

A-4. 馬場の偏り：ペースで説明される分を引いたうえで、日内の偏りを逐次更新

  • 各レースの勝ち馬・上位馬の4角順位から「前残り度」を出し、そのレースのペース形（前傾/平均/後傾）で期待される前残り度を引いた残りを「馬場の偏り」とする（前傾でも逃げが粘れば前有利、の再現）。ペース形は実測ラップ（前後半）で作る。
  • 日内では、1R から順に累積してそのレースより前の結果だけで更新する（当日修正のルール）。事前値（前日までの傾向）と、当日更新値の差が小さいか大きいかも特徴にできる。
  • 日単位ではなくレース数で数える（4鞍中2鞍など）。小さい母数なので、平滑化の強さ（事前のレース数）を検証で決める。
  • 外有利・内有利、枠だけの決めつけはしない：枠は偏り指標に入れず、通過位置（内外）で測る。

B. 隊列と動く馬：既存のラップ予想・走法マップを需要ベクトルに変換

  • 既存: ラップ傾向（スロー/ミドル/ハイ）の確率とハロンごとの予測（src/pipeline/models/lap_forecast.py）、走法マップの軸（TS・TS持続力・出脚・先行力・消耗耐性・まくり特性など。docs/ideas/running_map_axes_fixed.md）。
  • 追加で作る特徴（出走馬の as-of 値から）:
    • ハナ候補の数、番手候補の数（先行力・出脚の上位から）。
    • 動く馬の数（まくり特性・通過順位の上げ幅の履歴が大きい馬の頭数）と、その馬の枠・脚質。
    • ペース確率 × 動く馬の数 → 「逃げ・番手勢が脚を使わされる度合い」。
  • 需要ベクトルは学習で決める（過去レースの上位馬の軸の平均 − 出走馬全体の平均）。手で重みを置かない。A の馬場指標と B の隊列特徴を条件に、需要ベクトルを予測するモデルにする。

C. 馬の適合度と前走補正

  • 適合度 ＝ 馬の軸（as-of）と、そのレースの需要ベクトルの内積（または需要で重みづけた軸の偏差値）。位置取りは「逃げ・最後方を避け、逃げの直後〜好位後ろ〜中団」を好む傾向を、位置取りの中位への加点として入れるか、予想家の好みとしてではなく需要から出る結果に任せるか、両方試す。
  • 前走補正: 上がり順位と着順のずれ、通過順位の急な入れ替わり（不利の代理）、昇級初戦の割引。不利の扱いは既存のsrc/pipeline/megu_index/excusable.pyと重なる可能性があるので、先に中身を読んで重複を避ける。
  • 印: 適合度だけで上位3頭を取る案と、現行モデルの実力（勝率）との合成で取る案を作る。この予想家は実力の話をほぼしていないため、前者が「文字どおり再現」、後者が「実用に近い」。

6-3. 実施の順序

  1. 16レースの特定（答え合わせ用の台帳） 保存日は開催日ではない。場・R・馬番と馬名から、開催日を過去の出馬表で逆引きする（同じ場・R・馬名の組み合わせで一意に決まる想定）。特定できたら、各レースの結果と ◎○▲ の着順を台帳にする。見つからないレース（取得対象外など）は除外し、理由を残す。
  2. データ在庫の確認（欠けの確定） 含水率・クッション・開催週・使用コース、気象（風・気温・降水）、実測ラップ、通過順位が、過去何年・何日分あるかを数える。上の 6-2 の「欠け」を実測で確定し、代理で済ますか、手入力にするかを決める。
  3. 層 A の指標を作り、単独で検証 馬場差（A-1）、水分予測（A-2）、偏り（A-4）を日・レース番号単位で作る。検証は馬ではなくレース/日の側で行う:
    • A-2: 事前の水分予測が、その日の午後の時計差をどれだけ当てるか（朝の時計差だけで当てる単純版と比べる）。
    • A-4: 当日の途中までの偏り指標が、残りのレースの前残り度を、前日までの傾向より当てるか。
    ここで増分が無ければ、馬の層に進まず止める。
  4. 層 B・C を足し、現行モデルへの増分を測る A の指標・隊列特徴・適合度を、現行モデルへ束で足したときの勝率の対数損失の変化を見る。採否は既存の二段基準に従う：候補は「年ごとに抜いた検証（LOYO）で符号がそろい、点推定が −0.0002 以下」、そのうえで束として 2025 年のテストを1回だけ評価。2026 年はテストセット②として選択には使わない。
  5. 印・馬券の水準で確認 ◎○▲ の的中・複勝率・回収率をレース単位の母数で出し、現行モデルの印・同点数の人気上位と比べる。馬券は厳格な基準（区間下限が100%を超えるか）のまま。「逃げの直後」の安定（A の含水率帯別に逃げ／直後／差しの好走率）は、ここで別に確認。
  6. 16レースの答え合わせ（最後） 作った仕組みの事前出力（そのレースの前日・当日朝の as-of 値）と、この予想家の印・見解の言語化を、レースごとに並べて見る。一致する観点・しない観点を、定性的に記録する（採否には使わない）。

6-4. 再現できない／粗くしか再現できないところ

部分理由代わりに
映像・目視での不利判断データ化されていない通過順位の急変・上がり順位と着順のずれで代理
馬場の傷みの場所・張り替え・砂洗浄公式の数値が無い開催日目×通過位置の偏差、手入力リスト
午後の実際の水分含水率は日に数点レース番号別の時計差で間接推定
馬名を挙げた隊列の細部騎手の意図・当日のゲート内の駆け引き先行力・出脚の上位から、ハナ・番手候補の数と形だけ
予想家個人の経験・直感文面にない再現しない。増分は数値の層で測る
未取得の期間の気象・馬場情報取得範囲に限りがある範囲を在庫確認で確定し、足りない年は検証から外す

6-5. 最初の一手（着手するなら）

  1. 6-3 の手順 1（16レースの開催日の特定）と手順 2（データ在庫の確認）。どちらも読み取りだけで、費用はかからない。
  2. 手順 3 の A-1（par 差による日別の馬場差）。既存の par タイムがあるので、最も小さく始められ、「別の日との時計差」という中心の観点の効果を最初に見られる。
  3. A-1 に増分が見えたら A-2・A-4、見えなければ、この方向は止める。
