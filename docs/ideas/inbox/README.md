# 予想観念の受け皿（inbox）

予想の参考になりそうなテキストを、**無造作に置いていく場所**。形式・整理は不要。

## 置き方

- このフォルダに、`.md` か `.txt` のファイルを足すだけ（ファイル名は自由。日付や話題を付けると後で探しやすい）。
- 1 ファイルに何件貼ってもよい。出どころ（URL・書名・日付）が分かれば 1 行添えておく。
- 書式の決まりはない。コピペのままでよい。

## 取り扱い

- **このフォルダの中身（README 以外）は git 管理に入れない**（`.gitignore` で除外）。
  このリポジトリは公開で、他者の文章の転載を公開しないため。バックアップが要るときは別途コピーする。
- 整理して使うときは、自分の言葉で着眼点に書き直し、`docs/ideas/` 直下の `other_predictor_ideas.md` 等へ移す（原文の引用・固有名・数値は載せない）。
- 検証する段階になったら、as-of（その日より前の結果だけ）で調べ、翌年で再現するかを見る。
