# 過去位置取りの出遅れの扱い（2026-11-27）

結論:

- 今の値（M0・直近 8 走を新しい走ほど重くした加重平均）は変えない。
- 最頻（KDE の頂上）・中央値・出遅れの走を除く平均は、どれも次走の位置の当たりが M0 より悪い。
- 山が 2 つある馬で山を選ぶ規則（枠・距離・先行馬の数など 7 つ）も、M0 を超えない。
- 走数が 0〜3 走の馬だけは、平均の位置へ寄せると当たりが良くなる（B6）。効きの大半は寄せること自体で、父・母父・騎手・調教師の情報の上乗せは小さい。

道具は `src/scripts/data/pos_late_start_eval.py`（段 1）と `src/scripts/data/pos_rules_eval.py`（段 2）。
事前の決まりは、数を見る前に branch `fix/pos-late-start` へ commit した（段 1 は f4142463、段 2 は 2d90489a）。
段 2 は初回の後に、critic の指摘で 4 点を直して流し直した（2016 年より前の走が数えられない馬を除く・A3 を全頭で数える・本当の前走・対照 B7）。規則・候補・k の候補は変えていない。

## きっかけ

ユーザーの指摘（202603030511・福島 11R）: ふだんは前で競馬する馬なのに、出遅れた走が平均を後ろへ引いていそう。
例はヴィスマール（2 番）。ふだんは 1〜2 番手だが、小倉の 14/14 が入って、加重平均は 0.455（差し(前)）。
今回の実際の初角は 5/16（0.31）だった。

## 測り方

- 的: 次走の初角の相対位置（通過順位÷頭数）。着順・オッズは使わない。
- 行: 2016〜2024 年の JRA の平地と障害（段 2 は平地だけ）。
- 分け方: 開催（race_id の先頭 8 桁）の md5 の末尾の 16 進の偶奇で、探す側と確かめる側に分ける。
- 段 1 の主の的: 2023〜24 年の次走のうち、備考の表に載り「出遅」が無い走（普通のスタートの代わり）。副の的は全走。
- 差の判定: 開催単位のブートストラップ（B=2000）と Holm の補正。

## 段 1: 集計の形（確かめる側の平均絶対誤差）

| 候補 | 主の的（30,948 走） | 全走（190,676 走） |
|---|---|---|
| M0 今の加重平均 | 0.1944 | 0.2043 |
| M1 中央値 | 0.1996 | 0.2100 |
| M2 KDE の頂上（最頻） | 0.2106 | 0.2204 |
| M3 新しい走ほど重い KDE の頂上 | 0.2075 | 0.2173 |
| M4 出遅れ疑い（挽回あり）を除いた平均 | 0.1956 | 0.2081 |
| M5 ふだんより 0.3 以上後ろの走を除いた平均 | 0.1973 | 0.2118 |

- M1〜M5 は、どれも M0 より有意に悪い（Holm で p ≤ 0.014）。探す側も同じ順。
- 山が 2 つの馬（約 20%）は M0 0.2036、M2 0.2430。
- 出遅れの率が 25% 以上の馬は M0 0.2004、M4 0.2094。
- 3〜7 走の馬だけ M4 がわずかに良い（0.1929 対 0.1950）。後から見つけた差なので採らない。

なぜ M0 が良いのか:

- 序盤の位置は、同じ馬でも走ごとのばらつきが大きい。後ろだった走も、次の位置の手がかりになる。
- 出遅れが多い馬は、次も出遅れやすい。出遅れの走を除くと、その性質を消してしまう。
- 8 走から 1 点（最頻）を選ぶと、どの山を選ぶかで値が大きく動き、かえってぶれる。
- 平均は、ばらつく馬を真ん中へ寄せる。そのため外れたときの誤差が小さい。

数え: 今の外れ値の規則（MAD×4）が働く走は 8.4%。出遅れ疑い（挽回あり）を履歴に含む走は 28.8%。

## 段 2 (A): 山が 2 つの馬の山の選び方

予想 H = (M0 + 規則が選んだ山)/2。規則が何も言わないときは M0。
比べるのは、山が 2 つの全行の平均絶対誤差（探す側 27,175 走・M0 0.2109）。行は、表に初めて出たのが 2017 年以降の馬（平地）。

| 規則 | 向き | 言った走 | 当たり（選んだ山が近い） | いつも主の山 | H の誤差 |
|---|---|---|---|---|---|
| A1 枠 | 内 → 前・外 → 後ろ | 18,310 | 50.4% | 55.8% | 0.2220 |
| A2 距離の変化 | 200m 短縮 → 後ろ・延長 → 前 | 12,423 | 56.3% | 55.5% | 0.2124 |
| A3 先行馬の数 | 4 頭以上 → 後ろ・1 頭以下 → 前 | 16,413 | 58.4% | 55.7% | 0.2103 |
| A4 騎手の先行の率 | 0.35 以上 → 前・0.20 以下 → 後ろ | 2,667 | 58.8% | 56.0% | 0.2110 |
| A5 前走の位置 | 前走が前寄り → 前 | 27,165 | 58.9% | 55.6% | 0.2135 |
| A6 休み明け | 90 日以上 → 後ろ | 4,410 | 48.3% | 54.9% | 0.2144 |
| A7 頭数 | 10 頭以下 → 前・16 頭以上 → 後ろ | 15,792 | 48.1% | 55.6% | 0.2236 |

- 通った規則は無い。そのため確かめる側は開けていない。
- A3（先行馬の数）だけは H の誤差が M0 をわずかに下回る（-0.0005）。差は偶然の範囲（Holm で p = 0.58）。
- A3・A4・A5 は、山の当たりがいつも主の山より +2.7〜+3.3pt 高い。それでも、山へ寄せる分だけ外れたときの誤差が増える。
- A1・A6・A7 は、いつも主の山より当たりが低い。枠・休み明け・頭数では、どちらの山かは決まらない。
- 使わなかった事柄: クラスの上下と初角までの距離（軽い表に必要な列が無い）、騎手の替わりだけ（向きが決まらない）、母の産駒（母の ID が無い）。

## 段 2 (B): 走数が少ない馬の補い

B6 = (n·M0 + k·B5)/(n + k)。B5 は、父・母父・騎手・調教師の as-of の平均の位置の平均。k は探す側で 1 に決めた。
対照の B7 は、B5 の代わりに全体の平均へ寄せた物（k は同じ探し方で 1）。行は、表に初めて出たのが 2017 年以降の馬（平地）。

| 走数 | 確かめる側の走 | B0（M0。初出走は全体の平均） | B7 全体の平均へ寄せる | B6 父・騎手などへ寄せる |
|---|---|---|---|---|
| 0 | 19,064 | 0.2574 | 0.2574 | 0.2525 |
| 1 | 17,870 | 0.2579 | 0.2285 | 0.2267 |
| 2 | 15,532 | 0.2245 | 0.2151 | 0.2140 |
| 3 | 13,114 | 0.2147 | 0.2110 | 0.2101 |
| 全体 | 65,580 | 0.2412 | 0.2302 | 0.2279 |

- B6 は B0 より -0.0133 良い（開催単位のブートストラップで p < 0.001）。探す側も同じ向き。
- そのうち -0.0110 は、全体の平均へ寄せるだけで得られる（B7）。1〜2 走の位置は偶然が大きく、真ん中へ寄せると当たる。
- 父・母父・騎手・調教師の情報の上乗せは -0.0023（B6 対 B7。p < 0.001）。初出走では -0.0049。
- 単独では、今回の騎手の平均（B3）が最も良い（初出走で 0.2508）。

## 画面の説明の 1 文（C）

確かめる側でも M0 を超えたのは B6 だけ。説明の型:

- 「走数が少ない（n 走）ため、父・母父・騎手・調教師の傾向（前から X%）へ寄せています。」

山が 2 つの馬は、2 つの山を印で見せる。予想の値は M0 のまま。
