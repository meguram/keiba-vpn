# 走法マップ 軸の確定定義(実測ラップ版)

2026-10-30 にユーザー確定。`run_axes.py`(1走ごとの軸)→ `running_profile.py`(as-of プロファイル)→ `running_map.py`(9方面の地図+急坂・道悪の補助軸)へ統合済み(ANALYSIS_VERSION 13、REFERENCE_VERSION 3)。
入力は db.netkeiba.com の馬別 200m ラップ。実測のない走は `lap_predict.py` の予測ラップで補う。
(ギアチェンジは 2026-10-30 に追加。検証は host の /home/jovyan/acq/ts_gear1.py, ts_gear2.py)

## 1. TS
`horse_ts.py`。ラスト3区間の最速ラップを、レース水準補正(`lap_correction.py` モデルD)のうえコース単位で偏差値化。クラス・馬場区分は使わない。

## 2. TS持続力
- 窓: 1400m以下は L3〜L1(最大3)、1600m は L4〜L1(最大4)、1800m以上は L5〜L1(最大5)。本数/最大で正規化。
- 判定: ラップTS ≥ TS−D かつ ≥40。D は短距離9、他12。TS<45 は 0(床45)。
- 数え方: L3以降のピークを含む連続ブロックの本数。L4→L3 のラップTS上昇 ≥20 かつ L4 がブロック外なら +0.5。
- 零ルール: 生ラップ L5..L1 が単調減速(許容0.0秒)かつ L5 のラップTS − TS ≥ 10 なら 0。
- ラップTSのクリップなし。ラスト3Fで20秒/200m超の走は異常走として印のみ。

## 3. 前後半比(案C)
`pc[-3:].mean() / pc[1:-3].mean()`(pc は200m換算ペース、スタート区間を除く)。小さいほど後傾。コース偏差で使う。

## 4. 出脚(1F目のタイム)
- 標準化グループ: A=場+芝ダ+距離+初区間長(n≥100) → B=芝ダ+距離//400+初区間長(n≥100) → C=芝ダ+初区間長。初区間長は 200/100/150m。
- z = (1F秒 − グループ中央値) / (1.4826·MAD)。
- 出脚 = 50 + 10·(−(z − 0.5·レース平均z))。
- クリップなし。10未満・90超は印のみ(本物の出遅れ・速発を潰さないため)。

## 5. ギアチェンジ(新軸)
- 窓: 1400m以下は L3〜L1、1600m以上は L5〜L1。隣り合う1F区間で縮んだ秒 d = w[i] − w[i+1](正=加速)。
- 値: 窓内で加速した分の合計 sum_pos = Σ max(d, 0)(秒)。加速位置は見ない。
- 標準化: コース偏差(グループ平均を引く)→ レース平均偏差を k=1.0 で引く(レース内相対)→ 距離帯別(≤1400 / 1600 / 1800+)の std で割り 50+10z。MAD は 0 が過半(短距離52%・1600m以上約18%)で使えないため std。クリップなし。
- 評価(n=15,874): 次走再現性 k=0/0.5/1.0 → 0.084/0.122/0.140(短0.131・1600 0.117・1800+ 0.157)。k=1.0 は前後半比との相関 0.32(k=0 は 0.50)、TS持続力のギア加点との相関 0.05 で最も独立。
- 注意: 次走着順への増分R2 は TS に対しても TS+前後半比に対しても 0.001(予測力の上乗せは実質なし)。短距離は窓が2段で0が多い。タイプ分類用の軸として扱う。
- 不採用: max_step(sum_pos とほぼ同一)、best_gain(sum_pos と同等)、net_L1(前後半比と相関0.8で重複、裾が重い)。

## 6. 消耗耐性(新軸。ユーザー確定 2026-10-30「このまま軸として追加」)
「ハイペースのとき、同じ位置で追走した馬の中で、どれだけ落ちなかったか」。失速(スタミナ寄り)の軸。
- 減速 D21 = (L1+L2)/2 − 中盤平均(pc[1:-2] の平均、200m換算)。D31(L3まで含む)は前後半比とほぼ同一(相関0.99)なので不採用。
- 条件づけ: コース偏差した D21 を距離帯別(≤1400 / 1600 / 1800+)に [ペース(600/1000m通過のコース偏差), 自分の通過差, 通過位置の相対順位] で回帰し残差を取る。自分の速さ(中盤・初区間の偏差)を共変量にすると D21 自身を含むため循環して不可。
- 残差 − 1.0×レース平均 を、異常走(ラスト3Fで20秒/200m超)を除いた距離帯別 std で割り、50 − 10z(高い=落ちない)。クリップなし、異常走は印のみ。
- 評価(n≈16,800): 次走再現性 全体0.147(短0.079・1600 0.232・1800+ 0.211)。前後半比との相関0.72、TS 0.40、ギア 0.39、出脚 −0.01。
- 次走着順への増分R2: TSに0.016、TS+前後半比に0.044。ただし共変量(ペース・自分の通過差・位置)だけで0.049あり、共変量を入れた後にSを足す増分は0.0046(短0.006・1600 0.000・1800+ 0.003)。
- 解釈: 増分の大半は「前で速く追走した馬が次走で強い」という位置・序盤速度の効果で、落ちなかったこと自体の上乗せはほぼない。実減速 −D21 だけの増分は0.016。
- 扱い: 予測力の上乗せは小さく、前後半比・先行度と重なるため、タイプ分類用の軸として追加(ギアチェンジと同じ扱い)。定義は上記のまま変更しない。

## 7. 先行力(旧称「先行度」。ユーザー確定 2026-10-30「先行案はそのまま、名前は先行力」)
- 通過位置の相対順位 relpos = (通過順 − 1) / (頭数 − 1)。1400m以下は600m通過、1600m以上は1000m通過の区間の `position`(コーナー通過順ではなく区間ごとの順位)を使う。
- 前を高得点にするため符号を反転。コース偏差(グループ平均を引く)し、レース平均は引かない(頭数で正規化済みのためレース平均はほぼ0.5で潰れる)。距離帯別 std で 50+10z。
- 位置データ(`position`)は 2026 年分のみ実質的に入っている(2023 は 0 ばかり)。検証は 2026 データで行う。
- 検証(2026、n≈15.5k): 次走再現性 0.115(短0.078・1600 0.142・1800+ 0.129)、次走着順への増分R2 0.002。相関は TS 0.01・前後半比 −0.04・持続力 0.01・ギア 0.00・出脚 0.15・消耗耐性 −0.01 で他軸とほぼ独立。距離帯別の平均/sd は 50/10。タイプ分類用の軸。

## 8. 押し上げ(2軸に分割。ユーザー確定 2026-10-30)
- **Cr性能(確定)**: 3角 → 4角の相対順位の前進 `r3 − r4`(正=押し上げ)。コーナーで押し上げる器用さを見る軸なので、4角→着順(直線の脚)は混ぜない(混ぜると消耗耐性・TS・前後半比と重複)。コース偏差 → 距離帯別 std で 50+10z、レース平均は引かない。3C/4C は区間の `corner` ラベルで特定。
- **まくり特性(確定)**: 400m通過 → 3角の相対順位の前進 `r_400m − r3`(正=押し上げ)。スタート区間の順位は枠順ノイズなので使わない。スコア化は Cr性能と同じ。
- 両軸ともタイプ分類用(次走への増分R2 ほぼ 0)。2026 のみで検証、2025/2024 は補填完了後に再確認。
- 検証項目: 次走再現性(距離帯別)、増分R2(TS・TS+前後半比に対して)、既存軸との相関(先行力・前後半比・出脚・消耗耐性)、Cr性能とまくり特性の独立性。
- 位置は相対順位 r=(順位−1)/(頭数−1)。押し上げは前進を正にする(r_前 − r_後)。コース偏差 → 距離帯別 std で 50+10z。検証は host の ts_pos1.py / ts_pos2.py(2026のみ)。

## 9. 急坂適性(新軸。ユーザー確定 2026-10-30「中山・阪神のみB案」)
ゴール前の急坂区間で、ラップがどれだけ落ちなかったか。対象は中山・阪神の最終1F(L1)のみ。東京は例外として除外、中京(L2)は当面外す。
- 対象コース: 中山芝/ダ・阪神芝/ダ(`jra_courses.json` のゴール前の坂: 中山芝180→70m・中山ダ202→35m・阪神芝195→55m・阪神ダ200→60m)。坂が無いコースの走は欠測。
- 値(B案): slB = pc[-1] − 0.5×(pc[-2] + pc[-3])(坂ラップ − 直前2本の平均、200m換算秒)。大きい=坂で落ちた。
- 標準化: (場, 芝ダ, 距離) のグループ平均(n≥25、足りなければ場+芝ダ)を引いてコース偏差 → レース平均偏差(異常走除外)を k=1.0 で引く → 距離帯別(≤1400 / 1600 / 1800+)の std(異常走除外)で割り 50−10z(高い=坂で落ちない)。クリップなし、異常走(ラスト3Fで20秒/200m超)は印のみ。
- 評価(2026): 次走再現性は中山阪神どうしのペアで評価。TS・前後半比・消耗耐性を除いた偏再現 0.133、次走着順への増分R2 ≈ 0(タイプ分類用の軸)。消耗耐性との相関 0.74〜0.88(坂前の消耗と重なる)。
- 不採用: A案(坂ラップ−直前1本。ノイズが大きい)、共変量回帰版、坂ラップ速度そのもの。中京は窓(L2)の設定が不安定なため見送り。
- 注意: 阪神芝・阪神ダの坂位置は未確認(コースマスタの値のまま)。2025/2024 は補填完了後に再確認。

## 10. 道悪適性(軸として持つ。ユーザー指示 2026-10-30「予測に使えるかは無視、軸として重要なので持っておいてほしい」)
- 方針転換: 下記の検証では前向き相関がほぼ 0 で「予測力は確認できない」が、軸は予測力と無関係にタイプ分類用として持つ。以下の「軸にしない」「見送り」は予測用の判断であり、軸としての保持とは別。
- 軸名と実装(ユーザー確定 2026-10-30): **芝=芝道悪適性、ダート=ダートタフ適正**。芝とダートは完全に別計算(`src/research/race/going_aptitude.py`、テスト `tests/research/test_going_aptitude.py`)。running_profile / running_map への組み込みは未実施。
- 定義: 差 = パワー走の平均成績 − 非パワー走の平均成績(成績=−(着順−1)/(頭数−1))。パワー走=芝クッション値 ≤ 9.2、ダート含水率 < 6.5%(ゴール前と4角の平均)。水分の値が無い走はどちら側にも数えない。
- **不明の表現**: パワー走・非パワー走のどちらかが3走未満(出走履歴なし・道悪を走っていない等)の馬は値を **NaN(API では None、UI では「不明」)** にする。0 や 50 は入れない。n_power_*/n_normal_* も返し、判定可でも有効走数(1/(1/p+1/n))が6未満なら low_*=True(低信頼)。判定可が30頭未満の時点では全員不明。
- スコア: 差を m/(m+2) で0方向に縮め、判定可の馬全体で 50+10z。as_of より前の走だけを使う。
- 実データ確認(host、master 2020-2025、2025-10以降に走った6,713頭を 2026-01-01 時点で): 判定可は芝1,494頭・ダート1,225頭(約2割)で、残りは不明。判定可のスコアは芝 平均51.1・sd9.8、ダート 平均49.8・sd9.6。
- 位置づけ: 9章末の検証どおり「高いと判定された馬が実際に道悪で良い」とは言えない(ダートは確認できず、芝は同時期内で弱い)。タイプ分類用の軸であり、予測や馬券には使わない。

- サンプル(host の going_apt3.py / going_apt3.out): 〜2022 で各側6走以上の馬(ダ922頭・芝435頭)。極端な馬は走数6前後でノイズを含み、〜2022 の差の5分位別に見た 2023-25 の差はダ平坦(上位は逆転)・芝ほぼ平坦。芝ではウインシュクラン・ファロロジー・ヒュミドールのように翌期間も同じ向きの馬がいる。

### 以下は予測用途での検証(当初の「当面見送り」)
- 馬場種別の比較(同じ馬の重・不良 vs 良): 全面・ダートとも、道悪ペアの偏再現性は良ペアの基準と差がない(差の95%区間は0を含む)。標本は稍重以上まで広げて全面約730頭・ダート345頭。
- 馬場水分の連続値(芝=クッション値、ダ=含水率)を使った馬ごとの傾きも検証。被覆は芝クッション値 56%、含水率は芝 12%・ダ 15% しかなく、傾きを出せる馬(走4以上)は芝クッション値で110頭のみ。再現は 0.07〜0.11 で95%区間が0を含む。含水率は馬数が足りず評価不能。
- 注意: 馬場でTSがずれる(ダート=湿るほど速い、芝=重いほど遅い。例: ダ含水率 低1.8→TS 49.5、高5.7→TS 51.3、芝クッション値 低7.3→48.7、高10.1→50.5)。馬場をまたいで生のTSを使わないこと。
- 判断(馬ごとの軸): 「存在しない」ではなく「検出できない」。軸にしない。どうしても置くなら「稍重以上の着順偏差 − 良の着順偏差」の低信頼な馬場差軸の仮置きのみ。

### 馬場の境界線(含水率・クッション値の連続値で推定。ユーザー依頼 2026-10-30「馬場発表は無視、稍重位が境界では」)
- 方法: 2020〜2025 のレース単位(中央値の走破タイム・上がり3F・前半)を、コース・クラス・年(±開催)の固定効果で補正し、「境界までは平坦、境界を超えると傾く」折れ線を当てて境界を推定。信頼区間は日×場のブロックブートストラップ。馬場発表は推定に不使用(事後の突き合わせのみ)。JRA 公式 PDF から 2026 の欠けを補完済み(境界推定は 2020〜2025)。
- ダート含水率: 境界 約6〜7%(固定効果の置き方で6.1〜6.35、区間5.4〜6.85。上がり3Fでは6.85〜7.15、前半では5.2〜5.8)。境界までは平坦で、超えると含水率1%あたり約0.15〜0.17(log%)速くなる。平坦より折れ線が明確に良い。馬場発表との対応は、含水率6.8%までは良が86〜98%、6.8〜10%台は稍が最多で、境界は良→稍の切れ目に一致(ユーザーの見立てどおり)。弱点: 期間別で 2020-22 は6.6、2023-25 は4.7(区間3.8〜6.5)、場別では東京・中山の識別が弱い。
- 芝クッション値: 境界 約9.2〜9.3(区間9.2〜9.6)。これより低いと遅くなる(1あたり約+1.05〜1.09 log%)。8.0〜8.7で約+0.5〜0.64。馬場発表では良の中央値9.4、稍8.9、重8.4で、境界は良の側の縁(稍重の入口)。弱点: 開催固定効果ありや2023-25では10.0〜10.1に動き、折れ線が直線より良い度合いは弱い。2020 年はクッション値の被覆が約30%。
- 芝含水率: 境界なし(直線的で非単調、季節・開催と交絡)。馬場発表別の中央値もほぼ同じで情報が弱い。
- 注意: 2023・2025 年のレース数が他年(約1,650)より少ない(2023 は約1,340、2025 はダート688・芝560)。上がり3Fの絞り込みか欠損が原因の可能性。未調査。
- 道悪の意味(ユーザー指摘 2026-10-30): 道悪=パワーを要する馬場。**芝=水分が多い(クッション値が低い)、ダート=水分が少ない(乾いている)**。ダートは湿ると速くなるので、稍重以上はダートのパワー馬場ではない。
- パワー側の境界定義: 芝=クッション値 ≤ 約9.2、ダ=含水率 < 約6.5%。厳格版(境界から離す)は芝 ≤ 8.6 対 ≥ 9.8、ダ ≤ 5.0 対 ≥ 8.0。
- 馬ごとの道悪適性の再検証(2020-25、境界定義、走数 ダ パワー71,847/非パワー51,736、芝 45,158/51,655):
  - 前向き予測(〜2022 の差 → 2023-25 の差、パワー側−非パワー側): ダ perf_f +0.005 [−0.049, 0.066] n=1236、ダ rel_t −0.011、芝 perf_f −0.013 [−0.072, 0.040] n=1120、芝 rel_t −0.023。すべて 0。馬ごとの道悪適性は将来に持ち越されない。
  - 期間内の交互分割再現性(全走を使う単純差): 0.04〜0.13。弱い。
  - 「パワー走 − 前後の非パワー走」の局所差の交互分割は 0.34〜0.52 と高く出るが、隣り合うパワー走が同じ前後走を比較対象にしてノイズを共有するための見かけの再現性で、使えない。
  - 結論: 軸にしない(従来判断どおり)。なお初回の検証はダートの湿り/乾きを逆に置いていた(相関の大きさは不変、差の符号と解釈のみ誤り)。検証は host の going_apt1.py / going_apt2.py。
- 未実施: 2026(テストセット②)での独立確認。

### 芝・ダートをまたぐ道悪適性(絶対値)の検証(ユーザー依頼 2026-10-30)
host の going_apt4.py / going_apt5.py / going_apt6.py(出力は同名 .out)。
- レース単位: 乾いたダート(含水率<6.5%)は非パワーダートより +0.743 log%(0.78sd)遅く、濡れた芝(クッション≤9.2)は非パワー芝より +0.462 log%(0.38sd)遅い。走破タイムでは乾いたダートの方がパワーを要する。上がり3Fの遅れは同程度(0.36sd 対 0.35sd)、前半の遅れはダートが大きい(0.52sd 対 0.17sd)。注意: 比較の基準側が面ごとに違い、湿ったダートが最速の馬場なので、ダート側の差は膨らむ。
- 馬単位で芝とダートが同じ向きのベクトルか: 支持されない。同じ馬の芝パワー差×ダ乾き差 r=−0.037 [−0.136, +0.073](n=277)。共通尺度の傾き同士も r=−0.02(n=1504)、0.016(n=376)。
- 橋渡し馬(両面を走る馬)で重なり点を探す: 検出されない。ダート巧者と芝巧者の差は含水率帯によらずほぼ一定(ダ +0.09〜+0.13)。芝巧者の芝での優位はクッション値が上がるほど縮む(−0.148→−0.073)が弱い(約1.6σ)。
- 共通尺度 L(面ごとに水分→平均遅れの折れ線を20分位ビンで作り、全体 sd で割って芝ダ共通の単位にする)での馬ごとの傾き(馬×面で中心化、リッジ縮小 λ=Σ Lc² の中央値): 計算はできる(面を切り分けない絶対値)。ただし信頼性が非常に低い。交互分割 r=0.05(芝0.069・ダ0.022)、前向き 0.012。面をまたぐ前向きは符号が不安定。L の重なり: 芝は主に −1〜0、ダは 0〜1、L>1 の重い芝は少数、L<−1 の湿ダは長い負の裾。

### 「道悪巧者」と判定された馬は実際に道悪で良いか(ユーザー依頼 2026-10-30「実際に高いと言われた馬が本当にその傾向にあるのか。判定不能は欠損」)

- 芝: 弱い。交互分割では上位20%−下位20%が +0.038 [+0.014,+0.063](各側3走)、+0.032 [+0.003,+0.061](各側5走)で0を超えるが、判定側の差(+0.32〜+0.38)の1割弱しか残らない。時期分割は +0.004〜+0.012 で区間が広く(±0.05)、0と区別できない。走破タイム偏差では交互分割の上位20%−下位20%が +0.070 [−0.010,+0.153]、−0.003 で有意でない。
