# 走法が近い馬は一緒に来るか（買い目推奨への反映）

2026-11-02 検証。走法マップの「走法が近い馬」（同じレースの中で 8 方面の差の二乗平均が小さい 3 頭。`running_map.similar`）が、
予想・買い目推奨に使えるかを調べた。

## 使ったデータ

- 2025-01〜2026-10 の 6,316 レース（芝 3,212・ダート 3,104）。各レースの走法マップは、レース前の走りだけから作り直した
  （`running_map.build_running_map`。GCS は読まず、手元の `data/local/running_profile` と結果表のみ）。
- 着順・単勝オッズ・払戻は `data/page_reference/tables/<年>/race_result_flat.parquet`。
- 本番モデルの確率は `data/local/inference/predictions_backfill/bundle_v6_2025`（2026 年の 2,814 レース。学習期間外）。

## 結果

### 1. 軸を決めて相手を近い馬にする（ワイド・馬連の回収率）

軸から近い 3 頭へ買った場合と、人気（オッズ）をそろえた近くない 3 頭へ買った場合の比較。

| | ワイド 近い / 他 | 馬連 近い / 他 |
|---|---|---|
| 芝・軸=1 番人気 | 86% / 72% | 88% / 67% |
| 芝・軸=コース適性 1 位 | 89% / 82% | 95% / 62% |
| ダート・軸=1 番人気 | 86% / 79% | 81% / 77% |
| ダート・軸=コース適性 1 位 | 84% / 87% | 78% / 71% |

芝は 2025・2026 年とも近い馬が上。ダートは年によって逆転。どれも回収率 100% 未満で、これ単独では儲からない。
「コース適性 1 位」は方面の重要度に検証期間を含むため、やや楽観的。

### 2. すべての 2 頭の組で、同じ確率水準どうしを比べる（買い目推奨に入れた根拠）

2 頭がそろって来る確率（オッズ・本番モデルそれぞれから着順分布で計算）を 20 層に分け、層ごとに
「近い組」と「近くない組」の実際の的中を比べた（レース単位のブートストラップで 95% 区間）。

| 確率の元 | 芝 馬連 | 芝 ワイド | ダート 馬連 | ダート ワイド |
|---|---|---|---|---|
| 本番モデル v6（2026） | 1.16 [1.07, 1.27] | 1.13 [1.07, 1.20] | 1.16 [1.06, 1.27] | 1.12 [1.06, 1.19] |
| 単勝オッズ（2025） | 1.17 | 1.14 | 1.15 | 1.08 |
| 単勝オッズ（2026） | 1.20 | 1.16 | 1.19 | 1.15 |

近い組の確率は、近くない組より高い層に偏っている。層をそろえずに合計どうしで比べると（約 1.02 倍）、
その偏りのため効果が見えなくなるので注意。

## 反映

`src/pipeline/inference/betting.py` の `STYLE_PAIR_BOOST`: 走法が近い 2 頭の 馬連・馬単 ×1.10、ワイド ×1.08（区間の下限付近の控えめな値）。
2 頭の確率は各馬の複勝率を超えないよう上限を置く。近い組は事前計算の走法マップ（`race_analysis` の保存先）から読み、無ければ補正しない。
`BettingConfig(style_pair_boost=False)` で止められる。

## 残り

- 補正を入れた買い目推奨の実オッズでの回収率（実オッズは GCS にあり、費用の上限のため手元では未実施）。prediction_results の日次精算で様子を見る。
- 3 連複: 2026-11-03 に測定。本番 3 連複が評価するモデル上位 6 頭の 3 頭の組（2,795 レース・55,900 組）で、近い組を 1 つ以上含む 3 頭は
  同じ確率水準の「近い組なし」の 1.16 倍 [1.00, 1.32]、2 つ以上で 1.19 倍 [1.03, 1.44]。区間が広く下限が 1 付近のため、補正は入れていない。
- ダート用に近さを測る方面を作り直すか（2 の結果ではダートでも効いているので優先度は低い）。
