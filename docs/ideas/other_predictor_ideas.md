# 予想の着眼点に関するアイデア帳（自分の理解で書き直したもの）

他の予想の進め方を読んで得た**一般的な着眼点**を、自分の言葉で整理した覚え書き。原文の引用・転載はしない。固有の手法名・人名・記事名・数値は載せない。
各項目は「着眼点」→「自分の予想手順との関連」→「検証案」の順で書く。自分の予想手順は `memory: user_handicapping_process`（レースの来やすい馬のタイプ → 馬の分類 → 適合グループ内で実力上位に印 → オッズ別の買い目）に沿う。

## 1. 条件付きの共通点を、レース単位で洗い出す
- **着眼点:** 対象レースの過去の結果から「人気薄で好走した馬」を集め、そこに共通する特徴（前走の位置取りや上がり、コース実績、距離実績、年齢、斤量、騎手の継続・乗り替わり、馬体重、生産者など）を数項目に絞り、全項目を満たす馬を狙う、という型。
- **関連:** 手順1「どんな馬が来やすいか」を、直感ではなく過去データで言語化する部分に当たる。
- **検証案:** レース条件ごとの共通点の抽出を、as-of（その日より前の結果だけ）で自動化し、「全項目クリア」の馬の3着内率・回収率が、無作為の人気薄馬より高いかを見る。多重比較（項目数）に注意し、翌年で再現するかを確認する。

## 2. コース形状から、ペースの傾向と向く前走内容を逆算する
- **着眼点:** 坂の位置と数、コーナーの角度、直線の長さ、スタート地点の高低から、前傾／後傾／持続力型といったラップの傾向を決め、そこから「向く前走の内容」を導く。
- **関連:** 手順1の「来やすいタイプの判断」を、コース構造から説明できるようにする。既存のラップ予想や追走難度、レース質の推定と接続できる。
- **検証案:** コースごとの形状特徴を数値化した表を作り、実際のラップ傾向との一致を確認する。次に、ペース傾向別の「前走タイプ」の好走率の差を、as-of で検証する。

## 3. 同じ距離でも競馬場で別物として扱う／類似コースへ転用する
- **着眼点:** 同じ距離でも競馬場や回りで性格が違うこと、根幹距離でない距離は荒れやすい（持続力型）という仮説、過去データの少ないコースは似たコースの実績で代替すること。
- **関連:** 馬の分類（手順2）の軸に「コースの類似度」を加える。
- **検証案:** 血統や成績からコースの類似度を数値化し、類似コースの実績を代替特徴にした場合の予測の改善を、既存の特徴群に足して検証する（効果が小さい可能性が高いので、事前に基準を決める）。

## 4. 補助的な条件（馬格、斤量比、乗り替わり、生産者の属性）を修飾子として使う
- **着眼点:** 馬体重の水準、斤量の相対的な軽さ、騎手の継続か乗り替わりか、生産者の系統などを、本筋の条件を補強する修飾子として使う。
- **関連:** 手順3の「実力上位の中での絞り込み」に使える。
- **検証案:** それぞれ単独の効果は小さいと予想されるので、上位候補内での絞り込みとしての効果（条件付きの3着内率）を見る。

## 5. 不利を受けた馬の評価（前走を度外視する）
- **着眼点:** 映像などで、前走に不利があって能力を出せなかった馬を、前走の着順に関係なく評価し直す。
- **関連:** 手順3で「不利を受けた馬は目視で補正する」としている部分と同じ。
- **検証案:** 不利の有無を、通過順位の急な変動、進路の狭さの記録、コーナーでの位置の入れ替わりなどから間接的に推定できるか。推定した不利フラグが、次走の好走率を押し上げるかを検証する。

## 6. 特殊なコースや条件は別枠にする
- **着眼点:** 直線だけのコースや、枠順の影響が極端なコースは、通常の枠組みとは別に扱い、枠順確定後に結論を出す二段階にする。
- **関連:** 手順の前提（レースタイプ判定）に、特殊条件の判定を足す。
- **検証案:** 特殊コースのレースだけ、枠順を入れたモデルと入れないモデルを分けて評価する。

## 7. 的中の度合いを段階で振り返る
- **着眼点:** 予想の結果を「当たった／惜しい／外れ」のように段階で振り返り、傾向を見る。
- **関連:** 推奨度や印の信頼度を、段階（確信度）として扱う設計に近い。
- **検証案:** 印や推奨度の段階ごとの、的中率と回収率の関係が単調かを継続的に監視する（予測成績の日次集計と接続）。

## 8. 「穴馬」の定義を、モデルの外側の絞り込みにする
- **着眼点:** 人気薄という条件は、モデル本体の入力にせず、推論後の絞り込み（後処理）として使う。
- **関連:** 市場のオッズや人気を特徴量にしない方針と整合する。人気薄の条件は、買い目の設計（手順4）の側に置く。
- **検証案:** 汎用の3着内確率で順位付けしたうえで、人気薄の条件を後段で掛けたときの、回収率と点数のばらつきを評価する。

## 9. サンプルが少ない条件は、階層的な事前確率で補う
- **着眼点:** 3歳限定戦のように過去の対戦が少ない条件では、定量的な共通点が使えないので、個別の評価や、上位の条件（クラスや距離帯）の傾向で補う。
- **関連:** 条件別の効果表の、サンプルが少ない部分の扱い。
- **検証案:** 階層ベイズ（または縮約）で、少数サンプルの条件の推定を、上位の条件へ引き寄せる。縮約の強さを、翌年の再現で決める。

## 取り込みの優先度（自分の見立て）
1. 項目 2・3（コース形状と類似度）…既存のラップ予想や追走難度、レース質と接続しやすい。
2. 項目 5（不利の推定）…手順3の補正を自動化できる可能性。
3. 項目 8・9（人気の扱いと縮約）…設計の整理として有益。
4. 項目 1・4（共通点方式、修飾子）…効果は小さい可能性が高く、多重比較に注意。
