# 欧州瞬発力 × 父の系統区分（smartrc）: TS・TS持続力に傾向はあるか

2026-11-12 の調査。結論: **父の系統区分（国系統・大系統・小系統）では、欧州瞬発力の特徴（TS は高くないが持続する）は見つからなかった。**
区分は `docs/html/pedigree/sire_lines_all.html`（smartrc の系統。`data/meta/sire_lines/sire_smartrc_colors.csv`）。

## 方法
- 走ごとの TS・TS持続力（`run_axes.parquet`。2023〜2026 の 12.8 万走、異常走を除く）を、馬 → 父（horse_sire_map の sire_id）→ 区分に結ぶ。系統が空欄の父は除いた（456 走）。
- 芝だけ（64,064 走・父 452 頭）。TS・持続力は距離帯ごとに標準化（SD 単位）。「持続 − TS」を、TS が高くないのに持続する度合いとした（欧州瞬発力の定義）。
- クラス・距離帯・競馬場を調整し（回帰の残差）、区分ごとの平均を出した。誤差の幅は同じ父の産駒をまとめた（父単位クラスタ）95% 区間。

## 結果（芝、SD 単位。幅は 95% 区間）
- **国系統**: 欧州型は日本型と差がない（TS +0.008±0.053、持続 −0.008±0.042、持続−TS −0.017±0.024）。米国型だけ芝で低い（TS −0.19±0.10、持続 −0.13±0.07）。ダートは 3 つとも差なし。
- **欧州型の 4 区分**（ノーザンダンサー系・ミスプロ系・ナスルーラ系・その他）: どれも持続−TS が ±0.05 以内で、区間が 0 をまたぐ。**欧州型ミスプロ系（キングマンボ系・ドゥラメンテなど）は他の欧州型と同じ**（持続−TS −0.023±0.022 と −0.010±0.032）。
- **大系統・小系統**: 持続−TS が最大でも +0.08（エーピーインディ系。区間 ±0.09）で有意なものはない。ロベルト系は逆向き（−0.050±0.028。TS が高め）。サドラーズウェルズ系 +0.034±0.044、ダンチヒ系 +0.037±0.038 も区間が 0 を含む。
- **定義の条件で見ても同じ**: 中京・洋芝（札幌・函館）・洋芝短距離・開催後半（7 日目以降）・中京×開催後半のどれでも、欧州型と日本型の差は区間に収まる（中京×開催後半の日本型だけ持続−TS +0.20±0.11 だが 399 走）。
- **TS が平均以下の走に限った 3着内率**（頭数・クラス等を調整）: 欧州型 − 日本型は 全体 −0.007±0.17、中京 −0.098±0.31、洋芝 +0.003±0.27、開催後半 +0.018±0.21（対数オッズ）。差なし。

## 解釈と次の手
- TS・TS持続力は馬の走り（ラップ）の量で、父の系統区分とは結びつかなかった。欧州瞬発力は「パワー馬場でギアを上げた後に脚が切れない」ことなので、TS 持続力（TS 近くの脚を何ハロン使えたか）では測れていない可能性が高い。
- 素点の候補: ギア後の減速の小ささ（中京の急坂区間の L2〜L1 の落ち、開催の進んだ芝の L1 の落ち）、同条件での着順の期待との差。父だけでなく母父・5 代の欧州系血量も使う。
- 欧州型ミスプロ系は他の欧州型と傾向が同じなので、血統成分に含めても含めなくても結果は変わらない（保留だったが、含めてよい根拠は「差がない」ことのみ）。

### 追記 6: 欧州型の血を引きながら欧州瞬発力が低い馬の特徴（2026-11-12）
- 対象: 父か母父が欧州型で、パワー・ギア上げ走が 3 走以上、2勝以上で 3 着以内の実力馬 518 頭を、縮小値で 3 分割（低群・高群 各 173 頭）。
- **走法**: 低群は TS が高く（芝の全走平均 57.7 対 55.1、標準化差 +0.64、t=6.0）、Hペース耐性が低い（49.6 対 53.4、−1.02。減速の量を測る点で素点と重なるため、差は一部が当然）、TS 持続力が低く（0.11 対 0.15、−0.39）、ギアも少し低い。先行力・Cr・まくり・出脚・ダート出走の割合は差なし。→ 「TS は高いが、パワー馬場で最後に落ちる」スポーツカー型。
- **走る距離**: 低群は芝の平均距離が短い（1,744m 対 1,895m、−0.46）。パワー・ギア上げ走の距離帯は、低群が 2200m 以上 12%、高群 21%。競馬場の分布はほぼ同じ。
- **血統**: 国系統・小系統の内訳に大きな差はない。母父が欧州型ミスプロ系（キングマンボ系）は低群 21%・高群 14%、欧州型ミスプロ系を含む割合は 56% 対 49%、父が欧州型の割合は 58%（40+18）対 63%（48+15）で、いずれも差は小さい。欧州型の経路（父のみ・母父のみ・両方）は 40/42/18% 対 48/37/15%。
- 結論: 血統の内訳ではなく、TS が高く短めの距離を走るタイプ（切れ味・スピード型）であることが、欧州型の血を引きながら低い馬の特徴。欧州瞬発力を測るなら、距離・TS の高さ（スピード型かどうか）を併せて見る必要がある。

### 追記 8: 素点のロジック診断と、欧州血の濃さ（5 世代）での再検証（2026-11-12）
ユーザー指摘: 10 点満点の統計量で血統の差が出ないのはおかしい。測り方に、欧州瞬発力でないものが混ざっているのでは。血の濃さにもよるのでは。
- **診断（現行の素点＝パワー走での減速の小ささ）**: Hペース耐性と相関 0.42（良馬場での同じ素点とも 0.24）。馬場に関係ない一般的な落ちにくさが混ざっている。さらに、TS とギアの量を回帰で除いたことで「ギアチェンジ」の成分も消えていた。最終区間が最速（減速 0）の切れ味型も高く出る。
- **新しい素点（案）= 馬場による差**: パワー走（クッション ≤ 9.2）の素点 − 良馬場走（クッション ≥ 10.0）の素点（各縮小。両方 2 走以上の 1,033 頭）。Hペース耐性との相関 0.04、TS との相関 0.00 で、馬場の効果だけが残る。オオバンブルマイ +0.39（上位 14%）、パンジャタワー +0.32（上位 19%）。
- **血の濃さ**: 5 世代の祖先を、smartrc の国系統で数え、重み 1/2^世代で足した。馬場による差との Spearman は、欧州血量 −0.04（3 世代 −0.03、4 世代 −0.04）、欧州型ミスプロ系以外 −0.015、ミスプロ系 −0.028、サドラーズ系 −0.037、ダンチヒ系 −0.014、ロベルト系 −0.024、日本型 −0.032、米国型 +0.006。四分位別の平均も平らで、欧州血量が最も濃い群の差は +0.006（最も薄い群は +0.034）。
- 下位（良馬場では落ちないのにパワーで落ちる）に、ロードカナロア・タワーオブロンドン・エピファネイア・サートゥルナーリア産駒など欧州型の血が濃い馬が目立つ（キングマンボ系は速さ型）。上位はディープインパクト・キズナ・ブラックタイド系など日本型の父が多い。オオバンブルマイ自体は欧州血量 0.12・米国 0.75 で、smartrc の国系統では欧州型ではない。
- **限界**: 差の素点は 2 つの平均の差で、再現性が低い（各 2〜4 走）。標本 1,033 頭で検出できるのは |ρ| 約 0.07 以上で、測定のノイズで薄まるため、真の相関で 0.15 以上なければ見えない。「血統の効果がない」とは言えず、「あっても弱い」までしか言えない。
