# 欧州瞬発力 × 父の系統区分（smartrc）: TS・TS持続力に傾向はあるか

2026-11-12 の調査。結論: **父の系統区分（国系統・大系統・小系統）では、欧州瞬発力の特徴（TS は高くないが持続する）は見つからなかった。**
区分は `docs/html/pedigree/sire_lines_all.html`（smartrc の系統。`data/meta/sire_lines/sire_smartrc_colors.csv`）。

## 方法
- 走ごとの TS・TS持続力（`run_axes.parquet`。2023〜2026 の 12.8 万走、異常走を除く）を、馬 → 父（horse_sire_map の sire_id）→ 区分に結ぶ。系統が空欄の父は除いた（456 走）。
- 芝だけ（64,064 走・父 452 頭）。TS・持続力は距離帯ごとに標準化（SD 単位）。「持続 − TS」を、TS が高くないのに持続する度合いとした（欧州瞬発力の定義）。
- クラス・距離帯・競馬場を調整し（回帰の残差）、区分ごとの平均を出した。誤差の幅は同じ父の産駒をまとめた（父単位クラスタ）95% 区間。

## 結果（芝、SD 単位。幅は 95% 区間）
- **国系統**: 欧州型は日本型と差がない（TS +0.008±0.053、持続 −0.008±0.042、持続−TS −0.017±0.024）。米国型だけ芝で低い（TS −0.19±0.10、持続 −0.13±0.07）。ダートは 3 つとも差なし。
- **欧州型の 4 区分**（ノーザンダンサー系・ミスプロ系・ナスルーラ系・その他）: どれも持続−TS が ±0.05 以内で、区間が 0 をまたぐ。**欧州型ミスプロ系（キングマンボ系・ドゥラメンテなど）は他の欧州型と同じ**（持続−TS −0.023±0.022 と −0.010±0.032）。
- **大系統・小系統**: 持続−TS が最大でも +0.08（エーピーインディ系。区間 ±0.09）で有意なものはない。ロベルト系は逆向き（−0.050±0.028。TS が高め）。サドラーズウェルズ系 +0.034±0.044、ダンチヒ系 +0.037±0.038 も区間が 0 を含む。
- **定義の条件で見ても同じ**: 中京・洋芝（札幌・函館）・洋芝短距離・開催後半（7 日目以降）・中京×開催後半のどれでも、欧州型と日本型の差は区間に収まる（中京×開催後半の日本型だけ持続−TS +0.20±0.11 だが 399 走）。
- **TS が平均以下の走に限った 3着内率**（頭数・クラス等を調整）: 欧州型 − 日本型は 全体 −0.007±0.17、中京 −0.098±0.31、洋芝 +0.003±0.27、開催後半 +0.018±0.21（対数オッズ）。差なし。

## 解釈と次の手
- TS・TS持続力は馬の走り（ラップ）の量で、父の系統区分とは結びつかなかった。欧州瞬発力は「パワー馬場でギアを上げた後に脚が切れない」ことなので、TS 持続力（TS 近くの脚を何ハロン使えたか）では測れていない可能性が高い。
- 素点の候補: ギア後の減速の小ささ（中京の急坂区間の L2〜L1 の落ち、開催の進んだ芝の L1 の落ち）、同条件での着順の期待との差。父だけでなく母父・5 代の欧州系血量も使う。
- 欧州型ミスプロ系は他の欧州型と傾向が同じなので、血統成分に含めても含めなくても結果は変わらない（保留だったが、含めてよい根拠は「差がない」ことのみ）。

## 追記（2026-11-12）: 「パワー馬場でギアを上げた後に脚が切れない」の素点案の検証（芝、クッション値 ≤ 9.2）
ユーザー指示: 坂は考慮しない／パワー ＝ 馬場の意味だけ／対象は基本芝／クッション値ベース。コードは未変更（検証だけ）。
- 素点（1 走）: 最終 5 区間でギアを上げた走（1 区間の加速が 0.3 秒以上。パワー走の 54%）だけを採点。ピーク（最終 3 区間の最速）以降の衰え ＝ 最終区間 − ピーク（秒/200m。ピークが最終区間なら 0）を、コース偏差 → レース平均を引く → TS・ギアの量で調整 → 距離帯ごとに標準化し、高いほど「切れない」。
- 対象: 芝でクッション値のある走は 56,438 走（芝全体の 88%）、パワー走（≤9.2）24,346 走（1,833 レース・9,324 頭）。パワー・ギア上げ走が 3 走以上の馬は 1,593 頭、5 走以上は 429 頭。
- 再現性（偶奇分割・補正後）: 4 走 0.33、6 走 0.40、8 走 0.38（参考: TS 0.60〜0.68、ギア 0.33〜0.36）。中程度。
- 既存の軸との重複: 走ごとの相関は TS・ギアの量とも 0.00（調整で除いた）。馬ごとの平均では TS 0.04・持続力 0.14・ギア 0.23 で、独立性は十分。
- **父の系統区分との関係はない**: 国系統は日本型 +0.015±0.037、欧州型 −0.009±0.042、米国型 −0.029±0.136。欧州型の 4 区分も ±0.03 以内、小系統も有意なものなし（最大でディープ系 +0.049±0.045）。欧州型ミスプロ系は −0.024±0.076 で他と同じ。
- 名前の馬（走数が少なく参考）: オオバンブルマイ +1.82（2 走）、ハヤヤッコ +0.45（5 走）、ガイアフォース +0.39（3 走）、パンジャタワー +0.31（2 走）。テイエムスパーダ −3.86（1 走）。
- 結論: 軸としては成立する（再現性が中程度・既存の軸と独立）が、父の系統区分では予測できない。馬ごとの値は、パワー・ギア上げ走が 3 走以上の馬だけ出し、それ以外は不明にするのが妥当。血統成分を使うなら、母父・5 代血統の欧州系血量で別に検証する。

### 追記 2: 新素点が血統区分ごとの傾向として出るかのテスト（2026-11-12、芝・クッション値 ≤ 9.2・ギア上げ走）
- **(a) 父によるばらつき**（20 走以上の父 98 頭。級内相関 ICC。クラス・距離帯・場を調整）: 新素点 ICC 0.0105（F=2.27）、対照の TS（同じ走）0.0196（F=3.39）。父の効果は小さいが実在する（F 検定で有意）。TS の約半分。
  父を国系統ごとに分けても同じ（欧州型 0.0088、日本型 0.008、米国型 0.036＝父 14 頭）。区分の中のばらつきは区分の外と変わらない。
- **(b) 父・母父のうち欧州型の数（0・1・2 頭）別**: 新素点は −0.009±0.053 / −0.002±0.035 / −0.016±0.054 で**傾きなし**。TS は −0.063 / +0.017 / +0.056 と欧州血が多いほど少し高い（欧州型の芝・パワー走は TS が少し高めに出る）。
- **(c) 個別の種牡馬**（30 走以上の残差平均、SD 単位）: 高い側は ブリックスアンドモルタル（米国型・ストームバード系 331 走）+0.231±0.088、Kingman +0.300±0.291、ルーラーシップ +0.115±0.084、キズナ +0.108±0.072。低い側は アメリカンペイトリオット −0.490±0.293、マクフィ −0.363±0.294、ロードカナロア −0.151±0.096。欧州型でも ハービンジャー +0.020、ドゥラメンテ −0.004、モーリス +0.006 で、高い欧州型と低い欧州型が混ざる。
- **結論**: 新素点は測れる（再現性 0.33〜0.40、父の効果は実在）が、**smartrc の血統区分（国系統・大系統・小系統・欧州型の血の数）の傾向としては現れない**。出ているのは区分と無関係な種牡馬ごとの差（約 1%）。欧州瞬発力を欧州由来の血統の傾向とするなら、区分ではなく種牡馬・牝系の個別の情報（または別の素点）を探す必要がある。

### 追記 3: オオバンブルマイ・パンジャタワーの実走で、新素点が捉えられているか（2026-11-12、ユーザー指示「重馬場で最後まで衰えにくい TS の持続を見せている」）

- 2 頭の血統（smartrc）: オオバンブルマイは父 Discreet Cat（米国型・ストームバード系）× 母父 ディープインパクト（日本型）、パンジャタワーは父 タワーオブロンドン（欧州型・ミスプロ系）× 母父 ヴィクトワールピサ（日本型）。オオバンブルマイは**国系統では欧州型ではない**。ストームバード系は、検証で最も高かった種牡馬（ブリックスアンドモルタル +0.231）と同じ小系統。
