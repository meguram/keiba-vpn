# めぐサイクル（回収率 100% 超の買い方を探す 50 サイクル）

担当: megu-cycles。統括役: claude-orchestrator-handover。開始: 2026-11-23。

## 目的
重賞・平場のそれぞれで、選ぶ期間と確かめの期間のどちらでも回収率 100% 以上、かつ差の小さい買い方を探す。
条件の切り口だけでなく、賭けるべきでないレース・馬を避ける仕組み（期待値の下限・見送り）も試す。

## 固定した目標（config/megu_cycles/goal.json。サイクル 1 の前に commit b2d3ee69。途中で動かさない）
- 選ぶ期間（2017〜21）と確かめ（2022〜24）の両方で回収率 100% 以上。
- 確かめ ≥ 選ぶ期間 × 0.9。
- 確かめで年 50 件以上。
- 表に出す: 確かめの 95% 区間の下限（開催日で束ねたブートストラップ）、同じ人気の基準線との差。
- 重賞・平場のそれぞれに課す。重賞で件数が届かなければ「件数の壁」として記録する（緩めない）。

## 期間
| 名前 | 期間 | 使い方 |
|---|---|---|
| 学習だけ | 2016 | 自前の確率の最初の学習年（予測が無い） |
| select_a | 2017〜19 | サイクルの中で設定を選ぶ |
| select_b | 2020〜21 | 一次の確かめ（関門） |
| confirm | 2022〜24 | 関門を通った候補だけ。通算 10 候補まで。台帳 megu_cycles に confirm |
| final_once | 2025-01-01〜2026-11-20 | 50 サイクルの後に 1 回だけ |

## 判定に使う値
- 判定のオッズ: T-60 の再現（bet_cycles.load_drift と同じ作り）5 通りの平均。
  ずれの分布は 2026 年の発走前オッズと確定オッズの列だけを読む（着順・払戻は読まない）。過去の年に本物の発走前オッズは無い。
- 確率: 市場の列を使わない自前の確率（src/research/megu_cycles/mc_data.py。年ごとに前へ進める LightGBM。列は catalog の ALLOWED_COLUMNS から、めぐ指数を除く）。
- stage2・v6e の予測は確定オッズの offset を含み、上流が 2022〜24 を見て版を選んだので主にしない。使うときは「汚れた確かめ」と書く。
- 精算は確定の払戻（frame の ret_tan・ret_fuku）。

## 関門（2022〜24 に当てる前）
2017〜19・2020〜21 とも 100% 以上、2020〜21 ≥ 2017〜19 × 0.9、2020〜21 の市場比の 95% 区間の下限 > 1、2020〜21 で年 50 件以上、
並べ替えの帰無（区分 × 確定のオッズ帯の層で判定の列を入れ替える）で p ≤ 0.05。

## 道具
- `python -m src.research.megu_cycles.mc_data build`: 表と自前の確率（<MEGU_CYCLES_OUT>/runners.parquet）。
- `python -m src.research.megu_cycles.cycles run N`: サイクル N。結果は cycle_NN.json、所見は cycle_NN.md。
- `src/research/megu_cycles/mc_eval.py`: 成績・帰無・関門・確かめ（台帳）。
- サイクルごとの確率の版は `cycles.CYCLE_RICH`（4: v1・5: v2・6〜10: v4・11 以降: v5）。外す列の決まりは `mc_data.RICH_VERSIONS`。

## 記録
- cycle_NN.md: 仮説・設計・試した数・結果・2022〜24 に当てたか・合否・課題・次に生かすこと・打ち切る方向。
- lessons.md: 効かない方向・守る決まり。次のサイクルの前に読む。
- confirm_log.json: 2022〜24 に当てた候補の全件。
- trials.json: 試した数の通算。
