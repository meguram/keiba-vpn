# サイクル 18: 判定の時点を T-5 に（発走 5 分前の再現オッズ）

**結論: 関門を通った区分 平場。**

## 仮説
判定の時点を T-60 から T-5 に遅らせると、判定のオッズが確定に近づき（終盤の資金の情報が入る）、期待値の判定の雑音が減って回収率が上がる。運用は発走 5 分前の購入（自動の購入なら可能）。

## 所見
- 平場: combo・t 1.3・omax 50 で 2017〜19 139.3%（103〜179%）・153 件/年 → 2020〜21 149.5%（105〜198%）・170 件/年。市場比の下限 1.10。帰無 200 回で p 0.005。
  SmartRC の想定での 2021 年は 123.3%（86〜167%）・338 件。
- 第 2 段の重みは a 0.38・b 0.73（T-60 の 0.53・0.67 より市場が重い）。T-5 の市場は確定に近く、自前の確率の上積みは小さくなるが、判定の雑音が減る。
- 重賞は不合格（82.0% → 95.6%）。

## 割り引いて読むこと
- T-5 の再現は確定オッズに小さなずれを当てたもので、確定の並びの持ち込みは T-60 より大きい（楽観寄り）。見直しの感度でも、確定オッズで判定すると 2017〜19 は 130%。
- ずれの分布は 2026 年の t05 の記録（約 2,500 行）から借りる。
- 運用は発走 5 分前の購入（自動の購入なら可能。手での購入は難しい）。
