# サイクル 14: 単勝＋複勝（期待値で選んだ馬に半分ずつ）

**結論: 不合格（関門で落ちた）。2022〜24 には当てていない。**

## 仮説
単勝の期待値で選んだ馬（v5 の combo）に、単勝と複勝を半分ずつ賭けると、当たりの数が増えて区間が狭まる。複勝の払戻率の壁（約 80%）で回収率は下がるが、選んだ馬は複勝でも市場より当たる（サイクル 10 の市場比 1.2〜1.3）。

## 所見
- 平場: 110.9% → 101.6%。市場比の区間（0.91〜1.11）は単勝だけ（0.91〜1.31）より狭まったが、中心も 1.01 に下がり、下限は 1 を越えない。
- 重賞: 93.2% → 105.8%。2017〜19 が 100% に届かない。
- 複勝の側は控除の壁（約 80%）で、単勝の上積みを薄める。区間は狭まるが、中心も同じだけ下がる。

## 打ち切る方向
- 単勝の期待値で選んだ馬に複勝を足すこと（区間の幅と中心が一緒に下がる）。
