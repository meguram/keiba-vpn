# サイクル 24: s_* だけを外した v7（汚れた上流の列だけを外す）

**結論: 関門を通った区分 平場。**

## 仮説
サイクル 16 の落ち込みは、汚れた s_*（未来の年を含む上流の学習）ではなく、sr・f3 など（値は as-of、定数の当てはめが 2021 年末まで）を外したことによる。s_* だけを外した v7 でも c13 と同じ水準が出る。

## 所見
- v7 = v5 から s_*（3 列。上流で未来の年を含む学習）だけを外した版。sr・f3 など（値は as-of、定数の当てはめが 2021 年末まで）は残す。
- 平場: combo・t 1.3・omax 50 で 102.1% → 100.8%（年 750〜790 件・市場比の下限 1.03・帰無 p 0.03）。関門を通った。
  v5bag（c13: 103.2% → 104.5%）より少し低いが、効きの大半は s_* に頼っていない。v6（93.8%）の落ち込みは sr・f3 などを外したため。
- SmartRC の 2021 年 105.0%（804 件）。
- 汚れの一番少ない候補として c24_flat_v7 を 1 回だけ当てる（合格の線は c13 と同じ。当てる前に commit）。

## 次に生かすこと
- 確かめの「汚れ」のうち、s_* の分は小さい（2017〜21 で 1〜3 点）。sr・f3 の定数の当てはめ（2021 年末まで）は、2022〜24 には窓の外なので、確かめを有利にしない。
