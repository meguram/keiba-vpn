# サイクル 23: 判定の時点を T-15 に

**結論: 関門を通った区分 平場。**

## 仮説
判定の時点を T-15 にすると、T-60 と T-5 の間の成績になり、手での購入でも間に合う時点で 100% を越える。

## 所見
- 平場: combo・t 1.3・omax 50 で 125.4% → 126.9%（年 250 件・市場比の下限 1.08・帰無 200 回 p 0.005）。SmartRC の 2021 年 123.7%。
- 判定の時点と成績は単調: T-60（c13）103〜105% → T-15 125〜127% → T-5（c18）139〜150%。終盤のオッズほど確定に近く、判定の雑音が減る。
  同時に、確定の並びの持ち込み（再現の楽観）も時点が遅いほど大きい。
- T-15 は手での購入でも間に合う時点なので、運用の意味が大きい。候補 c23_flat_t15 として 1 回だけ当てる（合格の線は c13 と同じ。当てる前に commit）。
- 重賞は不合格（95.4% → 102.7%）。
