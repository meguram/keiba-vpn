# サイクル 4: 豊富な特徴量（1,231 列）の自前の確率 × T-60 の期待値

**結論: 無効（特徴量のリークが見つかったので結果を採らない）。2022〜24 には当てていない。リークを除いた作り直しはサイクル 5。**

## 仮説
サイクル 1 の確率は約 120 列で、市場に足す情報が無かった。本番のモデルと同じ 1,231 列（model-cycles の X_xgb.parquet。市場の列は名前で除く）で
年ごとに前へ進める XGBoost を作れば、確定の市場に足す情報が増え、期待値の判定が効く。

## 設計
サイクル 1 と同じ（rich・combo × t 5 通り × omax 3 通り × 2 区分 = 60）。

## 結果（採らない）
- 平場: combo・t 1.5・omax 50 で 2017〜19 145.6%（133〜158%）・1,254 件/年、2020〜21 105.3%（91〜120%）・893 件/年、帰無 p 0.03。
  関門は「2020〜21 が 2017〜19 の 0.9 倍未満」だけで落ちた。
- 重賞: rich・t 1.0・omax 20 で 86.3% → 96.5%。不合格。

## リークの見つけ方
1. 良すぎる: 2019 年の勝ち馬の対数損失が 1.943 で、確定の市場（1.962）より良い。市場の列を使わないモデルで、これは考えにくい。
2. 年ごとの第 2 段の重み（確定の市場に対する自前の確率の重み）: 2017 0.34・2018 0.53・2019 0.66・2020 0.32・2021 0.33。山が 2019 年にある。
3. 列の族を外すと: tl_*・wc_*・pxe・rb・zc・o_fld をまとめて外すと 2019 年の重みが 0.24 に落ちる（1 族ずつでは落ちない。同じ情報が複数の族にある）。
4. 確定の市場の残差（勝ち − 市場の勝率）とレース内の順位の相関を全列・年ごとに計った。
   tl_has_training（調教の記録の有無）は 2017 0.063・2018 0.094・2019 0.106・2020 0.001・2021 0.000。tl_*・wc_* が軒並み同じ形。rb_nk_* も 2018・19 だけ。
- 見立て: 過去の年の調教の記録は、後で取得した馬（走り続けた＝強かった馬）に偏る。「記録がある」こと自体が未来の情報になる。2020 年以降は記録がそろっている。

## 見つかった課題
- 上流の表の列は as-of の検査を通っていても、「データの取れ方」が未来に依存すると漏れる。年ごとの市場の残差との相関で見つけられる。
- 統括役へ報告した（model-cycles の学習の年に影響する。2022〜24 の評価のリークではない）。

- tl_*・wc_*・rb_nk_* を外して作り直す（サイクル 5）。
