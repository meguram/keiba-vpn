# サイクル 29: 確定オッズの見込みで期待値を計る（T-60 の順位ごとの平均のずれ）

**結論: 不合格（関門で落ちた）。2022〜24 には当てていない。**

## 仮説
T-60 のオッズは人気馬で確定より長く、人気薄で短い（終盤の資金）。期待値を、T-60 の人気の順位ごとの平均のずれで確定のオッズの見込みに直してから計ると、人気馬の過大な期待値を避けられ、回収率が上がる。

## 所見
- 平均のずれ（2026 年、T-60 の人気の順位ごと、log(確定/T-60)）: 1 番 −0.20・2 番 −0.21・3 番 −0.12・5 番 +0.07・8 番 +0.37・12 番 +0.73。
- 確定のオッズの見込みで期待値を計ると、人気薄の期待値が大きく見え、件数が 2 倍（年 1,600 件）になって回収率は下がった（平場 95.3% → 99.0%）。
- 平均のずれは「人気薄の確定オッズが長くなる」を当てるが、その分だけ勝ちにくい馬（市場が終盤に見放した馬）も含む。T-60 の生のオッズで計る方がよい。

## 打ち切る方向
- 期待値の計算を確定のオッズの見込みに直すこと。

## 注（批評の後）
- 平均のずれは、2026 年のレースを「確定の人気の順」に並べた値だった（bet_cycles.load_drift の races）。それを T-60 の人気の順位で引いたので、確定で人気になった馬の下げ幅を当てる形になり、補正が過大。仮説（T-60 の順位での補正）の検証としては不完全。打ち切りは、補正の向き（人気薄の期待値を大きく見せる）が上積みの源と逆向きで効かないという理由で保つ。
