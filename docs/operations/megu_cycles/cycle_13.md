# サイクル 13: v5 の学習の平均（3 本）× 期待値（サイクル 11 の設計）

**結論: 関門を通った区分 平場。**

## 仮説
v5 の確率を設定の違う 3 本の学習の平均にすると、1 本の学習の雑音が減って確率が鋭くなり、同じ期待値の水準で市場比が上がり、2020〜21 の市場比の区間の下限が 1 を越える。

## 所見
- 学習の平均（v5 の列、設定の違う XGBoost 3 本）。年ごとの重み 0.17〜0.33 で、v5（1 本）とほぼ同じ形。
- 平場で関門を通った: combo・t 1.3・omax 50。2017〜19 103.2%（93〜113%）・830 件/年 → 2020〜21 104.5%（92〜118%）・845 件/年。
  市場比 1.16 → 1.17（区間 1.08〜1.26）、帰無 p 0.03（30 回の下限）。SmartRC の想定人気での 2021 年は 111.6%（93〜133%）・886 件。
- 2017〜19 の区間の下限で選ぶ決まりのまま、1 本の学習（サイクル 11）の t 1.5（年 200 件）ではなく、t 1.3（年 830 件）が選ばれた。
  平均で確率の雑音が減り、t 1.3 の 2017〜19 の下限が上がったため。件数が 4 倍になり、市場比の区間が狭まった。
- 重賞: 89.9% → 96.0%。不合格。

## 別のエージェントの見直し（2026-11-24。結論: 条件付きで当ててよい）
- 判定のオッズの作り方で、2017〜19 の値が大きく動く（同じ凍結値で、確定オッズ 130.1%・ずれ 0.5 倍 113.3%・今の再現 103.2%・ずれ 2 倍 87.8%）。
  100% を超えるかどうかが、2026 年の 1 年だけのずれの大きさに依る。
- 窓の混ざり: sr・f3 などの当てはめ（FIT_END 2021-12-21）は選ぶ期間を水増しする向き。s_* の上流（EASE2・LAP）は未来の年を含む学習で、2022〜24 は「汚れた確かめ」。
- 選び過ぎ: 2020〜21 を何度も見た。勝者の呪いで −3〜5 点の目安。2022〜24 で 100% 以上は五分五分。
