# サイクル 20: 候補の中身の一貫性（選ぶ期間 2017〜21 だけ。探さない）

**結論: 効きは年・芝ダ・頭数ではおおむね一貫するが、クラスでは新馬・未勝利に偏り、オッズでは 10〜50 倍に偏る。設定は変えない。**

## 仮説
c13_flat・c18_flat_t05 の効きが本物なら、選ぶ期間の中のどの区画でも市場比が 1 を超え、一部の区画だけの偶然ではない。

## 結果（2017〜21、確定の市場に対する市場比。回収率）
| 区画 | c13_flat 回収率・市場比 | c18_flat_t05 回収率・市場比 |
|---|---|---|
| 2017 / 2018 / 2019 / 2020 / 2021 | 94・118・99・107・102%／1.12〜1.21 | 101・180・141・169・125%／1.28〜1.68 |
| ダート / 芝 | 102% / 106%（1.17 / 1.17） | 150% / 137%（1.57 / 1.27） |
| 新馬未勝利 / 1-2勝 / 3勝OP | 117% / 91% / 87%（1.19 / 1.18 / 1.01） | 171% / 86% / 107%（1.53 / 1.27 / 0.84） |
| 10 頭以下 / 11-14 / 15 頭以上 | 138% / 98% / 102% | 170% / 137% / 142% |
| 確定オッズ 3 倍以下 / 3-5 / 5-10 / 10-20 / 20-50 / 50 倍超 | 83 / 92 / 96 / 109 / 174 / 176% | 89 / 93 / 97 / 117 / 237 / 134% |

- 市場比は年・芝ダ・頭数のどこでも 1.1 以上。1 年・1 区画だけの偶然ではない。
- 回収率が 100% を超えるのは、新馬・未勝利と、確定オッズ 10 倍超の馬。1〜2 勝・3 勝 OP・人気馬は市場比 1 を超えても控除の壁を越えない。
- 根拠（公開の知見と整合）: 新馬・未勝利は走った記録が少なく、市場の情報が薄い。自前の確率は血統・調教・陣営の値で、その薄さを補う。
  人気薄で上積みが大きいのは、本命・大穴の偏りで人気薄の市場の確率が低く見積もられ、そこへ自前の確率が勝ちの見込みを足すため。

## 次に生かすこと
- 新馬・未勝利に絞る案は理屈が立つが、ここで 2017〜21 の群ごとの値を見たので、2020〜21 で確かめるのは汚れる。絞る案を作るなら、2017〜19 だけで決め、関門の汚れを記録する。
- 試した数: 0（探さない検査）。区画ごとに 2020〜21 を見たので、2020〜21 を見た回数に 1 を足す。
