# サイクル 49: 勝ち目の薄い馬を避ける（組んだ確率の順位も上位）

**結論: 不合格（関門で落ちた）。2022〜24 には当てていない。**

## 仮説
期待値が高く見えても、組んだ確率のレースの中の順位が低い馬（オッズの長さだけで期待値が高い馬）は、確率の推定の誤差の影響が大きい。組んだ確率の順位が上位（3・5 位以内）の馬だけを買うと、誤差に強くなり回収率が上がる。

## 所見
- 順位 5 位以内・t 1.3 で 101.6% → 98.4%。c13（順位の制限なし、103.2% → 104.5%）より低い。
- 上積みは人気薄（順位の低い馬）にあり（サイクル 20）、順位で絞ると上積みの源を捨てる。期待値の誤差に強くする狙いは、回収率を下げた。
## 打ち切る方向
- 組んだ確率の順位で絞ること。
