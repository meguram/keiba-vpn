# サイクル 42: 人気騎手・人気厩舎の過剰人気（市場 + 騎手・調教師の成績だけ）

**結論: 不合格（関門で落ちた）。2022〜24 には当てていない。**

## 仮説
人気騎手・人気厩舎の過剰人気（公開の知見: 有名な騎手の馬は売れ過ぎる）。自前の確率を使わず、T-60 の市場と、騎手・調教師の as-of の勝率だけの第 2 段（条件付き logit）で、市場が騎手・厩舎の名前に払い過ぎている分を取り除くと、期待値の判定が効く。

## 所見
- 平場の第 2 段の係数（標準化）: 市場 1.14、騎手の勝率 +0.02、調教師の勝率 +0.05。符号は「市場が人気騎手・厩舎を少し低く見る」側で、過剰人気ではない。大きさも小さい。
- 平場は期待値 1.05 以上が年 20 件しかなく、回収率 75%。重賞は 87.5% → 68.6%。
- JRA の今の市場では、騎手・厩舎の名前への払い過ぎは見えない。

## 打ち切る方向
- 騎手・厩舎の成績だけで市場を直すこと（自前の確率なし）。
