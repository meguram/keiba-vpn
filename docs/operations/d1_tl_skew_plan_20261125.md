## 段 1（〜12/5）: 動きの見積もり（着順を結ばない・0 円・GCS を読まない・nice 19）
- 行は 2 つ。
  - ① 2022〜24 の OOF の行（束の学習の中の行。木のモデルは反応が小さく出やすい）。
  - ② 2026-10-18 以降の本番の写しの X。X_full（発走後の記録で作った）と X_served（推論で実際に見えた）の 2 通り。学習に使っていない行で、本物の T-60 がある。台帳には特徴量の読みとして申告する。
  - ① と ② が 2 倍以上違えば、大きい方で判定する。
- 束は学び直さない。本番 v6e の束 → 第 2 段（stage2_noise と同じ係数）に、元・E0・E0'・E1 の X を入れて比べる。
- r は凍結 r2 の定義（log(p/q)、q は T-60 の市場。① では確定の人気か T-60 の再現の人気になるので、両方で出す）で、q は元のまま固定する。§77 の q̂ の変化は、r と別の表にする。
- 出すもの
  - v6e の p: log p の相関、レース内の KL（中央値・90 分位）、◎ の入れ替わり率。人気帯別（1・2〜3・4〜6・7〜9・10 以下）の Δlog p と |Δp| を、符号つきの平均・90 分位・区間で出す。
  - 凍結の規則にそろえた数（未勝利・新馬、2 番人気以下・p ≥ 5%）: 買う／見送るの入れ替わり率、◎ の入れ替わり、5% をまたぐ馬の数、区切り 0.492 を越える率の差、選ばれた馬の Δr の平均。新馬・未勝利・その他に分ける。
  - §77 の q̂: log q̂ の相関、KL、人気帯別の |Δq̂|、想定人気の 1 位の入れ替わり。R0-14 の ε の層分け（追い切りの空の多さ）のための値も渡す。
  - 列の族に分けた寄与: w1_・w2_ だけ／本数に依る列だけ／両方。
- 雑音の床: 元の X のまま、束の seed の違う半分どうしで同じ量を出す（作れない場合は代わりを記録する）。

## 予測（数字を見る前に書く）
- 2 号: 推論で全馬が「1 週前が空の馬」に見えるので、p がレースの中で平らになると予測する（本命の p が下がり、大穴の p が上がる）。その結果、2 番人気以下の r が上がり、区切りを越えるレースが増える。
- 2 号: 市場は 1 週前の追い切りを木曜には見ている。だから w1_ を外しても、市場に対する上乗せはあまり減らない。

## 判定（判定は E0' で行う。E1 は参考）
- 「小さい」（全部を満たす）
  - ◎ の入れ替わり ≤ 3%、かつ雑音の床の 1.5 倍以下（KL の中央値も雑音の床の 1.5 倍以下）。
  - KL の中央値 ≤ 0.005、かつ 90 分位 ≤ 0.02。
  - 人気帯別の |Δlog p| の中央値 ≤ 0.05。
  - 1 番人気の |Δp| の平均 ≤ 0.005。
  - 凍結の規則の対象で、買う／見送るの入れ替わり ≤ 5%（既知の経路のずれは 16%）。
  - r が 0.492 をまたぐレース（R3 の定義。② で数える）≤ 1%。
  - §77: 想定人気の 1 位の入れ替わり ≤ 2%、KL の中央値 ≤ 0.005。
- 「大きい」: 次のどれか。このときは段 2 を前倒しする。
  - ◎ の入れ替わり ≥ 10%
  - KL の中央値 ≥ 0.02
  - 0.492 をまたぐレース ≥ 3%
  - 買う／見送るの入れ替わり ≥ 10%
- 「中くらい」: その間。段 2 を 12 月前半に進める。
- ① と ② で判定が割れたら、重い方を採る。
- 閾値は段 1 の後に動かさない。

## 段 2（段 1 の後。12 月前半の平日）
- 採る案は、数字を見る前に仕組みで決める。
  - 「載せていない」場合: E1 の規則が写しで確かめられれば (1) そろえる、確かめられなければ (2) 外す。
  - 「取り方で落としている」場合: 取り方を直す。学び直しは急がない。
- 対数損失は「元の版より悪くないか」の確かめにだけ使う。悪化が seed の幅を超えたら止めて、会議に戻す。
- 測り方
  - 元・(1)・(2) の 3 版とも、検証の行は発走前の見え方の X（E0' か E1）で測る。
  - 元の版を元の X で測った値は「過去の開発の値の甘さ」として別に出し、比べには使わない。
- 期間: 2022〜24 の v6e の勝ち馬の対数損失だけを使う（1 号の判断: v6e にとってはすでに選んだ側の期間なので、会議の 0/3 は減らない）。
  - 払戻・回収率は結ばない。2020〜21 は補助として並べる（無観客期の注記を付ける）。2025・26 は使わない。台帳には開発の検証 1 回と記録する。
- seed は各版 3 本以上。区間は開催日で束ねたブートストラップで出す。
- 第 2 段も同じ X で学び直す。市場だけに対する上乗せと、p の重み α の変化を出す。
- 区切り 0.492 を値のまま使うか分位で決め直すかは、段 2 の前に会議で決める。決め直すなら、試した数に数える。
- §77 は段 2 で触らない（R0-13 の 1-3）。入力を空にする扱いは会議の側で行う。
- 過去の v6e の開発の値は、ずれの分だけ甘かった恐れがある。段 1 の結果にかかわらず、lessons に記録する。

## R3 の決定（1 号、2026-11-25。この節を正とする）
decisions.md への転記は、会議の担当がこの節から行う。
1. 段 0・段 1 に進んでよい。ただし次の 3 点を、この版で直した。
   - 「r が 0.492 をまたぐレース」は、「凍結の規則の対象の馬のうち、1 頭でも判定（区切りの上か下か）が変わったレース」とする。
   - ①（2022〜24）の行で確定の人気から作った r は、参考の扱いにする。r と買う／見送るの判定は、本物の T-60 がある ②（2026-10-18 以降）で行う。① は p・KL・◎ の入れ替わりの判定にだけ使う。
   - ② は特徴量とオッズだけを読み、着順・払戻は結ばない（台帳は KEIBA_SESSION=model-improve-cycles）。買う／見送るは、入れ替わりの数だけを数える。
   - 段 0 で rc6 の入口の条件がすでに破れていると分かったら、段 1 の前に 1 号に上げる。
2. 凍結・前向きの版（prereg_2026_r2 の v6e の参考の群、rc6 の p_rich）には、満期まで D-1 を当てない。
   - 直した版は、α を配らない影の列にする。
   - 入口の条件が破れていても、版は替えない。記録に「入口の条件の外」と札を付け、別の議題で扱う。
3. 閾値は v2 のままで固定する。そのうえで次の 2 点を足す。
   - 雑音の床の比べは、◎ の入れ替わりと KL の中央値の両方に当てる（「小さい」は、どちらも雑音の床の 1.5 倍以下）。
   - 予測（p が平らになる）は合否の線にしない。成績表に当たり外れを記録するだけにする。
4. 影で並べる日数は N = 6 開催日。切り替えの線は、着順・回収率を使わない次の 4 つで決める。
   - (a) 新しい版で、学習と推論の空の割合の差が、tl_ の族ごとに 5pt 以内。
   - (b) 推論の p と、学習と同じ作りの X で出した p との差（mean_abs_dlogp）が、旧版より 50% 以上縮む。
   - (c) 6 日とも失敗が 0 件で、出す時刻の遅れが旧版と同じ程度。
   - (d) 新旧の ◎ と、買う／見送るの入れ替わり率は記録だけにする。10% 以上なら、統括役に上げるときに明記する。
   - 影の 6 日間の 2026 年の対数損失・回収率は、判断に使わない。
   - 新しい版は、今の影の実行の中で計算する（回数を増やさない。増やすなら円に直して統括役へ出してから入れる）。
   - 切り替えは平日だけ。§77 の develop 入り・門 R・12/10 の学び直しとは、別の週にする。
   - 切り替えの後も、前向きの版は満期まで旧版のまま記録する。
