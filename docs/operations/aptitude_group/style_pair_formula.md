# 脚質の近さの係数を組の確率の比に直す式（pair-bets へ渡す・12/4 の A の門の 1 行）

2026-11-27・担当 aptitude-group。rules-council の 1 号の判断（develop の f3ca9799）に従い、数値を出す前に式だけを固定する。
**+0.045 は探す側の結果を見た後の値で、確かめの証拠にしない。** 判定は rules-council、計算は pair-bets。

## 元の値（記述・探す側 70%・2017〜24 年・単勝の確定オッズからの見込み）

- 2・3 着の段の条件付きロジットの組の項 `style_close = −|style_j − style_先|` の係数 β = +0.045（1 sd あたり・開催の束ねの SE 0.009）。
- 1 sd = σ = 0.190（style_close の 2 着の段の行での sd）。
- style = その馬の前 3 走の 4 角の位置の割合 (4 角の順位 − 1)/(頭数 − 1) の平均（0 = 先頭・1 = 最後方。前走が無い馬は 0.5）。作りは `src/research/aptitude_group/vector.py::pre_race`。

## 式

レース r の 2 頭 i・j について、発走前に分かる style だけで作る。

1. 近さ: `c_ij = −|style_i − style_j|`。
2. i が先に来たときの、j の 2 着の確率の倍率（i の他の相手と比べて）:
   `ρ_j|i = exp(β·c_ij/σ) / mean_{k ≠ i} exp(β·c_ik/σ)`（k はレースの i 以外の全頭）。
3. 馬連（i・j が 1-2 着）の組の確率の比: `ρ_ij = (P_i·P_j|i·ρ_j|i + P_j·P_i|j·ρ_i|j) / (P_i·P_j|i + P_j·P_i|j)`。
   - P は単勝からの Harville（P_j|i = q_j / (1 − q_i)）。
   - ρ_ij は、単勝から作った組の確率に対して、脚質の近さが組の確率を何倍にするかを表す。
4. ワイド（2 頭とも 3 着内）は、3 着の段で 1・2 着との近さの平均を使う形なので、近似として `ρ_ij^½` を上乗せの下限、`ρ_ij` を上限として両方を出す。

## 大きさの目安（式だけ・結果ではない）

- β/σ = 0.045/0.190 = 0.237。脚質がまったく同じ組（c = 0）と、差が 0.5 の組（c = −0.5）の比は exp(0.237 × 0.5) ≈ 1.13。
- 1 つのレースの中では、ρ の幅はおおむね 0.9〜1.1。

## pair-bets で見てほしいこと（判定の前の形）

- ρ_ij の帯（例: 上位 1/4・下位 1/4）ごとの、馬連の確定オッズ m に対する A/E。
- 問い: 組の市場 m は、脚質の近さの相関を織り込んでいるか。織り込んでいれば、m に対する A/E は帯で変わらない。
- 控除の線（m に比例して買うときの A/E 約 1.29）と比べる。ρ の幅が 0.9〜1.1 なので、届く見込みは低い。この見込みも先に書いておく。
- 確かめに使う行（12/4 の門の分け・前向きの記録）は rules-council が決める。aptitude-group の探す側 70%（split_search70_race_ids.txt）は、+0.045 を見た行なので確かめに使わない。
