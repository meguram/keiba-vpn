OPERATIONS · SERVER ARCHITECTURE

サーバーアーキテクチャ

keiba-vpn のローカル開発〜stg 運用で動いている全サーバーコンポーネント（FastAPI / Flask / Next.js / MLflow / PostgreSQL / Redis / GCS）の役割・ポート・起動方法をまとめたページです。 起動コマンドの詳細は docs/operations/service-endpoints.md、ディレクトリ構成は docs/operations/PROJECT_LAYOUT.md を参照してください。

全体構成図

ブラウザ │ ├─ http://127.0.0.1:3001 Next.js (stg) ──/api/v1/*──►┐ ├─ http://127.0.0.1:3000 Next.js (dev mock) │ ├─ http://127.0.0.1:8000 FastAPI（Jinja2 UI + レガシー REST） │ │ └─ http://127.0.0.1:5000 Flask /api/v1（仕様準拠 REST）◄┘ ※既定ポートは MLflow と衝突 推論・学習 ├─ MLflow Tracking :5000 （Flask の既定ポートと同じ → 片方を移動） └─ MLflow Model Serving :5001-5006, :5010 データ基盤 ├─ PostgreSQL :5432 （Layer 1〜5 / predictions） ├─ Redis :6379 （予測キャッシュ L2〜L4） └─ GCS gs://<bucket>/chuou/... （生データ SSoT・非 HTTP）

仕様上の正

DEC-013 により Flask /api/v1（:5000）が仕様上の正。FastAPI（:8000）は Jinja2 UI・管理画面・レガシー /api/* を担い、段階的に廃止予定です。

起動方法

一括起動（推奨）

# dev — Next.js モックのみ（API不要）
./service_start

# dev 実API開発（ホットリロード）
./service_start --env dev --full

# stg — 本PC上の本番相当（実API・GCS・DB）
./service_start --env stg

# prod プロファイル
./service_start --env prod

# 状態確認
./service_start --status

個別起動

# FastAPI
python main.py --host 0.0.0.0 --port 8000 [--prod]

# Flask（ポート衝突時は FLASK_PORT を変更）
FLASK_PORT=5100 python main.py --flask-api

# Next.js
cd frontend && npm run dev -- -p 3001

# Watchdog（FastAPI + MLflow を監視・自動再起動）
./scripts/server/server_watchdog.sh

ヘルスチェック

# FastAPI
curl -s http://127.0.0.1:8000/api/health | python3 -m json.tool

# Flask（ポートを変更した場合は番号を合わせる）
curl -s http://127.0.0.1:5100/api/v1/health | python3 -m json.tool

# Next.js（200が返れば起動済み）
curl -s -o /dev/null -w "HTTP %{http_code}\n" http://127.0.0.1:3001/

# リッスン中ポート一覧
ss -tlnp | grep -E ':(3000|3001|5000|5001|5010|5100|5432|6379|8000)\s'

運用ノート / 既知の問題

⚠ ポート 5000 は他プロジェクトと衝突しやすい

このマシンでは 別プロジェクト（daily_news）の src/app.py が常時ポート :5000 を占有していることがあります。 Flask 起動時に Address already in use が出た場合、まず ss -tlnp | grep :5000 でプロセスの出自を確認し、無関係なプロセスなら keiba-vpn 側を FLASK_PORT=5100 等の別ポートで起動してください（他プロジェクトの常駐プロセスを誤って kill しない）。 Next.js から Flask へ向ける場合は KEIBA_API_URL=http://127.0.0.1:5100 を合わせて設定します。

⚠ frontend/node_modules が壊れたシンボリックリンクになっている場合がある

frontend/node_modules が実体ではなく /tmp/<tmpdir>/node_modules のようなシンボリックリンクになっていて、リンク先が /tmp のクリア等で消えていることがあります（service_start.sh の frontend_node_modules_ok チェックに失敗し、フロントエンドが無言で起動しない）。 その場合はリンクを削除して npm install を実行し、実体の node_modules を作り直してください。 

cd frontend
rm node_modules
npm install

⚠ MLflow Tracking（:5000）と Flask（既定 :5000）はポート競合する

同時起動する場合は Flask を FLASK_PORT=5100 等に変更するか、MLflow を Docker 内のみに閉じてホスト側 Flask を :5000 のまま使う。

起動後チェックリスト

  • FastAPI: GET /api/health が 200
  • Flask: GET /api/v1/health が {"status":"ok"}
  • Next.js: トップページが 200 で返る
  • PostgreSQL / Redis の警告が出ていないか（出ていれば別途起動）
  • 意図しないポート衝突（他プロジェクトの常駐プロセス等）がないか ss -tlnp で確認
