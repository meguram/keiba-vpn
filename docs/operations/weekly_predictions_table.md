# めぐAI の週の予想（/weekly-predictions）の AI 予測の表

最終更新: 2026-11-16（成長度のバッジも外した）。実装: `frontend/app/weekly-predictions/page.tsx` の `PredTable`（この画面だけの部品。レース詳細 `/race/[id]` の表とは別）。

## 列（7 つに絞った。2026-11-25 に印を足して 8 つ）

ユーザーの依頼（2026-11-16）で、表の列を次の 7 つにした。

| 列 | 中身 | 並べ替え |
|----|------|----------|
| 枠 | JRA の枠の色の四角（`lib/bracket.ts` の `bracketChipStyle`） | 枠番 |
| 馬番 | 太字の数字（色は枠で示すので付けない）。未確定の段階は `-` | 馬番 |
| 印 | ◎○▲★△消（2026-11-25 に追加）。匿名・無料会員には予測の数値の代わりに印だけが来る（`tiered_access.md`）。title は `mark_source` で「無料のAI印」「めぐAI印」 | ◎ > ○ > ▲ > ★ > △ > 無印 > 消（もう一度押すと逆） |
| 馬名 | 押すと情報パネル（近走・血統・追い切り・成長曲線、騎手・調教師のタブ）。馬名の横の印やバッジは付けない | 馬名 |
| AI勝率 | `win_prob` | 勝率（大きい順から） |
| AI複勝率 | `top3_prob` | 複勝率（大きい順から） |
| オッズ（予測 単/複） | 1 列に 2 段。上段=単勝 `win_odds`、下段=複勝 `place_odds_min`-`place_odds_max`。100 倍以上は小数を落とす（列幅に収めるため） | 見出しは単勝。複勝は「そのほか」から |
| 期待値（単/複） | 1 列に 2 段。上段=単勝、下段=複勝（較正後 `ev_*_cal` があればそちら） | 見出しは単勝。複勝は「そのほか」から |

- 単勝・複勝は 2 列に分けず **1 列に 2 段** にした。390px の幅で横スクロールなしに収めるため（2 列に分けると 9 列になり、馬名が 4〜5 文字しか出ない）。
- 匿名のときは、オッズ・期待値の見出しの下段に 🔒 を付ける（値はサーバが落としていて `-`）。
- 並び替えバーの選択肢は、表に出している値だけにした（見えない列で並ぶと何順か分からないため）。

| 外した情報 | 見られる場所 |
|-----------|--------------|

| 成長度のバッジ（大きく成長・成長・横ばい・やや停滞・下降、押すと理由） | **どの画面でも見られない**（ユーザーの依頼で 2026-11-16 に外した）。馬名の情報パネルの「成長曲線」は別の情報（指数の推移と上昇中・下降中の傾き）で、こちらは見られる |

  API の `growth`・`growth_meta` と `lib/growth.ts`（テストあり）はそのまま残している（表示を戻すときに使える）。
- 印（◎○▲△★消）と取消はもともとこの表に出していない（印は推奨馬券・レース詳細、取消は出馬表の段階の表示 `EntriesStatusBadge`）。
- 表の下に一行の説明（上段=単勝・下段=複勝、色の意味、外した情報の見る場所）を置いた。

## 見やすさ

- 数値は右寄せ・`tabular-nums` で桁をそろえる。オッズの「倍」は付けない（見出しで示す）。
- AI勝率・AI複勝率は、そのレースの最大を基準にした細い棒をセルの下辺に出し、最大の馬は太字にする。
- 期待値は 1.00 以上を太字＋色（青）。較正後の値は 1.10 以上を緑・0.90 未満を赤、較正なしの値は 1.20 以上を緑・0.80 未満を赤（`fmtEv`）。総合順位の上位 3 頭は行をうっすら色付け（従来どおり）。
- 幅: どの幅でも同じ表（以前の「広い表・中間の表・スマホのカード」の 3 つは 1 つにした）。表の最小幅は 360px（印の列 20px を足した。2026-11-25）で、390px の端末では横スクロールなし。さらに狭い端末では表の枠の中だけ横に送れ、枠・馬番・印・馬名は左に固定（sticky）。769px 以上は列幅と文字を広げ、表の幅は 880px まで。
- 色はサイトの変数（`--text`・`--border`・`--surface`）を使う。**サイトはダークの配色だけ**（`prefers-color-scheme` や `data-theme` が無い）なので、表だけのライトの配色は作っていない。サイトにライトの配色ができたら変数で追従する。
- 並べ替えは独自に持つので、共通の `TableSorter` は効かせない（`<table data-no-sort>`）。

## 費用・ほかの画面への影響

- フロントの表示だけの変更。API の応答・計算・呼び出しの回数は変えていない（費用 0 円）。
- `PredTable` はこの画面だけの部品。共通の `lib/bracket.ts`・`EntryCardPanel` は変えていない。
- `GrowthBadge` は消した（この画面だけで使っていた）。
- `globals.css` は、消したスマホのカード表示（`.pt-card`・`.pt-bar i`）向けの規則だけを消した。ほかの画面は変わらない。
