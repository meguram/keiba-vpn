# R0-12 足切りの研究（下限 × 印・買い目）に入れる依頼の控え

資料の本体は 12/14 まで（1 号の決定）。この控えは、資料を作るときに入れる依頼を、来た順に残す。

## 1. 元の依頼（2026-11-25、統括役経由）

- 段 A（足切り）: AI の勝率か複勝率が下限以上の馬だけを候補にする。下限は、勝率 {5,8,10,15%} × 複勝率 {20,30,40%} を上限とする格子で動かす。
- 段 B（候補の中の最適化）:
  - 印は最適化しない（ユーザーが R0-10 で (a) を選んだため）。印は v2 のままとし、下限ごとの印の成績は記述にする。
  - 買い目は検定の対象にする。
- 70% は門 0 の模擬を通ったときだけ見る（通算 10 回目）。30% と 2025・26 年は使わない。

## 2. 追加の依頼（2026-11-25、統括役経由）: 変則的な買い方も網羅する

- ユーザーの文: 「3 連複や 3 連単は、◎-○▲★-印全部 でフォーメーションを組んだり、★ を好走が期待できる穴馬に置いて、★-◎○▲ にワイドや馬連で流すことも、よく見受けられる。そのような変則的な買い方まで網羅してほしい」。
- 印を使った買い方の目録を作り、すべて同じ物差し・同じ決まりで試す。決まりは、発走前の値だけ・開催 70/30・2025・26 は最後に 1 回・検出力の模擬・帰無・全部買った基準線・試した数の割引き。
  - 3 連複・3 連単のフォーメーション: ◎-○▲★-印全部、◎○-○▲★-印全部、◎-○▲-○▲★△ など。
  - 穴の軸: ★-◎○▲ のワイド・馬連・3 連複の 1 頭軸。
  - ◎ と ★ の 2 頭軸。印の数で点数を変える形。
  - 見送りの条件: 点数・合成オッズ・印の頭数。
- ★ の定義:
  - 印の決め方（全レースに AI の評価の順で印。★ は 1 号の決定）と整合させる。
  - ★ の選び方の違いは、研究の中だけの目録の軸にしてよい。画面の印の決め方は (a) のまま変えない。
- 前の研究の使い回し:
  - bet-patterns が ◎ 固定で試した組み方（docs/html/operations/final/bet_patterns_from_honmei.html、約 2.6 万通り）と重なる所は、結果を使い回す。
  - その数は、通算の試した数に入れる。
- 基本理念 0-0:
  - 各買い方の「なぜ効くはずか」を先に書く。
  - 例: ★ が穴の軸として効くなら、AI が市場より高く見ている中穴の馬が連に絡む割合は、市場の見込みより高いはず。

## 3. 担当のメモ（資料を作るときに見ること）

- 試した数は、2.6 万通りと合わせると非常に大きくなる。目録は、説明の書ける形だけに絞る。理由が書けない形は、目録に入れない（基本理念）。
- 券種ごとの控除率（単勝・複勝 20%、馬連・ワイド 22.5%、3 連複 25%、3 連単 27.5%）で、損益分岐に要る倍率が変わる。券種ごとの要る倍率の表を、先に作る。
- 3 連系の市場の確率（q）は、単勝から Harville などで換算するしかない（発走前の 3 連系のオッズの写しは無い）。換算の偏りを注記する。

## 4. ユーザーの念押し（2026-11-25、統括役経由）: 組み方にも基本理念を当てる

- 券種・組み方（フォーメーション・流し・ボックス・軸の置き方・点数・見送り・資金配分）にも、0-0 を同じ強さで当てる（protocol.md の 0-0 に 1 行足した）。
- 各組み方について、数字を見る前に「なぜこの券種・この形を選ぶのか」を書く。
  - 例 1: ◎ の勝率は高いが、単勝は人気で割に合わない。そこで連に広げて配当を取る。
  - 例 2: ★ は勝ち切れないが、連に絡む。そこで軸にはせず、相手に置く。
- そこから導ける予測（どの帯・頭数・クラスで効くはずか）を確かめる。
- 理由を言えない組み方、結果を見た後にしか理由が書けない組み方は、成績が良くても採らない。成績表の「なぜ効くのか」の列も、組み方ごとに置く。
- bet-patterns の約 2.6 万通りのうち、理由を書けない形は目録に入れない。試した数には、通算として数える。
