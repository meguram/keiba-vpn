- ユーザーの答え（統括役から、11/25）: 「Benter の 2 段を許す」。

  - 判定に確定オッズは使わない。
  - 自前の確率は、市場の列と偏りのある列（tl_*・wc_*・rb_*・mtl_* など、megu-cycles の lessons）を外したもの。
  - ほかの決まり（事前登録・検出力の模擬を先に・帰無・基準線・試した数の割引き・開催 70/30・2025・26 は最後に 1 回・GCS を読まない・開催日の日中は止める）はそのまま。
  - megu-cycles の c13〜c24 は同じ系統。その結果（2022〜24 を見た回数・楽観の倍率 s*: T-60 0.86・T-15 1.04・T-5 1.62）を、通算の割引きと前提に入れる。
  - 前向きの記録の道具（和集合の台帳）も、11/28・29 の日中を避けて進めてよい。
- 決めたいこと（反対役は 3 号の番）:

  3. 作り（確率・市場との組み方・区切り・母集団・2 段の門・検出力の模擬・合否の線）。

## 2. 前の決定と、同じ系統（megu-cycles）がすでに見たもの
- 本会議: RC-0〜RC-5 と (b)。オッズを使わない公開の情報は、どれも要る倍率に届かなかった。要る倍率は、オッズを使わないルールで「損益分岐 ÷ 帯の比」（一桁で約 1.27）。オッズを使う案では、さらに s* で割る（RC-3 の判断）。
- megu-cycles（50 サイクル、docs/operations/megu_cycles/）:
  - 自前の確率: rich_pred_v5bag（v5 の 1,083 列。tl_*・wc_*・rb_*・mtl_* を外す。XGB 3 本。年ごとに前へ進めて学ぶ）。2016 年は予測が無い。
  - 組み方: p ∝ exp(a·log p_rich + b·log q_pre)。c13 の a = 0.53・b = 0.67 は、2017〜19 の平場で当てはめた値。
  - 区切り: t = 1.3・50 倍以下（全部の候補で同じ）。
  - 期間: 2017〜19 で選び、2020〜21 で選び直しの関門、2022〜24 で確かめ（通算 10 候補まで。5 候補を最後に残した）。
  - 2025 年に 1 回だけ当てた結果（docs/operations/megu_cycles/final_once.json）: c13（平場・T-60）96.7%（609 点）、c18（T-5）131.0%（87）、c21（新馬未勝利・T-60）124.6%（208）、c23（T-15）141.7%（142）、c24（v7）98.6%（579）。
  - 楽観の倍率 s*（docs/operations/megu_cycles/drift_check.json。本物の T-60 の 2026-10-18〜11-20 の 280 レースと、再現の q の対数損失を合わせる倍率）: T-60 0.86・T-15 1.04・T-5 1.62。s* で読んだ 2017〜21 の回収率の見積もりは、c13 1.07・c21 1.27・c23 1.26・c18 1.18。
  - 前向きの計画: docs/operations/megu_cycles/forward_plan_c21_c23.md（担当 bet-optimizer）。2026 年は X_xgb に行が無く、確率を作るには、開催日の後に as-of の特徴量を作る再生が要る（モデルの本体は保存されていない）。

## 3. 事実（本会議の道具から）
- めぐの候補 c13 の買い目は、探す側 70% の 3 分の 2 が一桁（(b) の数え直し）。2017〜24 の買い目（再現 5 本のうち 1 本でも買う行）は 15,548。
- RC-1: 再現の T-60 の母集団は、本物の T-60 と分布・向きが合う（1 頭ごとの一致は乱数の床）。
- 開催 70/30 の分け方（種 20261124）は、2016〜24 の全年を両側に持つ。確かめの側 30% は、RC の候補の検定に 1 回も使っていない。ただし 2022〜24 の行は、めぐの確かめで集計として見ている。
- 通算（本会議）: 探す側 70% の着順を 5 回（RC-2 の 2・RC-3 の記述 1・RC-4 の 2）。確かめの側 30%: 候補の検定 0 回（当日の偏りの族だけ記述で汚れ）。2022〜24 の枠: 0 / 3。2025・26: 0 / 1。

## 4. 候補の作り（担当の案。決めるのは 1 号）
- 案 A（本会議の分け方での確かめ直し）: c13 と同じ作り（v5bag の確率・条件付き logit・t・50 倍以下）を、a・b・t を探す側 70%（2017〜24）だけで当てはめ直し、確かめの側 30% に 1 回当てる。2 段の門（帯の比 → 損益分岐）と並べ替えの帰無（レースの中で自前の確率を入れ替える）。
  - 弱み: 30% の 2022〜24 の行はめぐが見ている。t = 1.3 と「50 倍以下」は、めぐが 2022〜24 まで見て選んだ値。
- 案 B（ルールで表す Benter）: 自前の確率の代わりに、目録の水準の点数（RC-2 の 12 水準など）を、T-60 の市場の logit に足す。係数は探す側で 1 回だけ推す。
  - 弱み: RC-2・RC-4 で、水準の効きは ×1.10 以下（上側でも 1.33）と分かっている。
- 案 C（前向きの記録）: めぐの c21・c23 の再生の台帳（bet-optimizer の plan）と重ならない形で、本会議は和集合（RC-2）の台帳だけを作る。
- 案 D（判定の時点）: s* が T-15 で約 1、T-5 で 1.62 と大きい。判定を T-15 にした版の検出力と、本物の T-15 の期間の量を先に数える。

## 5. 楽観の元
- 再現の T-60 は、確定の人気の順位でずれを当てる（教訓 12）。s* 0.86 は 280 レースからの値。
- a・b・t・50 倍は、めぐが 2017〜24 を何度も見て決めた。同じ系統の通算の試した数（trials.json）を割引きに入れる。
- 自前の確率は年ごとに前へ進めた予測で、学習の外の年の行には先読みが無い。ただし列の選び方（v5 で外した列）は、2020〜21 の結果を見て決めた版がある（lessons 9・10）。
