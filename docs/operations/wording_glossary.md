# 利用者に見える文言の用語集（ギャンブルを助長しない言い方）

画面・API の表示用の文言・コラム・公開サイトで使う言葉の決まり。2026-11-25 に決めた（ユーザーの依頼「『馬券推奨』は避けて『サンプル買い目』などに」）。
広告（Google AdSense の審査・ポリシー）の準備も兼ねる（`docs/operations/ads_architecture.md`）。

- 対象は利用者に見える文字列だけ。コードの識別子・API のパス・JSON のキー・ファイル名は変えない（壊れるため）。
- 数字・機能・集計の意味は変えない。
- 運用者だけが見る Slack の通知（`src/scripts/data/daily_results_notify.py`・`src/scripts/ops/race_ready_notify.py`）と、開発用のポートだけで出る `templates/` は対象外。
- 新しく文言を書くときもこの表に従う。

## 言い換えの表

| 避ける言い方 | 使う言い方 | 補足 |
|---|---|---|
| 推奨馬券・推奨買い目・買い目推奨・推奨した買い目 | サンプル買い目 | タブ名・見出し・注記・エラーの文 |
| 推奨度（レースの段階 0〜4） | 参考度 | 段階のラベル（見送り・標準・注目・高注目・最注目）は変えない |
| 推奨の期待回収率 | サンプル買い目の期待回収率 | |
| 推奨どおり全部買った場合 | サンプル買い目をすべて買った場合 | bet-optimizer の 2 つの回収率の片方。意味は同じ |
| 強推奨・推奨（馬ごとの買い判断 `buy_tier`） | 期待値 高・期待値 中 | 「様子見」はそのまま。閾値は変えない |
| 推奨（単独のラベル。例「推奨 注目」） | 参考度（例「参考度 注目」） | |
| 軍資金・資金（入力欄） | 予算 | シミュレーションでは「初期の予算」「最終の残高」「残高の推移」 |
| 投資（表の見出し） | 金額 | |
| 購入額・購入合計（買い目の金額） | 金額・合計額 | 「仮想購入」「100 円ずつ購入した場合」は、仮の計算と分かるので残す |
| 購入上限 | 1R 上限 | |
| 購入の直前に〜選んでください | 締め切り前の実際のオッズを見て〜 | 買うことを促す言い方にしない |
| ○R に参戦 | ○R が対象 | |
| 〜を買います（第 2 段の根拠） | 〜を買ったとして数えます | |
| 儲かる（主張として） | 回収率が 100% を超える | 「儲かりません」と打ち消す文は残してよい。言い換えられるなら言い換える |
| 負けるまで買うのがベスト（血統メモ） | 負けるまでは評価を下げないのがよい | |
| 今すぐ買え・必勝・稼げる・勝てる（買い方の宣伝として） | 使わない | 「今すぐ戻る」（メンテナンス画面）は対象外 |

## 回収率の見せ方

- 回収率の数字には、過去の集計で、将来の結果を保証しないことを近くに書く。
- ホームの速報の 1 行は「サンプル買い目 ○R（仮想）・○R的中・回収率 ○%（過去の集計）」。
- 「100% を超えた日や月があっても、その買い方で将来も 100% を超えるという意味にはなりません」の注記は残す（成績の画面）。

## 注意書き

ユーザーの決定（2026-11-25、統括役から）: 入れるのは次の 2 つだけ。のめり込みの注意と相談窓口のリンクは入れない。

1. 馬券の購入は 20 歳以上の方に限られます（20 歳未満の方は購入できません）。
2. 当サイトの予想・サンプル買い目は参考情報で、的中や結果を保証するものではありません。

置き場所:

- 全ページの下（`frontend/components/SiteFooter.tsx`。`app/layout.tsx` から出す）。利用規約・プライバシーポリシーへのリンクは常に出す（機能 legal）。特商法の表記は billing の機能（`lib/features.ts`）が有効なときだけ出す。
- サンプル買い目・回収率の近く: ホームの成績のカード（`BET_NOTE`）、API が返す disclaimer（`config/paid_zone.json`・`config/target_bets.json` の notice）。
- 特商法の表記の「ご注意」と、利用規約の第 5 条（免責）。
- 公開サイト（`site_public`）は、もとから同じ趣旨の注記を自動で付ける（`site_public/build.py`）。
