## 馬場の当日予測（新設。合格線は測る前にここで固定、2026-11-07）

`bias_eval.py`。今までは画面（走法マップの「今日の馬場」、`src/research/race/running_map_day.py`）だけで、精度を測っていなかった。

- **予測するもの**（レースごとの実現した傾向。芝・ダート別、障害は除く）: レース内で、正規化着順 r=(着順−1)/(頭数−1) を
  初角位置（`act_early_norm`）と枠（馬番の正規化 (馬番−1)/(頭数−1)）へ同時に回帰した 2 つの傾き
  **b_F（前有利なら負）・b_D（内有利なら負）**。完走 6 頭以上のレース。
- **使ってよい情報**: そのレースより前に結果が出たレース（同じ日の前のレース＋同じ開催の前日。同じ場・同じ芝ダート）、馬場状態、コース（場×芝ダ×距離）の過去年の平均。
- **基準線**: コースの過去年の平均だけ（当日の情報なし）。年ごとに、その年より前（2016〜）で作る。
- **現行**: 走法マップの重み（直前ほど重い HALF_LIFE=6 レース、前日 ×0.7、馬場状態が変わったら ×0.5）で、前のレースの「傾き − コース平均」を重み付き平均し、
  レース 3 本分（`MIN_RACES`）の重みで 0 へ縮めて、コース平均に足す。
- **主指標**: 2022〜2024 年の、前のレースが 1 本以上あるレースでの **予測の技能 = 1 − MSE/MSE(基準線)** を b_F と b_D で平均したもの（大きいほど良い）。
- **合格線**: 現行が基準線より良ければ「基準線→現行の改善幅を 1 割伸ばした値」。現行が基準線以下なら **技能 ≥ 0.02**。
  どちらも、開催日でまとめたブートストラップの 95% 区間の下限が 0 を超えること。副指標: 年別の技能（どの年も 0 以上）、b_F・b_D それぞれの技能。
- 天井は未測定（1 レースの傾き自体の雑音が大きく、予測できる上限は低い）。

測った結果（2022〜2024 年、前のレースがある 9,817 レース）:

|---|---|---|---|
| 現行 | 走法マップの重み（`running_map_day`） | −0.020（区間 −0.026〜−0.014） | — |
| 1 | 重み・縮みの探索 | 0.005（最良。評価年で選んだので楽観的） | — |
| 天井 | 同じ日のレース間の共分散から（当日の効果が 1 日一定とみたとき） | 約 0.045（b_F 0.036 / b_D 0.054） | |

- 試行 2 で、合格線は当日の情報なしでも越えた（頭数・レース番号などで傾きの大きさが変わるのをコース平均が拾えていなかった）。
  趣旨（当日の予測）に合わせ、**「静的モデルに対する上乗せの区間の下限が 0 を超える」を条件に足した（厳しくする方向。緩めてはいない）**。試行 3 で満たした。
- 当日の情報の上乗せは小さく、ほぼ枠（内外）の傾向。前有利・差し有利（b_F）は当日の前のレースからはほとんど読めない（+0.0003）。
  選ばれた重みは「同じ日の前のレースは間隔によらず同じ重み、前日 ×0.7（b_F）/×0.4（b_D）、縮み 24 / 12 レース分」。
- 適用可否の出力は、前のレースの重みの合計（`sw_*`）を目安にする。画面（走法マップの「今日の馬場」）の作り方を変えるのは未実施。
