# めぐ AI の拡張ラベル（担当 model-relabel、2026-11-27〜）

## 結論（2026-11-28、成果のページ: docs/html/modeling/final/model_relabel.html）
- ラベルの拡張（勝ちは 1/2 馬身、複勝は 1/2・1 馬身）は、本物の 1 着・3 着内の当たりを良くしない。勝ちでは、市場と組んだ上乗せが減る（v5bag の 2022〜24 で +0.0018）。大敗の罰を足しても変わらない。
- 本命決着のレースを学習から除くと、複勝の Benter の上乗せが約 11% 増える（C3、2022〜24 で −0.00058、Bonferroni の区間で 0 より下）。
- 市場の logit と |ρ| ≥ 0.5 の 108 列は、外しても上乗せが劣らない（C1）。単体の当たりは下がるので、本番を替える根拠ではない。
- 複勝の順序の罰で上乗せが良くなる比べ（C2）は通らない。
- 本番への反映はしない。考えるなら、統括役とユーザーの承認と stg を通す。開催単位の分けは未実施。

勝ち馬と同等の走りをした馬を負例にしないよう、ラベルを広げてめぐ AI を学び直す研究です。
評価は本物の 1 着・3 着内で行います。研究だけで、本番・前向きの記録の版（prereg_2026_r2・rc6）は替えません。2025・26 年は開きません。

- 仕様（成績を見る前に固定）: `config/model_relabel/spec.json`（版は `history` に順に残す。いまは mr-9）
- 道具: `src/research/model_relabel/`（mr_labels・mr_train・mr_eval・mr_ped・mr_market・mr_check・folds・queue.sh）
- 出力: `/home/jovyan/work/model_relabel_out/`（ラベル・部品・予測）と、この置き場の `eval_*.json`・`dataset_check.md`・`label_rates.json`

## ラベル
| 名前 | 定義 | 割合（2016〜24 の完走馬） |
|---|---|---|
| y1 | 1 着 | 7.24% |
| y_w | 1 着、または勝ち馬からの着差の累積 ≤ 0.5 馬身 | 10.49% |
| y3 | 3 着内 | 21.70% |
| y_p | 3 着内、または 3 着内の馬の累積の最大から ≤ 0.5 馬身 | 26.10% |
| y_p1 | 同じ作りで ≤ 1.0 馬身 | 29.32% |
| 大敗 | 6 着以下、かつ勝ち馬との時計の差 ≥ 1.0 秒 | 49.85% |

- 着差の文字列の換算は、ハナ 0.05・アタマ 0.1・クビ 0.25・同着 0 です。分数はそのままの値、「大」は 99 です。
- 次のどれかがあるレースは拡張しません（元のラベルのまま。21 レース）。
  - 2 着以下に空の着差がある。
  - 1 着に着差が入っている。
  - 降着がある。
  - 時計の逆転がある。
- 罰は 2 案です。
  - P-w: 大敗の負例の重みを w ∈ {1, 2, 4} にします。
  - P-ord: 二値 2 本の累積で近似します。s = logit(P(拡張の正)) + κ·log P(大敗でない) で、κ ∈ {0.5, 1} です。
- 選びの指標は L_λ = 本物のラベルの対数損失 + λ·大敗の −log(1 − p̂) です。λ は 0.5 が主で、1.5・0 が感度です。

## 分けと評価
- 主の分けは時間の順です。
  - 年 t のモデルは、t より前の年で学びます。
  - 外側の年 t の選びは、t−1 年で数えます（較正は t−2 年で当てる）。
  - 主に読むのは 2019〜21 です。2022〜24 は最後に 1 回だけ並べます。
- 開催単位の 5 分割（seed 20261128）は報告だけです（rules-council 1 号の条件）。
- 評価の行は、平地で全頭の市場の q がそろったレースです。
  - 障害（年 125〜128 レース）と、平地で q の欠けたレース（2023 年に 1 つ）は除きます。
  - 学習には、今の v5bag と同じく障害も入れます。
- 物差しはラベルの当てはまりだけで、回収率は計算しません。
  - 対数損失、勝ち馬の −log p、AUC、較正、1 番手の勝率・3 着内率。
  - Benter の 2 段の上乗せ。確定の q と組み、t−1 年で当てて t 年で数えます。

## 注意（結果を読むときに必ず添える）
- **中止・失格の馬**: 学習の表 X は完走馬だけです（`layer_a_dataset.py:167` の finish_position > 0）。中止・失格の馬（平地の 0.31%）は行がありません。
  - 本物の行は作れません。群の表（train_table・S3・TL・aux・CY・BEST・factory ほか）がほとんど完走馬の行だけで作られているからです。
  - さらに、レース内の相対の列（_rz・_rrank・fm_* など約 280 列）は、中止の馬を入れると完走馬の値も変わります。
  - そこで感度で扱います。3 通り（戻さない・ラベル 0 で戻し予測はレースの最小・同じく中央）の、すべてで向きがそろう比べだけを採ります（spec mr-9）。
  - 中止の馬を含む X の作り直しと、この列の学習と推論のずれは、12/1 以降の train-serve-skew の仕事です。
- **漏れの列**: v5bag の列にも、s_time_pred・s_time_gap・s_rank_pred（leave-one-year-out の上流）と、2021-12 までの全体の当てはめの族（sr_・f3_・f2_・e_・pc_）があります。
  - ラベルどうしの比べは同じ列で行うので、この漏れは効きません。
  - ただし値の水準は楽観に寄ります。s_* だけを外した版が v5bag_mfs です。
- **v6e の代理**: 市場の判定を確かめていない 148 列（tl_・wc_・mtl_・rb_ など）が残ります。主の判定は v5bag で行います。
- **血統の 4 列**: 作りは pedigree_lab が 2016〜24 の成績を見て凍結したものです。このため、v5bag_ped − v5bag の差は選んだ期間の中の比べです。
- **前向きの登録 prereg_dirt_mat5**: 比べの相手は凍結の v5bag のまま変えません。
- **データの点検**: `dataset_check.md` にあります（重複 0・写しの 2 レースの扱い・障害・初出走・名前が結果に見える列など）。
