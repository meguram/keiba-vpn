# 無料の AI 印（public_mark_type）— なぜ効くのか と、そこから導ける予測（2026-11-25、bet-optimizer）

## 結論
- 基本理念（protocol.md の 0-0）に合わせ、印ごとに「なぜ効くのか」を言葉にし、その説明が正しければ訓練データで成り立つはずの予測を、データを見る前に書く。
- 確かめるのは探す側 70% だけ（11/30〜12/2 の 1 回。通算 8 回目の中で行う）。30% の側・2025・26 年は使わない。
- 予測が外れた印は、説明が立たないものとして「なぜ効くのか: 説明なし」と表に書き、門 C の前に会議に返す。印の定義（`config/public_marks.json`、hash 89c2decb）は変えない。
- 成績の表には「なぜ効くのか」の列を足す（下の表の 1 行の説明と、予測が成り立ったか）。

## 印ごとの説明と予測
判定の q は確定の q（lessons 20）。excess_mr は同じ確定オッズの帯 × クラス群の ◎ 以外の馬で割る。区間は開催日で束ねたブートストラップ。「成り立つ」は点推定の向きと、95% 区間が向きの側にあること。

| 印 | なぜ効くのか（説明） | 説明から導ける予測（70% の側で確かめる） |
|---|---|---|
| ◎ | 市場（人気）は、前走の着順のような目立つ情報に強く反応し、能力の指標（上がりの速さ・騎手と調教師の成績・血統の適性）を薄く見る。モデルはそれらを足し合わせるので、勝つ見込みを市場より正しく並べる | P1: ◎ が 1 番人気でないレースの ◎ の excess_mr は、◎ が 1 番人気のレースより大きい。P2: 情報の少ないレース（新馬・未勝利）の ◎ の excess_mr は、上のクラス（2 勝以上）より大きい。P3: ◎ の前走が 4 着以下だったレースの ◎ の excess_mr は、前走 1〜3 着のレースより大きい（市場が前走の負けに反応しすぎる。RC-2 の前走の結果への反応しすぎと同じ向き） |
| ○ | ◎ と同じ理由で、2 番目の見込みも市場より正しく並ぶ | P4: ○ の excess_mr は 1 以上で、◎ の excess_mr 以下（評価の順に効き目が並ぶ） |
| ▲ | 3 着内の見込みは、勝つ見込みより能力の安定（大きく負けない）に寄る。モデルは着順のばらつきを見ているので、市場の複勝の人気より 3 着内を正しく並べる | P5: ▲ の複勝率は、同じ確定の単勝オッズの帯の馬の複勝率より高い。P6: Harville の偏りから、▲ が人気上位のときは差が小さく、人気 4 番以下のときに差が大きい |
| △ | モデルも市場も高く見る馬。市場がすでに買っているので、上乗せは小さいはず（「当たりやすいが妙味は小さい」の目印） | P7: △ の勝率は確定の q に近く（excess_mr の 95% 区間が 1 を含む）、複勝率は全体の平均より高い |
| ★ | 人気の薄い馬は一般に買われすぎる（本命と大穴の偏り）。その中で、モデルが市場より大きく高く見る馬だけは、偏りを越える見込みがある | P8: ★ の excess_mr は、同じオッズの帯（10 倍以上）の ★ 以外の馬より大きい。P9: r（log(p/q)）の大きさの 3 分位で、excess_mr が r の大きい側ほど大きい（単調） |
| 消 | 人気が 10 番以下で、モデルの 3 着内の見込みも小さい馬は、能力の指標がそろって低い。市場の安い人気よりさらに来ない | P10: 消の複勝率は、同じ T-60 の人気の基準線の複勝率より低い |
| 印なし（割れている） | p の最大が小さいレースは、モデルにも確かな馬が見えない。印を付けても効き目は小さい | P11: 割れているレースで仮に p_win 最大の馬に ◎ を付けたときの excess_mr は、印のあるレースの ◎ より小さい |

## 確かめの決まり（事前に固定）
- 予測は 11 本。どれも 70% の側で 1 回だけ見る。割り引きは Bonferroni（11 本で片側 0.05 / 11 ≈ 0.0045）。合否ではなく「説明が立つか」の記述に使う。
- p は開催単位の out-of-fold か as-of の p だけを使う。そういう p が無い印・期間は確かめず、「確かめられず」と書く（v6e の p は使わない。1 号の確認 3）。
- 前走の着順（P3）は、その開催より前に分かっていた値だけを使う。
- 予測が外れても、印の定義・区切りを選び直さない。説明が立たない印は、門 C で「なぜ効くのか」を言えないので、「人気より勝つ」と書かない。
