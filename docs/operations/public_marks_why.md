# 無料の AI 印（public_mark_type）— なぜ効くのか と、そこから導ける予測（2026-11-25 改め、bet-optimizer）

## 結論
- 基本理念（protocol.md の 0-0）に合わせ、印ごとに「なぜ効くのか」を言葉にし、その説明が正しければ訓練データで成り立つはずの予測を、データを見る前に書く。
- 数えるのは「まだ見ていない形」の予測だけ。すでに見た形の予測と、「印が効く」という主張そのものは、説明の予測に数えない（成績の表の記述に回す）。
- 確かめるのは探す側 70% の 1 回だけ（11/30〜12/2。通算 8 回目の中で行い、回数を増やさない）。p が out-of-fold か as-of のときだけ確かめ、無ければ「確かめられず」。
- 成り立つかの線は 1 つ: Holm で割り引いた片側の検定（全体 α 0.05）。着順なしの模擬で検出力が 50% に届かない予測は、事前に「確かめられず」と書く。
- 着順なしの模擬の結果、◎・★・消の説明の予測はどれも検出力が 50% に届かない（下の表）。この 3 つの印は、70% の側の 1 回では説明が立つかを確かめられない。▲ の 1 本だけが確かめられる。
- 印の定義（`config/public_marks.json`、hash 89c2decb）と止める規則（7639a938）は変えない。
- 会議の記録: decisions.md の「R0-09 の R3」の末尾（この文書への指摘）。

## 検出力の模擬（着順は読まない）
- 方法: ◎ の q は手元の 11/21〜23 の T-60 の ◎ の q（37 レース）から引き直し、70% の側の ◎ のレースを約 5,000 と置いた。2 群の片方に ×1.06〜1.10 を植え、Holm の最も厳しい線（片側 0.05/10）で見分けられる確率を 2,000〜4,000 回で出した。
- 結果: 勝ちの比べ（◎・○・★・印なし）は、群の割合 15〜50% で ×1.06 なら 2〜3%、×1.10 なら 6〜18%。×1.20 でやっと 58〜93%。複勝率の比べは、▲（複勝率 0.40 前後）で ×1.10 なら 50〜62%、消（0.025 前後）では 1〜5%。
- 道具: `/home/jovyan/.claude-jovyan/jobs/788811b9/tmp/power.py`・`power2.py` と同じ計算を、12/3 の門 A の資料に `src/research/public_marks/` の道具として入れる。
- 読み: 70% の側の 1 回では、説明の多くを確かめる力が無い。確かめられない予測は、前向きの記録（門 C の満期 3,000 レース）で同じ予測を数える。そのとき、ここに書いた予測を変えない。

## 確かめの決まり（事前に固定）
- 予測は E1〜E10 の 10 本。Holm（全体 α 0.05、片側）。E6 は TOST（0.95〜1.05、片側 2 本とも同じ Holm の中）。
- 確かめるのは、検出力が 50% 以上の予測だけ（今は E5）。ほかは「確かめられず」と書き、結果を見ない。
- p は開催単位の out-of-fold か as-of の p だけ（v6e の p は使わない）。無ければ E5 も「確かめられず」。
- 前走の情報（E1・E3）は、その開催より前に分かっていた値だけを使う。
- 予測が外れても、印の定義・区切りを選び直さない。「要」の予測が外れた印は、説明が崩れたとして「なぜ効くのか: 説明なし」と書き、門 C で「人気より勝つ」と書かない。
