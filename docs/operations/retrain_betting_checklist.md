# モデルを再学習したときの、推奨馬券の再確認手順

推奨馬券（M=5・3連複のみ・最大3点・k=2.0・τ=1.0。決定ログ §78）は、モデルの勝率・連対率・複勝率を入力にしている。再学習で確率の質が上がれば、3連複の的中確率（MB60）と買い目の選別は自動で更新される。ただし**精度の改善が、そのまま回収率の改善になるとは限らない**ので、再学習のたびに次を確認する。

## 自動で効くもの
- 3連複の的中確率（`exotic_probabilities.py` の MB60）と、買い目の選別（的中確率÷購入額の順に詰める `portfolio_target.py`）。実装の変更は要らない。

## 再学習のたびに確認するもの（軽い）
1. **想定オッズの写像の当てはめ直し。** 3連複の想定オッズは「確率の2次多項式」で作る（係数は `config/` の odds_pred 係数）。係数は現行モデルの確率の分布に合わせてあるので、確率が尖る・較正がずれると、同じ確率でも想定オッズの意味がずれ、購入額（想定オッズに比例）が変わる。新しい OOF で `odds_pred_eval.py` の写像を当て直す。
2. **k（安全係数）・τ（想定EV下限）・M の再確認。** 2022〜2024 年で格子を再評価し、2025 年で検証する（`portfolio_target_eval.py`）。2026 年は検証専用で、選択に使わない。
3. **崩れていないことの確認。** 見送り率、的中率（約6%）、トリガミ率（ほぼ0%）、目標到達率、回収率の区間、最大ドローダウンが、前回から大きく変わっていないこと。

## 精度と回収率は別の話
- 回収率は「市場との差」で決まる。市場がすでに織り込んでいる情報で精度が上がっても、回収率は上がらない。市場に近づく方向の改善は、差を縮めて回収率を下げることもある。
- これまでの検証で、勝率の LogLoss の改善が、回収率100%超を示した例はない。回収率100%超は未確認（2025年の区間は 0.99〜1.46）。
- 再学習後も「期待値・回収率を保証しない」表示（UI の注意書き）を外さない。

## 反映の流れ
1. 新しい OOF で上の 1〜3 を実行し、結果を決定ログに追記する。
2. 写像の係数・設定（`config/` の成果物）を更新し、`config/fitted_artifacts.txt` の登録を確認する。
3. stg に反映して画面を確認 → prod へ（`scripts/ops/vps/promote_oneshot.sh`）。
4. 旧設定に戻す場合は、環境変数 `KEIBA_BET_STRATEGY=legacy`（推奨馬券の方策切替）で戻せる。
