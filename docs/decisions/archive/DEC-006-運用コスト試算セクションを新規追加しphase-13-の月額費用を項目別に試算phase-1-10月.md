| Cloud Run メモリ | ~$0.10〜$0.50 | ¥15〜¥75 | 512MB × 60req/日 × 30日 × $0.00000250/GB-秒 |

> ただし**コールドスタート（モデルロード）に 1〜3 秒かかる点**はバッチ設計で許容できる。

## 決定事項サマリー（DEC-006 として記録）

```
決定: 現在の keiba-vpn スケールにおける推論処理は VPS 内 Celery バッチで実装する
     外部推論 API（Vertex AI / SageMaker 等）は使用しない

理由:
  1. LightGBM の推論時間（10-50ms）は外部 API 往復遅延（20-100ms）より短く
     外部化すると遅くなる
```
