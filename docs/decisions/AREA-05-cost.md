### フェーズ別コスト試算（AI 推論アーキテクチャ選択）

| フェーズ | アーキテクチャ | 推論追加月額 | 適用規模 |

| **Phase 1**（現行） | VPS 内 Celery / cron バッチ推論 | ~¥10（GCS ストレージのみ） | < 50 ユーザー |
| **Phase 2** | Cloud Run 推論マイクロサービス（FastAPI + LightGBM） | ~¥0〜375（無料枠内に収まる可能性大、上限 +¥750） | 50〜500 ユーザー |

### コスト削減方針（確定）

1. **Redis キャッシュ**: GCS Egress を 95% 以上削減（Redis ヒット率 ≥ 90% 維持）
2. **VPS 固定費モデル**: 重賞週末のアクセス急増時もスケールアウトコストが発生しない
3. **GCS**: 書き込み中心で読み取りは VPS ローカルキャッシュ経由 → 従量課金を最小化
4. **Vercel Hobby**: CDN 配信・デプロイ自動化を追加コスト ¥0 で実現
5. **バッチ推論分離**: Web プロセスと推論プロセスを分離することで OOM による再起動コストを排除
