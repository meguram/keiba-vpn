# AREA-08 — コスト計算要件

**Status**: FINAL | **Last Updated**: 2026-07-03 | **Consolidates**: DEC-001

---

## 概要

DEC-001（REQ-001）はデータ要件・モデリング要件を主題とする文書であり、**コスト計算要件（月額費用内訳・スケールアップ判断基準・AI推論外部化コスト比較・コスト削減方針）に関する記述は含まれていない。**

---

## 抽出された関連事項

DEC-001 の全文を精査した結果、以下の項目のみがコスト計算要件に間接的に関係する技術選定情報として確認できる。

### 使用技術・インフラコンポーネント（コスト試算の前提となる要素）

| コンポーネント | 用途 | 出典箇所 |
|---|---|---|
| PostgreSQL（想定） | Layer 1〜5 データ格納 | テーブルスキーマ定義（DDL） |
| Redis | 予測結果キャッシュ（TTL: 発走まで有効 / 発走後60秒失効） | F-12, N-12 |
| LightGBM | Stage 1/Stage 2 モデル推論（オンプレミス or セルフホスト想定） | §3-3 |
| LSTM（拡張予定） | ラップ系列予測（Phase 4 移行検討） | §3-3, R-8 |
| REST API サーバー | 予測結果配信（レスポンス ≤200ms / ≤2,000ms） | N-1, N-2 |
| MLflow（等） | モデルバージョン管理 | F-16 |
| スクレイピングワーカー | netkeiba.com 定期取得（並列1、間隔2秒） | §2-5 |

### 推論方式（外部化コスト比較に関係する設計方針）

DEC-001 は AI 推論を **外部 API（OpenAI 等）に委託する記述を含まない**。モデルはすべて LightGBM（および将来的に LSTM）によるセルフホスト推論として設計されている。外部推論サービスとのコスト比較に関する記述は存在しない。

## 対応アクション

コスト計算要件を確定させるには、以下の内容を含む新規 DEC の作成が必要である。

1. **インフラ構成の確定**（クラウドプロバイダー・インスタンスサイズ・ストレージ容量）
2. **月額費用試算**（スクレイピングワーカー・DB・Redis・API サーバー・モデル推論サーバーの各内訳）
3. **スケールアップ判断基準**（N-1/N-2 の SLA 達成を維持するためのリソース閾値）
4. **AI 推論外部化の要否判断**（LightGBM セルフホスト継続 vs. SageMaker / Vertex AI 等への移行コスト比較）
5. **コスト削減施策**（Redis キャッシュによる推論回避率向上、発走後データのコールドストレージ移行等）
