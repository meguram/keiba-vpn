## 3. AI 推論外部化コスト比較

現規模（<50 ユーザー）では VPS バッチが圧倒的優位:

| 選択肢 | 月額目安 | 備考 |
|---|---|---|
| **VPS バッチ（現在）** | **+¥10**（GCS ops のみ） | LightGBM 10〜50ms/レース、外部化より速い |
| Cloud Run（50〜500 ユーザー） | ¥0〜375 | スケールアップ時 |
| Vertex AI Batch（500+） | ¥750〜3,000 | GPU モデル不要時 |
| Vertex AI Prediction | ¥7,500〜22,000 | GPU 必要時のみ |

LightGBM は 10〜50ms/レースで動作するため、外部 WebAPI 化すると往復レイテンシ（+20〜100ms）が増加するだけで費用対効果が悪い。

## 4. スケールアップ移行トリガー

| トリガー条件 | 移行先 | 追加コスト目安 |
|---|---|---|
| ETL 処理時間 >30 分 | Cloud Run Jobs（ETL 専用） | ¥0〜300/月 |
| 同時接続 >500 | Flask → FastAPI 移行（VPS 内） | VPS 費用内 |
| ユーザー 50〜500 | Cloud Run（推論マイクロサービス） | ¥0〜375/月 |
| ユーザー 500+ / GPU モデル | Vertex AI または SageMaker | ¥750〜22,500/月 |
| 月次分析が必要 | BigQuery 追加（ADR-002） | ≤¥5/月（小規模） |
