DECISIONS · AREA-05

AREA-05 — コスト計算要件

FINAL 最終更新: 2026-07-06　|　統合: DEC-023（VPS ファースト確定）

1. 概要

DEC-023 の確定により、インフラは GCP マネージドサービスから ConoHa VPS ファーストへ移行 された。 BigQuery / Cloud Run / Cloud SQL / Cloud Scheduler は廃止。GCS は冷ストレージ用途のみ継続使用する。

月額予算上限

目標 1,000円 / 絶対上限 3,000円

2. スクレイピング基盤（P1-6: DEC-023 準拠）

2-1. 構成

コンポーネント構成
スケジューラVPS 上の cron（systemd timer または crontab）
ワーカーCelery（単一ワーカー、逐次処理）
実行環境ConoHa VPS（2GB RAM / 2vCPU）
ストレージローカルディスク + GCS（冷ストレージ）

2-2. 廃止コンポーネント（DEC-023 により削除）

廃止コンポーネント

以下はすべて廃止。コードベース・設定ファイルへの記述を残してはならない。

  • GCE Cron（旧案）
  • Cloud Run Jobs
  • Cloud Scheduler
  • Cloud SQL

2-3. スクレイピング制約（必須）

NETKEIBA_MAX_CONCURRENT_REQUESTS=1   # 並列リクエスト禁止
NETKEIBA_REQUEST_INTERVAL_SEC=2      # リクエスト間隔 2秒以上

並列リクエスト絶対禁止

並列リクエストは絶対禁止。Celery の concurrency は常に 1。逐次処理（1 リクエスト完了後に次リクエスト開始）のみ許可。

  • 想定リクエスト数: 最大 50,000 req/日（1,000 req/レース × 36 レース）。
  • 上記を超えるレース数が発生した場合は日次取得をキュー分割し、複数日に分散する。

3. 月額コスト試算（VPS ベース）

3-1. 月額費用内訳

項目月額（円）備考
ConoHa VPS 2GB RAM / 2vCPU~1,030API サーバー・Celery ワーカー・PostgreSQL・Redis を同居
GCS ストレージ 50〜100GB（冷ストレージ）~170〜350過去レースデータのアーカイブ
GCS API 呼び出し（HybridStorage キャッシュ活用）~100〜200L1メモリ→L2ディスクキャッシュにより GCS アクセス最小化

3-2. 廃止コスト項目（旧 GCP 見積もりから削除）

廃止コスト項目

  • BigQuery（クエリ課金）
  • Cloud Run（リクエスト課金）
  • Cloud SQL（インスタンス時間課金）
  • Cloud Scheduler（ジョブ実行課金）

3-3. 予算制約

区分金額
目標月額1,000円
絶対上限3,000円

予算超過時の対応

月額が 2,000円を超えた場合は即時レビューを実施し、コスト超過の原因を特定する。3,000円を超える構成変更は 事前承認必須。

3-4. HybridStorage によるコスト最小化

GCS へのアクセスは HybridStorage（L1メモリ → L2ローカルディスク → L3 GCS）によりキャッシュされる。 頻繁にアクセスされる最近レースデータはメモリ・ディスクで完結し、GCS API 呼び出しコストを最小化している。

5. スケールアップ判断基準

メトリクス閾値アクション
VPS CPU 使用率80% 超が 1 時間継続プランアップグレード検討（月額 +1,000〜2,000円 範囲内）
VPS メモリ使用率90% 超が 30 分継続不要プロセス削減 or プランアップグレード
API レスポンス（P99）2,000ms 超Redis キャッシュヒット率確認・クエリ最適化
GCS ストレージ100GB 超ライフサイクルルール設定（古いデータの削除）

スケールアップ時のコスト優先順位

スケールアップによる月額が 3,000円を超える場合は、機能削減・スクレイピング頻度削減を優先する。

6. AI 推論外部化コスト比較

DEC-001 / DEC-023 ともに AI 推論は外部 API に委託しない。 LightGBM によるセルフホスト推論を ConoHa VPS 上で実行するため、推論コストは VPS 月額に含まれる。

外部推論サービス（SageMaker / Vertex AI 等）への移行は、VPS 月額が 3,000円上限を超えた場合のみ費用対効果を再評価する。
