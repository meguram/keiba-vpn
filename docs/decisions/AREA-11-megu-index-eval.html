めぐ指数 — 性能評価レポート

モデルバージョン: v1　|　評価実施日: 2026-07-10

対象データ: STG 環境 2026年レース（芝・ダート）

算出根拠仕様（当時）

v1 仕様（本文書と同時点）。現行仕様は AREA-11-megu-index.html §1〜9 を参照。基準値・par_time 算出方法が v3 で変更されており、下記の数値は v1 当時のものである点に注意。

1. 算出ロジックの概要

めぐ指数 = 100 + (par_time − adjusted_time) × 10
adjusted_time = finish_time − (Δpace + Δtrack + Δweight + Δlevel)

1点 = 0.1秒差。par_time（基準タイム）は同距離・馬場・コース条件の 2着馬 補正済みタイムの平均値。

2着基準フィルタ（v1 最適化）

対象扱い
1着・2着常に regression / par_time 算出に利用
3着以降 かつ 2着タイム＋2秒以内正常計算
3着以降 かつ 2着タイム＋2秒超out_of_range（megu_index = NULL）
データ自体なしDB にレコードなし（欠損）

勝ち馬が余裕で勝つ場合や、後方大差馬のノイズによる誤差拡大を抑制するため、2着タイムを基準に設定。

6. computation_status スキーマ設計

computation_statusmegu_index意味
'valid'数値あり正常計算済み
'out_of_range'NULL2着タイム+2秒超（測定範囲外）
レコードなし—データ自体欠損（scratch 等）
-- 絞り込み例
SELECT * FROM megu_index WHERE computation_status = 'valid';           -- 有効
SELECT * FROM megu_index WHERE computation_status = 'out_of_range';   -- 着差大
-- LEFT JOIN で出現しないレコード → データ欠損

8. 今後の改善ポイント

  1. FQ（総賞金）データの整備 → β₄ を有効化してレベル補正を追加
  2. 2020–2025年分の指数算出 → 長期トレンド分析・モデリング特徴量として活用
  3. races.surface 正規化 → ダートの集計・UIへの反映
  4. 指数の時系列変化追跡 → 同馬の成長・衰えを可視化
