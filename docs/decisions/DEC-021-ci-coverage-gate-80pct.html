DEC-021: CI カバレッジゲート: 20% → 50% → 80% 段階引き上げ

accepted 2026-07-04　|　担当: Orchestrator　|　関連 AREA: AREA-08　|　矛盾ID: S-9-A

項目内容
日付2026-07-04
ステータスaccepted
担当Orchestrator
関連 AREAAREA-08
矛盾IDS-9-A

コンテキスト

MASTER.html N-13 と AREA-08 はユニットテストカバレッジ ≥ 80% を CI ブロッキング条件として定義しているが、.github/workflows/ci.yml の --cov-fail-under=20 は実質的にゲートとして機能しておらず、仕様書の要件を 4 分の 1 しか担保していない。

決定事項

段階的引き上げを採用する:

  1. 即時: --cov-fail-under=50 に引き上げ（現状テスト数では 80% 達成が困難なため中間値）。
  2. Phase 2 完了後（ML 実装完了）: テスト拡充後に --cov-fail-under=80 に引き上げ、MASTER.html N-13 と一致させる。
  3. CI 追加: ML テスト（tests/ml/）と E2E テスト（tests/e2e/）のジョブを追加する。

選択肢と比較

選択肢メリットデメリット
段階引き上げ（採用）現実的・CI が壊れない・継続的品質向上即時 80% 達成できない
即時 80%仕様書準拠現状テストが少なく CI が常に失敗

影響範囲

  • .github/workflows/ci.yml の --cov-fail-under=20 → 50 に変更
  • ci.yml に ML テスト・E2E テストの job を追加
  • docs/decisions/AREA-08-testing.md に段階引き上げ計画を注記

備考

80% 達成時期は tests/ のカバレッジ拡充進捗による。Phase 2（ML 実装完了）後に再評価し、DEC-021 を superseded に更新する。
