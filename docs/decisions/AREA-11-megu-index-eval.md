**算出根拠仕様**: [AREA-11-megu-index.md](./AREA-11-megu-index.md)

## 1. 算出ロジックの概要

```
めぐ指数 = 100 + (par_time − adjusted_time) × 10
adjusted_time = finish_time − (Δpace + Δtrack + Δweight + Δlevel)
```

**1点 = 0.1秒差**。par_time（基準タイム）は同距離・馬場・コース条件の **2着馬** 補正済みタイムの平均値。

### 2着基準フィルタ（v1 最適化）

| 対象 | 扱い |
|------|------|
| 1着・2着 | 常に regression / par_time 算出に利用 |
| 3着以降 かつ 2着タイム＋**2秒以内** | 正常計算 |
| 3着以降 かつ 2着タイム＋**2秒超** | `out_of_range`（megu_index = NULL） |
| データ自体なし | DB にレコードなし（欠損） |

> 勝ち馬が余裕で勝つ場合や、後方大差馬のノイズによる誤差拡大を抑制するため、2着タイムを基準に設定。

## 2. 回帰モデル（NB-02）

### 推定係数

| パラメータ | 値 | 意味 |
|-----------|-----|------|
| β₁ (beta_pace) | **0.8760 sec/sec偏差** | 前半スプリット偏差 1秒 → 0.876秒補正 |
| β₂ (beta_track) | **0.1965 sec/TSI単位** | TSI（馬場状態指標）1単位 → 0.197秒補正 |
| β₃ (beta_weight) | **0.5498 sec/(kg×距離スケール)** | 斤量偏差1kg×2000m → 0.550秒補正 |
| β₄ (beta_level) | 0.0（暫定） | FQ データ未整備のため0設定 |
| TSI 平均値 | 3.309 | 正規化の基準値 |

### 回帰モデル性能

| 指標 | 値 |
|------|-----|
| 学習サンプル数 | 145,924 行（175,472 行から17%除外） |
| 訓練データ期間 | 2020–2024年 |
| adjusted R² | **0.9393** |
| 多重共線性（最大VIF） | 1.004（問題なし） |
| 標準誤差種別 | HC3 ロバスト標準誤差 |

> β₃ = 0.550 の妥当性確認: 55kg × 0.550 × (2000/2000) ≈ 30.2秒（2000mでの斤量寄与の全走破タイム換算）

## 5. 着順予測性能

### レース内相関（最重要指標）

1レースごとに「めぐ指数順位 vs 実際の着順」の相関を計算し、308レース分を集計。

| 指標 | 値 |
|------|-----|
| 平均レース内 Pearson 相関 | **0.8051** |
| 中央値（P50） | 0.8436 |
| P25 | 0.7132 |
| P75 | 0.9373 |
| 評価レース数 | 308（5頭以上 valid 完走） |

> レース内での速さ順位付けとして **80%の一致率** は実用的な水準。出走頭数が多く条件差が大きいレースほど精度が高い傾向（P75=0.937）。

### 距離帯・馬場別内訳

| 馬場 | 距離帯 | valid件数 | out_of_range | 平均 | 標準偏差 | 中央値 |
|------|-------|-----------|-------------|------|----------|--------|
| 芝 | sprint（〜1200m） | 1,075 | 60 | 103.7 | 13.4 | 103.7 |
| 芝 | mile（〜1600m） | 1,120 | 74 | 105.4 | 15.3 | 105.7 |
| 芝 | middle（〜2000m） | 2,278 | 267 | 107.1 | 17.1 | 107.4 |
| 芝 | long（2001m+） | 415 | 71 | 110.6 | 17.3 | 110.5 |

> 長距離ほど平均・標準偏差が高い傾向（条件差が大きい）。ダートは `races.surface` 未整備のため JOIN 集計外だが、計算は正常実施。

## 6. computation_status スキーマ設計

| `computation_status` | `megu_index` | 意味 |
|---------------------|-------------|------|
| `'valid'` | 数値あり | 正常計算済み |
| `'out_of_range'` | NULL | 2着タイム+2秒超（測定範囲外）|
| レコードなし | — | データ自体欠損（scratch 等）|

```sql
-- 絞り込み例
SELECT * FROM megu_index WHERE computation_status = 'valid';           -- 有効
SELECT * FROM megu_index WHERE computation_status = 'out_of_range';   -- 着差大
-- LEFT JOIN で出現しないレコード → データ欠損
```

## 7. 既知の制限事項

| 項目 | 現状 | 対応方針 |
|------|------|---------|
| β₄ (level / FQ) | 0固定 | FQ（賞金合計）データ整備後に再推定 |
| ダート races.surface | 空文字列のため JOIN 集計不可 | races テーブル surface 正規化 |
| 2026年以前データ | 計算未実施 | `compute.py --year 2025` 等で拡張可能 |
| 前スプリット欠損 | カバレッジ 92.7% | 欠損時は Δpace=0 で対応中 |
