1. GCS の JSON カテゴリ（正本）

1.1 保存の共通規則

項目内容
バケット / 接頭辞バケットは環境変数 GCS_BUCKET。データは chuou/data/preprocessed/netkeiba/pc/（GCS_BASE）、その他は chuou/data/others/（GCS_OTHERS）
キーの種類（CATEGORY_MAP）race: <GCS_BASE>/<カテゴリ>/<race_id先頭4桁=年>/<race_id>.json ／ horse: …/<horse_id先頭4桁>/<horse_id>.json ／ other: <GCS_OTHERS>/<カテゴリ>/<キー>.json ／ local_only: GCS に置かずローカルのみ
race_id / horse_idrace_id は 12 桁の文字列（年4 + 場2 + 回2 + 日2 + R2）、horse_id は 10 桁（先頭 4 桁=生年）
付与されるメタ保存時に _meta.scraped_at（UNIX 秒）と _meta.scraped_at_jst を付け、_meta.schema_validation（schema_version・passed・違反の一覧）と _meta.scrape_validation_status（ok / schema_failed / schema_skipped）を記録する
検証（既定は厳格）スキーマ定義があり不合格のデータは GCS に保存せず SchemaValidationError（キューは failure_reason=schema_validation）。KEIBA_SCHEMA_STRICT=0 で不合格でも保存。advisory のカテゴリは不合格でも保存を止めず記録のみ。スキーマ定義の無いカテゴリは検証を skip
違反の記録data/local/meta/schema_violations/<カテゴリ>.jsonl（1 行 = 1 回の不合格）、拒否したデータ本体は data/local/quarantine/<カテゴリ>/<キー>.json
スキーマの正本src/scraper/schema_defs.json（git 管理）。実データからの再構成は python -m src.scraper.schema_infer collect|report|apply。各カテゴリの _provenance に観測サンプル数・キー範囲・適合率を持つ
生 HTMLchuou/data/raw/html/<カテゴリ>/<年|先頭4桁>/<キー>.html.gz。カテゴリごとに最大 10 件のサンプルだけ保持（構造変更の検出用）
ローカルの補助L1 メモリ LRU（TTL 3,600 秒）、L2 ディスク data/cache/（週 2 回以上読まれたキーだけ書く。TTL 当年レース系 12 時間・過去/馬系 2 日）。GCS と同形のミラー data/local/mirror/ は設定（local_mirror_config）で有効にしたカテゴリのみ（ホストは未設定=無効）
開発 PCKEIBA_ENV=dev では GCS に接続せず data/dev_mock/（同じレイアウト）を読み書きする

3. Parquet の表と特徴量

3.1 レース・馬の表 data/page_reference/tables/<年>/

python -m src.scraper.export_tables（cron: export_tables_daily.sh が当年を毎日 07:00 JST に増分更新）が GCS の JSON から作る。*_flat.parquet: 1 行 = 1 馬（entries を展開）、*_race.parquet: 1 行 = 1 レース（元の構造を保持）。flat の列は「レースのメタ（race_id・date・venue・surface・distance・direction・grade・race_class・weather・track_condition・start_time・field_size・race_name・venue_code）」+「JSON のトップ項目（辞書・配列は JSON 文字列にする。JSON 化して 1KB（FLAT_MAX_JSON_BYTES）を超える項目は除外）」+「entries の各項目」。JRA（場コード 01〜10）のレースだけ。年ディレクトリは 2020〜2026。2026 年は取得が不完全。

実列・型は stg ホストの 2025 年ファイルを polars.read_parquet_schema で読み取った結果。行数は 2025 年。2026 年のファイルは _export_report.json, megu_index_flat.parquet, race_result_flat.parquet, race_result_lap_flat.parquet, race_result_lap_race.parquet, race_result_on_time_flat.parquet, race_result_on_time_race.parquet, race_result_race.parquet（取得状況により年ごとにファイルの種類が異なる）。
