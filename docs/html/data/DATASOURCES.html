データソース一覧

netkeiba.com から取得するデータソースの仕様書です（SmartRC は DEC-027 で取得を継続。DEC-024 の除外を見直した）。
各ページの URL パターン・認証要否・パーサー／クライアント・ストレージカテゴリ名・取得フィールドを定義します。

概要

netkeiba.com

認証「要」: netkeiba プレミアム会員のログインが必要です（認証は完了している前提）。認証情報は .env の netkeiba_id / netkeiba_pw で管理します。

SmartRC (smartrc.jp)（取得を継続・DEC-027）

現状: DEC-024 は SmartRC を除外としたが、2026-10-16 の DEC-027 で取得の継続に見直した（位置取り・ペース予測に使うスタート後 1F＝テン1F が目的）。キューの smartrc タスクは前日夕方・開催日夕方に動き、smartrc_race には 2020〜2026 年の全レース分がある。利用規約は未確認。保存カテゴリは現在 smartrc_race のみで、下表の smartrc_runners / smartrc_horse / smartrc_trend は旧仕様の名前です。

SmartRC 認証（旧仕様）: netkeiba とは別アカウントでした。.env の SMARTRC_LOGIN / SMARTRC_PASSWORD で管理します。
SmartRC は JSON API（ExtJS ベース）のため、HTML のパースは不要です。
APIのアドレス（ベース）: https://www.smartrc.jp/v3/smartrc.php/{endpoint}

ストレージ構成

GCS のアクセスポイント（バケット・prefix）は stg と prod で同一です（dev は GCS に接続しない）。

Google Cloud Storage（GCS）— 正データ置き場

gs://{GCS_BUCKET}/chuou/data/
  ├── preprocessed/netkeiba/pc/{category}/{年}/{race_id}.json       # レース単位（先頭4桁 = 年）
  ├── preprocessed/netkeiba/pc/{category}/{先頭4桁}/{horse_id}.json  # 馬単位（先頭4桁 = horse_id の先頭）
  ├── others/{category}/{key}.json                                  # jra_cushion / requirement_row_trace など
  └── raw/html/{category}/{年 or 先頭4桁}/{id}.html.gz              # HTML アーカイブ

主なカテゴリ（HybridStorage.CATEGORY_MAP。schema_defs.json に定義済みの 39 カテゴリの全一覧は database_schemas.html）: race_result・race_shutuba・race_index・race_shutuba_past・race_odds・race_pair_odds・race_paddock・race_barometer・race_oikiri・race_trainer_comment・horse_result・horse_pedigree_5gen・horse_training・broodmare_mating、 および行固有の派生 11 カテゴリ・生成物（race_predictions 等）。

GCS — HTML アーカイブ

gs://{GCS_BUCKET}/chuou/data/raw/html/
  ├── race_result/{年}/{race_id}.html.gz
  ├── race_shutuba/{年}/{race_id}.html.gz
  ├── ...
  └── horse_result/{先頭4桁}/{horse_id}.html.gz

パスは html_archive.py の GCS_RAW_BASE（chuou/data/raw/html）。

ローカル

data/page_reference/
  ├── race_lists/{date}.json          # 日付別レース一覧 (local_only: GCS に置かない)
  └── race_day_schedule/              # 発走時刻スナップショット (local_only)
data/meta/
  └── structure/                      # ページ構造フィンガープリント

認証情報の設定（.env）

# netkeiba.com
netkeiba_id=<email>
netkeiba_pw=<password>

# GCS（stg / prod。dev は GCP に接続しないので空のまま）
GCS_BUCKET=<bucket>
GCS_TYPE=service_account
GCS_PROJECT_ID=...
GCS_PRIVATE_KEY=...      # ほか GCS_PRIVATE_KEY_ID / GCS_CLIENT_EMAIL / GCS_CLIENT_ID / GCS_CLIENT_CERT_URL（.env.example 参照）
