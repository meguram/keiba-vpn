最終アーキテクチャ（stg／prod × VPS／GCP）と、データ取得・表示の全体像

この本のまとめの章。「どこで何が動き、データがどう流れ、ユーザーの画面に出るか」を 1 か所で見渡す。最終形の記録で、2026-10-27 時点の到達点は 9 章。時刻はすべて JST。

1. 3 行でいうと

画面は VPS、計算と保存は GCP、研究は別の PC。ユーザーが開く画面と入口は ConoHa VPS に置き、予測・集計・保存・API は Google Cloud（Cloud Run／Jobs／GCS）が担う。研究用 PC は学習と評価だけで、運用データには書かない。

stg と prod は同じ作りで、違うのは「どの版か」と「誰が見られるか」。stg は確認用の版（API は Cloud Run のタグ付きリビジョン、画面は VPS の 2 つ目）、prod は本番の版。どちらも GitHub への push で配備される。

止まっても他が動く。各段階（予約・取得・予測・集計・表示）は GCS を介してつながり、直接は呼び合わない。研究用 PC が止まっても、運用には影響しない。

守ること：毎日 JST 03:00–04:00 はメンテナンス表示（02:30 から事前告知）なので、この間に push・昇格しない（スモークが 503 で落ちる）。API は昇格直後に切り替わるため、壊す変更は 2 段（新旧両対応 → 旧を消す）にする。

5. ユーザーへのデータ表示フロー

図 5　画面を開いてから予測が出るまで。①〜④ が往路。黄色の破線は、各所で待ちを減らす工夫。

5.1 画面を開くと起きること

順何が起きる待ちを減らす工夫
1ブラウザが app.megu-keiba.com を開く。Cloudflare が受け、Tunnel で VPS の nginx へ。画面の殻（HTML・JS・CSS）は VPS が返す。データの計算は含まない
2画面の JS が /api/* を呼ぶ（開催日の一覧 → レース一覧 → レースの予測）。URL に ?race= があれば、一覧を待たずにそのレースの予測を先に取り始める。一覧が出たら同じ日の他のレースも裏で先読み
3nginx が /api/* を Cloud Run API へ中継（共有鍵と接続元 IP を付ける）。Cloud Run は最小 0（待機コストなし）。待ちの目立つ最初の 1 回は、画面側の先読みと前回表示で隠す
4API が GCS の予測・出馬表・オッズ・モデルを読み、会員区分で項目を絞って返す。事前生成した応答があればディスクから返す（なければ従来どおり計算）。保存のあったレースだけ作り直す
5ブラウザに描画。直前に見たレースは前回の表示を先に出し、最新が届いたら差し替える。取得済みの予測は 45 秒メモリに保持（一覧⇔詳細で共有）。ログアウトで前回表示は消す

6. 止まったとき、どうなるか

止まるものユーザーの画面裏の動き復旧
研究用 PC影響なし学習・補填が止まるだけ。運用データには書いていない起動し直す
VPS画面が開けないGCP の予測・集計は続く。取得役も止まるので、期限が来た取得タスクは失敗として残り、生存報告の途絶で Slack に緊急通知VPS を再起動。画面は GCS の最新版を再度取り込む
Cloud Run API予測が出ない（画面の殻は出る）Jobs と取得は続き、GCS に溜まる1 つ前のリビジョンへ（数秒）
取得元が遮断新しいデータが入らないアクセス制限の疑いは再試行せず、30 分取得を止めて通知間隔を空けて再開
GCS全体が止まる（正本）—復旧待ち（唯一の共通点）

7. 費用と守る約束

  • 月額の目標：GCP＋Cloudflare＋ConoHa の合計で 2,000 円以内。VPS は前払い済み（2028-05 まで）。Cloud Run は最小インスタンス 0 で無料枠にほぼ収まる。最小 1 にすると約 2,900 円/月増えて予算を超える。日次のコスト報告（想定と実績、急増の警告）で見張る。
  • VPS のメモリ：常駐 600MB 以下、空き 1GB 以上。取得役は上限 250MB で、超えたら最初に止まる。
  • 取得は 1 本ずつ。netkeiba への同時アクセスは 1、日の上限と間隔を守る。同じタスクを 2 か所で取らない（担当を 1 つに決める）。
  • 鍵を作らない・貼らない。GitHub から GCP へは WIF。VPS と研究用 PC の鍵は役割ごとに分け、権限は最小（models/ への公開だけ、ops/ の読み取りだけ、など）。
  • 環境名は prod 一つ。確認用の stg は、ホスト上の環境ではなく、GCP のタグ付きリビジョンと VPS の 2 つ目の画面に置く。
