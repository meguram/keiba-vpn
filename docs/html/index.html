1プロダクト概要・ユーザー

1.1 目的と提供価値

  • JRA（中央競馬）の出走馬ごとに、AI 予測（勝率・連対率・複勝率、ラップ・ペース、追走難度・位置取り、最終オッズ）を発走前に提供する。
  • 予想の根拠をユーザー自身が探索・検証できるデータ分析機能（血統・種牡馬成績、コース統計、馬場速度、成長曲線、めぐ指数など）を提供する。
  • AI 予測と予測オッズから期待値（EV）を求め、Kelly 基準で馬券配分を提案する（馬券最適化・シミュレーション）。
  • 元データをそのまま提供せず、出馬表の一部抜粋と独自の AI 予測・分析のみを提供する（DEC-024 の法的リスク判断の前提）。
