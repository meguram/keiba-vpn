トラックバイアスの判定（前後・内外）

作成 2026-11-26 15:22（JST）。担当 track-bias。全部の開催日 × 場 × 芝・ダートに、1 行の名札を付けた。対象 2016-01-09〜2026-11-23 の 6,269 日（判定なしを除く）。全部の名札は 名札の一覧。

結論

  • その日・その場・芝ダのレースで、市場の見込み（確定単勝オッズからの 3 着内の確率）に比べて前の馬・内の馬がどれだけ来たかを測り、同じ条件のふだんの日と比べて 5 段に分けた。
  • 名札は「内外 × 前後」の 1 文（例「内有利・前残り」「中立」）。2017〜24 の日の 16% が前残りの側（前残り・強い前残り）、16% が差し有利の側だった。
  • 1 日の値のばらつきのうち、本当の馬場の偏りの分は目安で 9%〜19% にとどまる。残りはその日のレースの偶然のばらつきで、1 日 6 レースほどでは偏りと運を分けきれない。
  • そのため「強い」の名札の日のうち、目安で 85% ほどは、偏りが全く無くても偶然で同じ大きさのずれが出る数に当たる。名札は「その日の結果がそう出た」という記述で、馬場がそうだったことの証明ではない。
  • 2 つの目安は、1 レースの分散 V に日の偏りの分も少し入るので、本当の偏りの割合は小さめ・偶然の割合は大きめに出る向きがある。
  • 翌日（土日の続き）の値との相関は 前後 0.09・内外 0.16 と弱い。これは次のレース・翌日を当てる道具ではない（当日の偏りで次を当てる話は RC-3 が閉じた）。
  • 主の値は 前後「前後（序盤の位置）」・内外「内外 案 B'（4 角の群の中の相対位置。単独は中ほど）」。統括役の決定で内外は案 B を元にし、その変種を同じ物差しで比べて決めた（下の「作りの比較と採否」）。
  • 基準線に足した項は、前後の主が なし、内外の主が 開催の何日目 × 仮柵。採らなかった項（クッション値・含水率など）は、日の表に並べるだけにした。ほかの値ごとの採否は下の「作りの比較と採否」。

判定の作り

  • 対象: 平地の芝・ダート、発走した馬（取消・除外を除く。競走中止の馬は残して 3 着外とする）。3 着の同着は、残りの枠を同着の頭数で割る。頭数 5 未満・オッズか通過順の欠けがあるレース（直線の芝 1000m など）を除く。同じ馬が同じ日に 2 回出ている写しのレースは落とす。
  • 市場の見込み q: 確定単勝オッズの 1/オッズ を和 1 に直した勝率から、Harville の式で 3 着内の確率（レースで和 3）。y は 3 着内なら 1。
  • 前らしさ c = 0.5 − 序盤の相対位置（通過順の最初の数字。角が 2 つのレースは 3 角）。逃げ +0.5、最後方 −0.5。4 角の位置は、好走する馬が前へ上がって来る分だけ着順の結果でもあるので、並べる版にした。脚質の名札（逃げ・先行・差し・追込）も序盤の位置から作る。
  • 1 レースの値 S = Σ (y − q) × c。逃げた人気馬が負け（y − q が負で c が正）、後方の穴馬が来る（y − q が正で c が負）と大きく負になる。人気に逆らって位置取りが結果を動かしたレースを、そのまま数える。
  • 基準線 E（一般的な傾向）: 場 × 芝ダ × 距離帯（〜1400・〜1800・〜2200・それ以上）× クラス群（新馬・未勝利／1 勝／2・3 勝／OP 以上）× 馬場（良／稍重／重・不良）× 頭数群（〜8・9〜13・14〜）の、その日より前のレースだけの平均。空の区分が多いので、芝ダ → 芝ダ × 距離帯 → （場のコースの癖）＋（場を問わない条件の癖）へ順に縮めた（経験ベイズ）。縮める強さ k は 2018〜24 の as-of の誤差で選んだ（前後 200）。
  • その日の値 D = Σ (S − E)、z = (D ÷ √ΣV − μ) ÷ s。V は前の日のレースの残り (S − E)² の平均（区分は芝ダ × 距離帯 × 頭数群）。μ と s は、2017〜24 の日（レース 3 以上）の実際の平均と SD（芝ダごと）。2016 年は基準線の溜め、2025・26 年は校正に使っていない。
  • 区分（閾値は数字を見る前に決めた）: |z| < 1 は中立、1 以上は有利、2 以上は強い。レース 3 未満の日は判定なし。区間は D の 80% 区間（± 1.28 × s × √ΣV）。
  • 1 日の中の変化: 前半（〜6R）・後半（7R〜）と、その日の中で馬場の発表が替わったときの区切りの z を並べる（記述だけで区分は付けない）。区切りの z は区切りのレースだけの分散で割るので、レースごとの「日の z への寄与」を区切りで足した値とは一致しない。

主の決め方の結果

  • 前後: 主は「前後（序盤の位置）」。「前後（上がり 3F の遅さ）」: 持続の 3 つのうち 1 つで 「前後（序盤の位置）」 より 0.01 を超えて高い・本当の偏りの割合は 下がる。「前後（序盤の位置 + 上がり 3F の遅さ）」: 持続の 3 つのうち 0 つで 「前後（序盤の位置）」 より 0.01 を超えて高い・本当の偏りの割合は 下がる。
  • 内外: 主は「内外 案 B'（4 角の群の中の相対位置。単独は中ほど）」。「内外 案 B − 序盤の位置の分」: 持続の 3 つのうち 0 つで 「内外 案 B（4 角の群の内から何頭目。単独は最も内）」 より 0.01 を超えて高い・本当の偏りの割合は 下がる。「内外 案 B'（4 角の群の中の相対位置。単独は中ほど）」: 持続の 3 つのうち 2 つで 「内外 案 B（4 角の群の内から何頭目。単独は最も内）」 より 0.01 を超えて高い・本当の偏りの割合は 下がらない。
  • 採った基準線の項の誤差の下がりは 0.051%〜0.106% と小さい。決まり（0.05% 以上）で採ったが、効きは小さい。
  • 前後の 4 角の版は、同じ開催の持続が最も高い。着順の結果を含むので主の候補にしていない。
  • 上がり 3F を使った版は主に採らなかった。「前後（上がり 3F の遅さ）」は、持続で前後の主を 0.01 を超えて上回ったのが 同じ開催、本当の偏りの割合は 8.5%（前後の主 9.8%）。「前後（序盤の位置 + 上がり 3F の遅さ）」は、持続で前後の主を 0.01 を超えて上回ったのが なし、本当の偏りの割合は 7.9%（前後の主 9.8%）。
  • 同じ開催の前の日を事前の値にして縮める案は採らなかった。前の日と同じ向きに寄せる作りなので、翌日・同じ開催の持続の物差しが作りで上がり、比べられない。名札も日ごとに独立でなくなる。
  • 芝の内回り・外回りは、表の列が 2024〜25 年にほぼ空なので比べられなかった。

内外の案

  • 案 A 馬番: 内らしさ g = 0.5 − 馬番の相対位置。全部のレースで取れて単純。弱点は、枠の効果が最初の角までの距離・脚質と混ざり、道中の進路ではないこと。
  • 案 B 4 角の併走の内外: 4 角の通過順の括弧（1 馬身未満の併走の群）の中は、内側の馬から書く（JRA の成績表の見方）。群の中で外にいた馬ほど g が低い。実際の進路に近い。元の B は単独の馬を最も内と数えるので、単独で走ることの多い逃げ・先行の馬を内側に数えてしまう。

  • 案 C 馬番 − 序盤の位置の分: レースの中で g（案 A）を序盤の前らしさ c に回帰した残り。内枠の先行馬が残った日を「内有利」と取り違えにくい。

限界

  • 1 日の値の大半は偶然のばらつき。名札は結果の記述で、馬場の状態の測定ではない。
  • 市場の見込み q は確定オッズからの Harville で、人気馬の 3 着内を少し大きく見込む。基準線も同じ q で作るので、ふだんの分は打ち消し合う。
  • 芝の内回り・外回りは基準線に入れていない。表の列（course_type）が 2024〜25 年はほぼ空で、区別できない。
  • 直線の芝 1000m（通過順が無い）は対象外。
  • 開催・仮柵の表（course_position）は 2026-11-08 まで（名札を作った時点）。それより後の日は、開催の何日目・仮柵が「?」の群に入り、その群の過去の平均に寄る。
  • 内外の主も、前後の主と日の z の相関が 0.30 ある（2017〜24）。逃げ・先行の馬が内に入りやすい分か、本当に内と前が同じ日に有利になるのかは、この作りでは分けられない。

作り方・再現

  • nice -n 19 python -m src.research.track_bias calibrate（2016〜24 だけで k と校正を決め、config/track_bias/calibration.json に書く）。
  • nice -n 19 python -m src.research.track_bias build-all（全期間の名札。data/local/research/track_bias/daily_labels.parquet・年ごとの CSV）。開催日の夜に流し直すと新しい日が足される（30 秒ほど）。
  • python -m src.research.track_bias day --date 2026-11-22 --venue 東京（その日の判定とレースごとの根拠の JSON）・html（この文書）。
  • 費用 0 円（手元の表だけ。GCS を読まない）。2025・26 年の結果は記述として読んだ（台帳の系統 track_bias・eval_only）。
