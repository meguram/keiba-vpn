特徴量戦略書（tp-02 〜 tp-04）

学習パイプライン notebooks/modeling/training_pipeline/ の特徴量設計の根拠・定義・検証手順をまとめる。確定した結果は 確定事項ログ に記録し、本書は「なぜそう設計したか」と「次に何をどう比べるか」を持つ。最終更新: 2026-10-14。

この文書の範囲
  • tp-02（特徴量生成。実装済み）の設計原則・特徴量ファミリーの定義・根拠。
  • tp-03（特徴量の ablation。未作成）の比較手順と採否基準。

3. 特徴量ファミリー（tp-02 で実装済み。94 特徴量）

列名の接頭辞でファミリーを判別できる（feature_families.json がホスト PC の data/local/modeling/training_pipeline/features/ にある）。EWM は指数加重移動平均（半減期はレース数）。

系列数計算の中身主な列根拠
A 上がり・脚質14 各走の上り 3F を、レース内の標準化（z）、最速馬との差、順位（頭数で割る）にする。上り最速の頻度。位置取り（初角・最終角の順位を頭数で正規化）の EWM を「脚質」とし、先行時／後方時の上がり z を分ける。直近のトレンド（短期 EWM − 長期 EWM）、最良値、直近 5 走の中央値・標準偏差。 a_l3fz_ewm2/ewm6/best/med5/std5、a_gap_ewm2、a_rk_ewm2、a_top3_freq、a_l3fz_back/front、a_style、a_style_late、a_trend 上りの絶対値は馬場の高速化で年代比較できない（S1）。レース内で相対化する。33 秒台が標準・後傾ラップへの対応を見る（S8）。L2→L1 の減速量（S9）は未実装。
B 得意な舞台17 各走の「相対成績の残差」（Elo による期待順位との差。res = S − E）を、条件セルごとに階層縮約する。セルは (芝ダ×距離帯)・(場×芝ダ)・(芝ダ×馬場)・(回り×芝ダ)・(場×芝ダ×距離)・クラス。親セルへ (Σres + κ·親) / (n + κ) で縮約し、親は「芝ダ×距離帯 → 馬の全体」。距離適性は、log 距離の二次リッジ回帰を過去走のモーメントの累積から閉形式で解き、今回距離での予測値・標準誤差・傾き・最適距離からのずれを出す。 b_aff_all/sd/venue/going/dir/course/class、b_n_*、b_dist_pred/se/slope/gap 経験ベイズによる縮約（出典 L5）。距離適性の残差回帰は Benter の DPGA（出典 L1）。同じ競馬場での実績・距離変更への対応（S7）。
C レースの質・相手関係17 過去走の残差の EWM（短期・長期）・中央値・最大・最小・トリム平均（頑健統計）。出走馬の事前 Elo の平均・上位 3 頭の平均・自分との差（立ち位置）。クラス別の基準からのずれ（相手関係の質 rq = 相手の平均 Elo − クラスの基準）。クラスの EWM と、今回との差（昇級／降級）。前走の残差と長期平均の差。 c_res_ewm2/ewm6/med5/max5/min5/trim5、c_fs_ewm2、c_fstop3_ewm2、c_standing_ewm2、c_rq_ewm2、c_cls_ewm2/prev、c_opp_step、c_cls_step、c_fs_step、c_last_dev 昇級初戦は強い相手と当たりやすい（S5）。大敗は誤差として扱い、頑健統計で処理する（S12）。相手関係の補正は Benter の因子（出典 L1）。後日談（その後の出走で相手が好走したか）は、リーク回避のため未実装。
D 休養・体重10 前走・前々走からの日数、過去走数、初出走からの日数、馬体重の長期平均からの偏差、前走の増減、今回の増減、前走の着順・頭数・着順率。 d_rest、d_rest2、d_nprior、d_career_days、d_wt_dev、d_wt_chg_last/now、d_prev_fin、d_prev_field、d_prev_fin_pct Benter の因子分類（近走成績・間隔・馬体重など。出典 L1）。
E 信頼度3 残差の標準偏差（直近 5 走・全期間）、上りの有効走数。サンプルが少ない馬の特徴量の信頼度をモデルに渡す。 e_res_std5、e_res_std_all、e_n_l3f縮約の信頼度（出典 L5）。
F1 条件類似度4 今回の条件と過去走の条件の距離（log 距離、同場、同芝ダ、馬場、回り、クラス、頭数、経過年数）の重み付き和 d から w = exp(−d) を作り、過去走の残差を重み付き平均する。重みの係数は FIT_END 以前で探索。有効サンプル数も出す。 f1_sim_res、f1_sw、f1_neff、f1_sim_z 出走レースと各馬の過去履歴とのマッチ度（ユーザーの着想）。距離適性の考え方は出典 L1。効果は不安定（§6）。
F2 展開・脚質マッチ17 前傾／後傾ラップへの相性を含む。各レースの実際のペースを「前半 3F − 後半 3F」（距離帯ごとの分位で 3 区分）に分ける: 区分 0 = 前傾（前半が速い）、1 = 平均、2 = 後傾（後半が速い）。馬ごとに、過去走をこの 3 区分に分けた「区分別の相対成績」（f2_a_reg0/1/2、縮約済み）と、その過去走数（f2_n_reg0/1/2）を持つ。前傾に強いか後傾に強いかの差が f2_pace_adv（区分 0 − 区分 2）。
今回のレースの想定ペースは、出走馬の脚質（a_style）から先行馬の頭数・割合（f2_pressure）を数え、3 区分に分けた先行馬圧力 f2_bin から、FIT_END 以前で推定した対応表 P(実際のペース区分 | f2_bin) で確率にする（f2_p_fast = 前傾の確率）。この確率で区分別の成績を重み付けしたものが f2_pace_match（展開マッチ）。ほかに、先行馬の頭数、出走馬内の前からの順位、脚質×先行馬割合、単騎逃げのフラグ。		 f2_nfront、f2_nfront40、f2_nknown、f2_early_rank、f2_pressure、f2_bin、f2_a_reg0/1/2、f2_n_reg*、f2_pace_match、f2_pace_adv、f2_p_fast、f2_style_x_press、f2_lone_front 逃げ馬が 1 頭ならスロー、同型が 5 頭以上なら前崩れ（S7、S12）。逃げはスローで有利、先行はハイペースで消耗（S2）。
限界: 想定ペースの確率がほぼ一様（約 1/3 ずつ）で、展開の予測としては弱い。ペース区分は前半・後半の差だけで決めており、中盤の緩みなどラップの形は見ていない。試作検証でもペース別成績（F2b）の効果はほぼゼロだった（§6）。ペースを専用に予測する前段が必要（§4）。
F3 Elo（相手関係付きレーティング）9 多頭数 Elo。順位から S = (N − 順位)/(N − 1)、期待値 E は全ペアの勝率の平均。K=300（fit 期間で勝ち馬の対数尤度が最小。K=24 では残差の自己相関が 0.31 残った）、初期値 1500、過去走 3 未満は K を 1.5 倍。レース前のレーティング、相手の平均・上位 3 頭・標準差、自分との差、レース内順位、過去走数。 f3_r、f3_E、f3_fs_mean/top3/std、f3_r_gap、f3_r_gap_top3、f3_r_rank、f3_n_pre Elo・Glicko・TrueSkill（出典 L7、L8）。Glicko の不確実性（RD）の考え方は未実装。Plackett-Luce（出典 L9）は目的関数側の検討事項。

4. 前段予測量（ステージ予測）と特徴量への組み込み

4.1 なぜ必要か

  • 馬とレースの「マッチ」は、そのレースの展開の予測と馬の得意な展開の組み合わせで決まる。前者の精度が、マッチ特徴量の効きの上限になる。
  • 現状（F2）の想定ペースは、過去走の脚質から先行馬を数えて 3 区分に分け、対応表で確率にするだけの簡易版。実測では確率がほぼ一様で、前傾・後傾への相性（f2_a_reg0/1/2）を活かしきれていない。
  • 上がり・位置取り・走破タイムも同じで、「今回の条件・展開の下での期待値」を先に予測してから、後段の特徴量にする方が、過去走の平均だけを渡すより情報が多い。
  • 例: ペース予測を先に出し、その確率で区分別成績を重み付けする。先行馬の頭数も、過去の脚質の平均ではなく、位置取り予測から数える。

4.5 リーク防止と精度の基準

  • ラベルは結果、入力は as-of: 位置取り・ペース・上がり・時計は当該レースの結果なので、学習のラベルにだけ使う。入力は tp-02 の as-of 特徴量と、前の段の OOF 予測だけ。P2 の集計は出走馬の as-of 値だけで作る（自馬の結果を含めない）。
  • 時系列の OOF: 年 Y の予測は、Y の開始 10 日前（purge 7 日 + embargo 3 日）より前のデータで学習したモデルで出す。2020〜2021 年の行には予測が付かない（NA）。2025 年（test）の予測は、2020〜2024 年で学習したモデルで出す。
  • 連鎖の注意: 第 2 段以降が使える行は、前段の OOF がある 2022 年以降に限られる。その分、後段の学習行が減る（助走期間が実質的に長くなる）。代替として、年単位の leave-one-year-out の OOF（学習行は増えるが、将来のデータでパラメータを学習する軽い先読みを含む）も比べるが、既定は厳密な expanding window とする。
  • 精度の基準（P3 の例）: 3 区分の予測の LogLoss が、一様予測（≈ ln 3 = 1.099）を明確に下回ること（seed 間のばらつきを超える改善）。下回らない場合は m_pace_match に使わず、簡易版（F2）に戻す。P1 は実際の位置取りとの相関と MAE、P4 は MAE と相関で評価する。
  • 寄与の確認: 各段の予測そのものの精度とは別に、後段への寄与（s_*・m_* の有無での p_win の LogLoss 差）を tp-03 と同じ手順で測る。
  • 簡易版との関係: F2 の f2_pressure・f2_p_fast・f2_pace_match は、P2・P3・m_pace_match の簡易版（ルールベース）としてそのまま残し、前段の予測で置き換えた版と比べる。

7.3 時代ずれの追跡（adversarial validation）

採用セットごとに、train と valid／test を見分ける AUC を記録する。現状（on_time 補正後、tp-02 の 94 特徴量）は、全部で 0.86（valid）・0.90（test）、F5 を除くと 0.76・0.79、F5 と件数系を除くと 0.74・0.78。上位は c_rq_ewm2、c_cls_ewm2、c_cls_step、f3_fs_mean、c_fstop3_ewm2。AUC は「分布差の大きさ」の目安であり、単独の合否基準ではない。LogLoss を悪化させずに下げられる範囲で対処する。

8.2 設計方針

  • 前段予測量の定義・連鎖・精度の基準は §4。以下はその実装方針。
  • 入力は as-of のみ: tp-02 の特徴量（レース前に分かる情報）だけを入力にする。目的変数はそのレースの結果で、学習のラベルとしてだけ使う。
  • OOF（学習に使わなかった fold の予測）を時系列で作る: 各 valid 年（2022・2023・2024）の予測は、その年の開始 10 日前までの学習で作ったモデルで出す。ランダムな GroupKFold は使わない。2025 年（test）の予測は、2020〜2024 年で学習したモデルで出す。2020〜2021 年の行には前段の予測が付かない（NA）。これは助走期間として扱い、tp-03 の「助走期間を外す」実験と整合させる。
  • 最終モデル（tp-05）への渡し方: 前段の予測値は特徴量として渡す。ただし同じ年の fold の学習に使ったレースの予測は渡さない（OOF の原則）。
  • 重複の整理: 前段の脚質予測と、tp-02 の a_style（過去走の脚質 EWM）は情報が重なる。ablation で両方入れた場合の効果を確認する。
  • 保存先: OOF は data/local/modeling/training_pipeline/oof/、MLflow の実験は keiba-tp-stage に記録する。
  • 障害レースの扱い: 障害レースは上りが 13〜14 秒台（約 125 レース/年）で、上り 3F のモデルでは別扱いにする。
