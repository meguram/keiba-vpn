3連単の実オッズで再評価（tp-48）

tp-36 で『確定オッズが無いと検証できない』として保留した買い方を、3連単の実オッズ（2024〜2026 年、9,711 レース）で再評価した。ユーザーの質問『的中率が高い上位3券種に、期待値が高いものだけを買う検証はしたか』にも答える（§4.5）。オッズは確定後に取得した値で、購入時点の値ではない。

要点.
  • 区間下限が 100% を超える方策は、無かった.345 方策を試し、2024〜25 年の最良の下限は 96%（複勝、モデルの EV を縮約して選ぶ）。White の Reality Check は p=0.96（最大 t=1.43）。
  • 3連単で 2024〜25 年に 170% 近い回収率が出る方策（モデルの EV 上位 5 点）は、的中 3 レースの払戻に支えられた偶然。上位 3 的中を除くと 52%、年別は 270%（2024）、69%（2025）、12%（2026）と揺れる。破産確率（100 単位）は 95%。
  • 市場を混ぜた確率（mixed）で選ぶ3連単は 18〜71% で、100% に届かない。モデル単体（model）は年で逆転する（2026 年は上位 k 点が 0〜31%、上位 50 点が 87%、縮約しきい値が 106〜118%。2025 年は 59〜65%）。
  • 的中率が高い券種の『期待値が高いものだけ』: 複勝はモデルの EV≥2.0 で 113%（区間 93〜132%）、上位 3 的中を除いても 106%。年別も 103%・110%・99% と安定して 100% 前後に位置するが、下限は 100% を超えない。ワイド・馬連の 1 点買いは 117%・156% だが、的中 3 レースを除くと 101%・89%。
  • 印の組合せ（◎○▲★△）は 89〜96%。2026 年は 66〜85%。

  • 応答には、人気薄の組合せが一部欠ける日がある（平均 0.3〜0.4%）。欠けた組合せは買えないものとして扱う。欠けが 3% 以上、Σ(1/オッズ) が 1.37〜1.39 の外、または的中組合せの払戻が合わないレースは、3連単の評価から除外する。
  • オッズは確定後（締切後）に取得した値で、購入時点のオッズではない。

2. 評価の設計

  • 確率は割引 Harville（レースごとに連対率・複勝率へ α を当てはめる）。『model』は V4 の勝率・連対率・複勝率（市場なし）、『mixed』は単勝の Benter 混合を勝率とし連対率・複勝率を拡縮。
  • EV = 確率 × 実オッズ。複勝は下限＋0.3×（上限−下限）（tp-47 の修正）。『縮約後』は tp-47 の縮約係数 k（複勝 0.24、馬連 0.11、ワイド 0.10、3連系は仮に 0.10）で払戻率の側へ寄せた EV のしきい値。
  • 各方策は 100 円ずつの均等買い、払戻は確定払戻。レース単位の母数、ブートストラップで 95% 区間。設計は 2024〜25 年、2026 年は最後に 1 回（実オッズのある券種のみ）。
  • 試した方策は 345 通り（3連単、プール間の不整合、3連複、複勝・ワイド・馬連、印の組合せ）。
