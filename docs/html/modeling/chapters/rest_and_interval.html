休養明け・レース間隔の分析（tp-34）

前走からの間隔・休養明けの叩き何戦目・その組み合わせ（前走の結果、年齢、クラス、乗り替わり、休養中の調教）が好走率にどう効くか。V4 アンサンブル（v4_e2）の valid 2022〜2024 の予測 140,865 行（10,366 レース）に対する残差（実際の率 − 予測の平均）を、レース単位のブートストラップ 95% 区間つきで見る。特徴量（コード: src/pipeline/features/tp34_rest.py）は、日付が厳密に前の走・調教だけから作る（as-of）。市場オッズ・人気は使わない。

要点. 第 2 段で採用基準を満たした群はありませんでした。V4 には何も足しません。 V4 は間隔・休養明けの効果をほぼ吸収している。残る系統的なずれは、休み明け初戦の複勝率を V4 が 0.7 ポイント（相対 4%）ほど高く見積もる点（2022〜2024 の全年で同じ向き）と、半年超・14〜26 週の長い休養の複勝率をやや高く見積もる点。 馬ごとの『休み明けの得意不得意』には再現性がある（偶数番目と奇数番目の休み明けの相関 r = 0.24、全体への補正後 0.39）が、調教師ごとの休み明けの仕上げ傾向には再現性がない（前半と後半の相関 r = -0.05）。

3. 再現性（馬・調教師の得意不得意）

  • 馬ごと: 3,167 頭（休み明け初戦が 4 回以上）。休み明け初戦の成績（同じ馬のそれ以外の走との差）を、偶数番目と奇数番目で分けた平均の相関は r = 0.24（スピアマン・ブラウン補正で 0.39）。馬ごとに休み明けの得意不得意がある。平均では、休み明け初戦は同じ馬のそれ以外の走より fp（正規化着順）が +0.060 悪い。
  • 調教師ごと: 179 人。休み明け初戦の V4 に対する残差を前半（2022〜23）と後半（2024）で比べた相関は、複勝 r = -0.05、勝率 r = +0.04。調教師の休み明けの仕上げ傾向は再現しない。

4. 特徴量の増分（V4 全体に対して）

群: R1_band = 間隔の帯・叩き何戦目・その馬の過去の間隔との比較、R2_horse_pref = 馬ごとの同じ間隔の帯／休み明け／叩き何戦目での過去成績、R3_tataki_gain = 馬ごとの叩き 2・3 戦目の上昇度、R4_trainer = 調教師ごとの休み明け／叩き 2 戦目／間隔の帯の成績、R5_cross = 年齢・クラス・面・性別・距離・季節 × 間隔の帯の全馬横断の成績、R6_prev = 前走の消耗（着差・上がり・押し上げ）× 間隔、R7_work = 休養中の調教の本数・強度・カバー率、R8_season = 前走月 × 今回月（夏休み・年末年始）。いずれも as-of（日付が厳密に前の走・調教のみ）。基準は V4（新しい土台）の LightGBM。採否は『95% 区間の上限 < 0、効果 ≥ 0.0002、連対・複勝の悪化 0.0002 以内』。G1 の rest 群（前走間隔の日数・フラグ・直近の出走数）、tp-31 の T5_rest_cls（前走間隔×コース）は別。

5. 見かけの大きな改善はリークだった（浮動小数点の端数）

前走の消耗の群 R6 は、第 1 段で勝率 −0.00329、新しい seed の第 2 段でも −0.00379（上限 −0.00323）と、これまでのどの特徴量より大きな改善に見えた。調べると、 rs6_prev_fp_vs_mean（前走の正規化着順 − 過去の平均）の 1 列だけで同じ改善が出て（この列を除くと消える）、しかも改善は『過去 1 走だけの馬（11.5%）』の行にすべて集中していた。 原因は、過去の合計を『累積和 − 自分』で作っていたこと。数学的には『自分より前の合計』だが、浮動小数点では (a + b) − b が a に戻らないことがあり、端数に今回の値 b の痕跡が残る。 今回が 1 着（正規化着順が厳密に 0）のときだけ端数が 0 になる、というパターンを木モデルが拾い、勝ち馬を当てていた（値の差は 1e-16 で、通常の許容誤差つきの先読み検査では見えない）。

6. 結論

  • 第 2 段で採用基準を満たした群はありませんでした。V4 には何も足しません。
  • V4 は、間隔・休養明けの効きの大部分をすでに持つ（G1 の rest 群・experience 群、TL_A の追い切り、S3 の前段、補助ヘッド）。休み明け初戦の複勝率を高く見積もるずれは小さく、特徴量として足しても勝率の改善にはならない。
  • 馬ごとの休み明けの得意不得意には再現性があるので、運用では『その馬の過去の休み明け成績』を見る価値がある（人が読む用）。調教師ごとの仕上げ傾向は再現しない。
