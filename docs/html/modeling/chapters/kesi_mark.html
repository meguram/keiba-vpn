消印＝3着内に来る確率が低い馬（人気区分別の目標と判定）と、推奨列の印表示（tp-67）

依頼: 「推奨の列は印を出す。◎○▲★で1頭ずつ」「消しマークの付いた馬の好走率（3着以内に入る率）を低くする。人気馬に対する消しと、10人気以降の馬に対する消しがある。レースによっては付かないことも、複数付くこともある」。ユーザー確定の目標（2026-10-21）: 1〜5 人気 ≤10%、6〜9 人気は付けない、10 人気以下 ≤5%（実績の 3 着内率）。判定は期間別（設計 2022〜23／確認 2024／参考 2025／最終確認 2026）に、二項分布の Clopper-Pearson 95% 上側信頼限界が目標以下かで行い、点推定だけで達成としない。データは tp-36 の入力（V4 の OOF の複勝確率 p_top3、確定の単勝オッズ・人気）と rank_tbl の確定着順（3 着以内、8 頭以上のレース、着順の取れないレースは除外）。人気は対象の区分けにだけ使い、予測の入力にはしていない。

要点.
  • 10 人気以下: 達成.複勝確率 ≤ 8% の馬に消印。実績の 3 着内率は 設計 2.61%（上側限界 2.83%）・確認 2.32%（2.62%）・参考 2.60%（2.91%）・最終 2026 2.68%（3.06%）で、4 期間とも上側限界が目標 5% を下回る（内部の基準 3% は 2026 年だけ 3.06% でわずかに超える）。カバー率は 1 レースあたり 約 3.5 頭、レースの約 89% に付く。
  • ただし 10 人気以下は何もしなくても 5% 以下（全馬で 4.2〜4.5%、上側限界 4.6〜4.8%）。モデルの確率で絞ることで 4.4% → 約 2.5%（約 6 割）に下がるのが、消印の中身。
  • 1〜5 人気: 達成できない → 付けない.V4 の複勝確率が低い人気馬でも実績は 15〜17%（複勝確率 3〜10% の 933 頭、上側限界 20% 超）。消し要因の信号（休養・馬体重・前走大敗・クラス・距離・位置取りなど 190 列）を足した分類器も、複勝確率だけと AUC・LogLoss がほぼ同じで、予測が最も低い層でも実績 14〜21%。単独の信号の両端 3% の集合でも最低 19〜29%。10% 以下と言える集合は見つからなかった。
  • 6〜9 人気: 設定なし（付けない）.
  • 他の印との重なり.採用ルールの馬 44,802 頭（2022〜25 年）のうち、◎○★△が付いていたのは 0 頭、▲が 6 頭（0.01%）。▲は消印にしない。△との重なりは無い（△は複勝確率が均等確率の 1.35 倍以上で、10 人気以下の複勝確率 8% 以下の馬とは重ならない）ので、推奨馬券の相手候補は変わらない。
  • V4 の複勝確率の低確率域の信頼性は人気区分で逆.10 人気以下は過大（予測 4.0% に対し実績 3.0% など。消印にとっては安全側）、1〜5 人気は過小（予測 4〜9% に対し実績 15〜17%。人気馬の『来ない』は信用できない）。

1. 目標と判定法

区分目標方式
1〜5 人気消印の馬の 3 着内率 ≤10%複勝確率（および消し要因の信号）で低確率の馬を探す → 見つからなければ付けない
6〜9 人気設定なし付けない
10 人気以下≤5%複勝確率 ≤ しきい値。しきい値は設計年（2022〜23）で『上側限界 ≤3%』になる最大値（ユーザーが最初に挙げた 3% を内部の基準にして、5% に余裕を持たせた）に固定。確認・参考・最終はこの値の検証だけに使う

1 レースの個数に上限・下限は置かない（0 頭のレースも複数頭のレースもある）。人気は実オッズ（なければ予測オッズ）の単勝人気。◎○▲★の付いた馬には消印を付けない。

6. 他の印との関係

  • 採用ルールの馬 44,802 頭（2022〜25 年）の現行の印: 無印 44,796、▲ 6、◎○★△ 0。▲の馬は消印にしない（ルールで除外）ので、◎○▲★に消印は付かない。
  • △は、複勝確率が均等確率の 1.35 倍以上で合成点が基準以上の馬（16 頭立てで約 8.4% 以上）。複勝確率 8% 以下の馬とは重ならないので、△を消印に置き換えることはなく、推奨馬券の相手候補（△）も、◎○▲★の組合せも変わらない。そのため『消印の馬を相手から外した場合の 3 連複・ワイドの回収率』の差は、構造上ゼロ（買い目の提案は消印を見ていない）。

7. 実装と運用

  • src/utils/race_probabilities.py の assign_kesi_mark（assign_mece_marks の後に呼ぶ。複数頭可・0 頭可）。10 番人気以下で複勝確率 ≤ 8%、◎○▲★は除く。8 頭未満・全頭の単勝オッズ（人気）が無いときは付けず理由を返す。根拠 kesi_reason は『N番人気で複勝確率x%。過去の実績では 10 番人気以下で複勝確率 8% 以下の馬が3着以内に来たのは約2.5%』。ライブの予測（app.py・local_predictions.py）と、保存済み予測の読み出し時（確率とオッズが揃うレースだけ）で付く。旧ロジックの保存済み予測は書き換えない（旧ロジックは未配備）。
  • 予測成績（prediction_results.py）: 印別の着順分布に消を追加（消は 3 着以内に来る割合が低いほど当たり）。旧い日次集計に消のキーが無くても合算できる。
  • UI: 推奨列＝印（◎○▲★△消）、買い判断は下段の小さな字（レース詳細は「推奨」の下に「印」「買い判断」）。凡例『消: 3着内に来る確率が低い（10人気以下で複勝確率8%以下。過去の実績では約2.5%・目標5%以下。複数付くことも付かないこともある）』。
  • 再現: python -m src.scripts.data.tp67_kill prep / calib / rule / top5 / overlap（tp67_kesi は初版の定義の比較）。テスト: tests/utils/test_kesi_mark.py。
  • 注意: しきい値 8% は V4 の OOF で決めた。本番の予測が V5 に切り替わったら、V5 の同じ形の OOF（または shadow の蓄積）で再確認する。確定前は予測オッズで人気が決まる（10 人気以下の区分は全馬で ≤5% のため、人気が多少ずれても目標に影響しにくい）。

8. 推奨列の現状と修正

  • 広い画面（1100px〜）の「推奨」列は買い判断（強推奨・推奨・様子見）の文字だけで、印は狭い画面のカードの端にしか出ていなかった → 推奨＝印、買い判断は下段の小さな字に。見出しをクリックすると印の順（◎→○→▲→★→△→消）で並ぶ。
  • 中間幅は馬名の前に印、下段は『買い判断 …』。カードは右上の印に消を追加。レース詳細は「推奨」のグループに「印」「買い判断」の順。予測成績は ◎・○・★に消を追加。

10-8. 設定と再確認

  • 設定は config/kesi_mark.json（version・min_field・min_pop・p3_max・保守／積極の代替・旧版の履歴）。assign_kesi_mark はこの設定を読み（更新時刻で読み直す。KEIBA_KESI_CONFIG で別ファイルも可）、ファイルが無い・壊れているときは既定値（version 0, p3_max 8%）。旧版（version 1、上位5人気の最小1頭）は履歴に残し、未配備のため設定としては持たない。
  • V5 の確率に切り替わった後の再確認: 予測成績（data/local/prediction_results/<日>.json、印別の消の件数）を貯めて python -m src.scripts.data.tp67_opt recheck --results-dir data/local/prediction_results --out DIR。月別・モデル別・全体で消印の 3 着内率と上側限界を出し、目標 5% を超えたら tp67_opt grid で V5 の OOF（または shadow の蓄積から作った表）に対してしきい値を取り直し、p3_max を更新する（version を上げて履歴に追記）。

11. 申し送り

  • 10 人気以下の消印は『何もしなくても 5% 以下』の区分での、さらに約 6 割に絞った目安。1 レース約 3.5 頭・レースの 89% に付くので、表示が多すぎる場合は、しきい値を下げる（5% で約 2.5 頭・84%、実績 1.6〜1.8%）選択肢がある。
  • 人気馬を『消す』には、V4/V5 の確率では足りず、故障明け・調教の欠落などの本物の消し要因の特徴量が要る。パドック・当日の気配は取れない情報。
  • 確定前のオッズが貯まったら（10/24 以降の T-10/T-5/T-2）、直前オッズの人気で再評価する。
