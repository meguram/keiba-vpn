1. 血統ベースのレース質分析（中心課題）

『同じ血統マップのグループは、レースの質によって好走しやすさが違い、その中には人気以上に走るものがある。レース前に質の確率が分かれば、結果が未知のレースで予想・馬券に生きる』という仮説を、次の形で検証した。

  • 血統グループ g: 構成埋め込み A（親の ID を持ち込まない）のクラスタ K=16 と K=40（2021 年までにデビューした馬で定義を固定、以降の馬は最近傍の中心に割り当て）。解釈しやすい対照として、父の系統 8 通りと、産駒数上位 30 の父。
  • レースの質 q: 実測側（結果から作る）は tp-61 の展開タイプ 9 通り（ペース×隊列）、ラップ型 6 通り、上がり水準 3 段階、馬場（良／道悪）、勝ち時計の基準比 3 段階、荒れ度 3 段階。事前側は、展開タイプ・ラップ型・上がり水準をレース前に分かる量から年ごとの拡張窓で予測した確率（y 年の確率は y 年より前だけで学習）、馬場は発表値（T-60 でほぼ確定）。
  • 好走率の差分: 勝ち・3 着内の実績 − 市場の見込み（r_win = 勝ち − 単勝オッズ由来の勝率、r_t3 = 3 着内 − 複勝オッズ由来の 3 着内率）。『人気以上の好走』はこの超過。V4 の確率との超過も併記。
  • 効果: 交互作用 = 平均(g, q) − 平均(g)（市場の残差はレース内で和が 0 なので q の主効果はほぼ 0）、疑似 300 件で 0 へ縮約。検定は z（縮約前）、多重比較は BH（q = 10%）。
  • 未知のレースへの適用: 各馬の期待上乗せ = Σq P(q̂) × effect(g, q)（効果表はその年より前の全期間から作る）。オラクル（q を既知とした上限）と事前の確率版（実運用の下限）の両方を出す。

8. 血統グラフ上の近さ（構成埋め込み）

8.1 設計: 近さは『祖先の構成』で決め、親の ID を持ち込まない

節点 = 馬・種牡馬・繁殖牝馬（グラフ上 100,024 節点、両親が分かる節点 98,303）、辺 = 親子（父・母、重み 1/2）。節点 v の構成ベクトル Et[v] を、t=0 は節点ごとのランダムベクトル（葉）、t≥1 は 0.5×(Et-1[父] + Et-1[母])（親が不明なら葉で止まる）と再帰的に定義する。 Et[h] は『h の t 世代前の祖先の枠（各 2-t）に載る葉』の和＝血量で重み付けた祖先の構成で、馬の埋め込みは Σt=tmin..T γt-tmin Et[h]。 tmin=2 なら 1 世代目（父・母）の ID は入らず、父は父の両親（祖父母）の構成に展開される。全兄弟は祖先の枠が同一なので距離 0、父だけが違う産駒（同じ母 × ディープインパクト／ブラックタイド）も父どうしが全兄弟なので距離 0 になる。 これは学習なしの『親から子へのメッセージ伝播』（パラメータ無しの GNN）であり、Personalized PageRank 型の世代減衰は γ、カーネル（共通祖先の血量の積和）はランダム射影で保つ（次元 256）。グラフラプラシアンのスペクトル埋め込みはこのカーネルの主成分（SVD 32 次元）と同じ空間になるので別実装にしていない。

8.5 推論時のコストと汎化

  • 未見の馬（新種牡馬の産駒・初出走馬）でも、両親が分かれば埋め込みは親の埋め込み（窓を 1 世代ずらしたもの）の平均で作れる（ユニットテストで一致を確認: 子の E2..T = 0.5×(父の E1..T-1 + 母の E1..T-1)）。推論時に持つのは節点ごとの 32 次元（100,024 節点 × 32 × 4B = 約 13MB）と、競走馬 35,794 頭の座標（約 4.6MB）。
  • kNN は競走馬 35,794 頭 × 32 次元の総当たり（行列積）で近傍 30 頭を出せる（本実験は約 20 秒/方式）。近傍馬の as-of の成績は『馬 × 条件』の累積表（ホストの履歴バンドルと同じ形）を引くだけ。低メモリのサービング（約 340MB）に追加で載る規模。
  • クラスタ定義は 2021 年までにデビューした馬で固定し、以降の馬は最近傍の中心に割り当てる。クラスタ割当は血統のみで結果を使わないのでリークは無く、統計は過去の結果だけ（自分自身の過去走は引く）。

10. 結論

  1. 血統ベースのレース質分析（中心課題）: 血統マップのグループ（K=16/40、父の系統、上位 30 の父）× レースの質（展開タイプ・ラップ型・上がり水準・馬場・勝ち時計・荒れ度）で、人気以上の好走の差分は弱く、翌年の再現も低い（順位相関 −0.05〜+0.37、BH 通過セルは全 1,986 セル中 6 個）。事前の質の確率で未知のレースに適用した期待上乗せの説明力は相関 0.02 以下で、馬券側の EV 絞り込みも再現しない。例外は馬場（発表値）が弱く一貫する点と、特定の父 × ラップ型の少数の対応（キズナ × 中緩み再加速など。2026 年で確認できず）。
  2. 血統の回収率で稼げる条件は見つからない: 区間の下限が 100% を超えるセルは 0、規則 198 本・100 本の reality check は p = 1.00・0.21。勝率・複勝率は翌年も続くが、回収率と市場超過は続かない（血統は市場に織り込み済み）。
  3. EV への補正・絞り込みは、血統単独でも、騎手・調教師の規則（tp-59）への重ね掛けでも再現しない。V4 の確率の血統による補正は最大で 1 頭あたり約 −0.0002。
  4. 10 世代の血量は、6〜10 世代が V4／V5 の残差にほとんど効かない（|t|>2 が 4/36）。5 世代以内の他位置の血量は V4 の残差に効く（7/36）が、V5 が大半を吸収している。
  5. 近さの定義は『祖先の構成』（親の ID を持ち込まない）に決め、既知ペアの検証（全兄弟 = 距離 0、サドラーズウェルズ→ヌレイエフ 3 位、父だけ違う産駒 cos 1.00）を満たす。近さ ≠ 適性（全兄弟でも能力の相関 0.13）。V5 に累積した 5 群のうち第 1 段の採用基準を満たしたのは 0 群（最良は PQ_K16 の Δ勝率 -0.00006、上限 +0.00021）。

次にやること. (1) 直前オッズ（T-10/T-5/T-2）が貯まってから、馬場 × 血統・父 × ラップ型の少数の候補を購入時点のオッズで再検証。(2) 質の粒度を『展開タイプ』より細かく（想定位置取りの分布 × 脚質 × 血統）して、血統の寄与を位置取りの有利不利から分ける。(3) 荒れ度の事前予測（フィールドの拮抗度・人気の割れ方）ができれば、荒れ度 × 血統グループの安定した関係（オラクルで t=3〜5）を未知のレースに使える可能性がある。

11. 限界・注意

  • 回収率は確定オッズ・確定払戻での値で、購入時点のオッズとは違う（直前オッズの蓄積後に再検証）。区間はレース単位ブートストラップで、年をまたぐ自己相関は考慮していない。
  • 外国産馬（マル外）のフラグは取得していない（生産国は horse_profile から）。系統は名前の正規表現で創始者に寄せた近似。
  • 6〜10 世代は 5 世代 JSON の連結で作り、各祖先の 5 世代表が欠けた枝の深い血量は 0 になる（被覆は 99.99% 以上）。
  • 適性の指標（芝−ダ、長−短、距離の傾き）は馬 1 頭あたりの出走が少なく信頼性が低い。『近さと適性の対応が弱い』という結論は、血統の寄与が小さいのではなく、個体の適性を測る側の誤差が大きいことの影響も受ける（補正後の相関を併記）。
  • p_win は V4（2022〜2026 の推論済み）の確率で、V5 の OOF は 2022〜2024 のみ。V5 での確認は深い血量の回帰（7.4）と特徴量の増分（9）に限る。
  • 学習型の GNN（親 → 子のメッセージ伝播を学習する）は未実施。学習なしの再帰（構成埋め込み）が同じ伝播をパラメータ無しで行い、制約（実質同じ配合が最近接）を満たしたため、学習型は『近さの定義』ではなく『適性を直接予測する埋め込み』として別の課題にした（自己教師の損失設計と、同配合でも適性が違うことの扱いが要る）。
  • Node2Vec は小さな学習量（約 2.6 エポック）。十分に学習させても節点の ID を支配的に使う設計は変わらないが、順位の数字は目安。
