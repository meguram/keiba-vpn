1. 結論

  • 最良の方式は C1 二値 + 相対化 + 前段3列（p_win LogLoss 0.21722）。基準 A1（二値）の 0.21823 から -0.00100（95% 信頼区間 -0.00144〜-0.00075、3/3 fold で改善）。
  • 確率をレース内で合計 1 にそろえる（M1）だけで 0.00258 改善する（A1 の正規化前 0.22081 → 後 0.21823）。モデルを変えるよりも大きい改善で、必ず最終段にかける。
  • tp-04 で採用した前段の 3 列（s_time_pred ほか）は、二値でも -0.00051（95% 信頼区間 -0.00075〜-0.00028）と、効果が統計的に確認できた。
  • ランキング系（lambdarank・rank_xendcg）は温度 T=1 では較正が悪い。検証 fold で T を最適化した値（楽観的な参考値）では二値・softmax と同等まで届く。実運用の確率には使えず、順位付けの用途に限る。
  • 1 位的中率は全方式で約 30%、NDCG@3 は約 0.51 と、方式間の差が小さい。確率の質（LogLoss・race_nll）で差がつく。

8. 解釈と次の実験

  • 最終候補は 2 つに絞られた: 二値 + 相対化 + 前段 3 列（LogLoss 0.21722）と、softmax + 相対化 + 前段 3 列（0.21731、race_nll は 2.0491 と二値の 2.0483 に近い）。差は 0.00009 と小さく、方式の違いによる誤差の多様性が期待できるため、両方を残してアンサンブル（tp-05e）で合わせる。
  • softmax は p_top2・p_top3 を直接出せない。馬連・ワイド・3連複の確率には、Plackett–Luce／割引 Harville で p_top2・p_top3 を導く必要がある（既存の exotic_probabilities.py と接続して検証する）。
  • ランキング系の温度は、過去 fold で決めた T を使った評価に直す（今回は検証 fold で最適化した楽観値）。
  • tp-05b: CatBoost・XGBoost・線形（条件付きロジット）・NN（GPU）を、同じ条件で比べる。tp-05c: 時間減衰の重み、2020〜2021 年の扱い、early stopping。tp-05d: 上位候補だけを Optuna で調整（今回は固定パラメータ）。
  • 注意: 今回は固定パラメータ・3 seed・3 fold で、市場オッズとの比較は未実施（tp-06）。絶対的な強さは、市場の暗黙の確率との差で判断する。
