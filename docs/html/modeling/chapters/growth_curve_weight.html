成長曲線（馬体重の変化とパフォーマンス）の特徴量化（tp-39）

横軸 = 出走日、縦軸 = パフォーマンス指標・馬体重としたときの『体重が増えると上がる馬／減ると上がる馬／無関係な馬』を馬ごとに判別し、該当レースの補正ポイントを V4 に足せるかを検討した。履歴の無い馬・浅い馬には、年齢・性別・馬格・季節の母集団の成長曲線を使う設計を加えた。調教タイムから成長・調子を読む案は別（tp-40）。

要点.
第 1 段で採用基準を満たした群: KR_pt, KR_pro, KR_mga, GR_mga, GR_comp。
V4 全体への GBM 評価（第 1 段）は 19/19 群が完了。最良は GR_comp の Δ勝率 -0.00041（95% 上限 -0.00014）で、効果の最小値 0.0002 に届かない。残りの群は、ホストの重い処理が 3 本を超えている間は始めない規則で待機中（実行は自動で続く）。
馬ごとの傾きの個体差は、偶然とほとんど区別できない。10 走以上の馬で『増えると上がる』と判定された割合は、馬の中で体重の並びを入れ替えた帰無分布との差が -1.5〜+0.2 ポイント、『増えると下がる』は +0.1〜+3.2 ポイント（体重差・体重差の大きさで負側が増えるのは母集団の傾向）。前半と後半の傾きの相関は r = -0.011〜+0.019（帰無の標準偏差は約 0.01）。
傾きの真の個体差 τ² は、観測された傾きの分散の 0〜12%（縮約後は事実上、母集団の傾きに寄る）。馬ごとの傾きを縮約せずに使うと、予測は大きく悪化する（二乗誤差が +30% 前後）。
母集団の成長曲線には山型の形がある: 若い馬（2〜3 歳）は体重が大きく変わるとむしろ上がり、4 歳以上は増減どちらでも下がる（大幅増・大幅減とも −0.06〜−0.15）。ただし V4 はこれをほぼ吸収していて、V4 の勝率の残差は体重変化の帯の全てで ±0.5 ポイント以内。
母集団の成長曲線を縮約の事前分布として使う効果は小さい。体重差の母集団の応答表は R の予測で二乗誤差を 1.2% 減らす。履歴の浅い馬（対 1〜2）で、縮約先を母集団曲線にしても全体の傾きと有意に変わらない（差 +14.9×10⁻⁴ [-1.9, +32.6]）。履歴 0 走の馬は馬格の表で二乗誤差が 1.3% 減る（95% 区間は 0 を含まない）。
軽い一次選別（V4 の確率に特徴量を 1 つ足す条件付きロジット）: 試した 479 個のうち 2024 年で t<−2 は 12 個（偶然でも約 11 個）、2023 年は 2 個。最良でもレース当たりの負の対数尤度が -0.00051（基準 1.93 に対し 0.03%）。
補正 LightGBM（軽い GBM 評価）: 全ての馬で学習した場合の Δ勝率は -0.00013〜+0.00024、2 つの検証年とも 95% 上限が負になった集合は 0 個。履歴 0〜2 走の馬だけで学習・評価した場合も -0.00036〜+0.00059、2 年とも上限が負は 0 個。分割や群で符号が揺れ、履歴の浅い馬にも効く成長曲線の補正は見えない。
