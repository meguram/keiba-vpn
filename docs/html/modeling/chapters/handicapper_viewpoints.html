2026-10-21、ユーザー依頼『特徴量のやり残しの確認。特に X で予想を出している人の考え方は参考になる気がする。任意のレース名で検索して情報を取得してほしい』への回答。前段の棚卸しは 特徴量のやり残しの棚卸し。学習・評価は走らせていない（読み取りと集計のみ）。効果の数字は 見込み で、実測ではない。

要点.
  • X の本文は 1 件も取れなかった（ログイン無しでは取得経路が無く、検索エンジン経由はボット判定で止まった。ログイン・アカウント作成・判定の回避はしていない）。代わりに note の公開検索 API と無料記事 を使った。15 レース名で 53 回検索し、記事 388 件（無料 267 件）→ 本文 257 件を取得 → 重複を除いて 249 本 を集計した。
  • 観点の上位は、馬場状態・バイアス、ペース・展開、世代・クラス、脚質・決め手、オッズ・妙味（いずれも 249 本のうち 3 回以上言及するのが 5 割前後）。上位の観点はほぼ V5 の特徴量に入っているか、試して不採用だった（4 章）。

  • データが無い観点は、風・気温（6%）、パドック・返し馬（23%、予測時点 T-60 より後）、映像で見た不利（13%）、外厩（9%、取得元未確認）。

4. モデルに足す価値がありそうな観点（優先度つき）

見込みは V5 に足したときの勝率 LogLoss の差の目安（全体）。記事の頻度は、効果の証拠ではなく「現場が重視している」度合い。1 群が 2 段階（valid 2022〜23 → 2024・新 seed）を通って採用される確率は 1 割に満たない、という棚卸しの実績は変わらない。採用基準・test 2025 と 2026 年を選択に使わない点も同じ。

#観点記事での頻度見込みデータ先読みリスクと対策評価の特記
N1当日・前日のレースから見た馬場の実測の偏り（新規）当日・前日の傾向に触れる 21%、開催週・コース替わり 40%−0.0000〜−0.0003可（確定結果の通過順・着順・上がり・枠。開催日程）中。対象レースの確定前の結果は使わない: 同じ日の先のレース（発走が対象より前で、結果確定済み）と前日までに限る。運用では T-60 の再予測で当日の確定結果を取り込めるかを確認静的な偏り（fdr_*）・馬場状態・前日の馬場は入っている。足りないのは「その日に実際に出た偏り」。作り方の例: 先のレースの上位馬の枠順位・最終コーナーの位置と着順の相関、先行馬の勝率と脚質分布からの期待との差。標本が少ない午前の R1〜R4 は縮約し、R 番号別に層別して報告。馬の脚質（履歴）との交互作用は GBM に任せる（tp-58 の交差探索とは別に、この特徴量を入力に渡す）
N2進路のロス・包まれ・外回し（棚卸し 2・6 の根拠を補強）56%（3 回以上 33%）、外を回す・ラチ沿いの語だけでも 38%−0.0002〜−0.0006（棚卸しと同じ）可（horse_lap の内外・位置、被覆は要確認）低（過去走のみ。取得率が年で違えば時代の見分け特徴になる）棚卸しの 6 候補のうち、記事での言及が最も多いのがこれ。着順・着差に出ない「ロスの有無」が一番の差分情報と見られているため、再学習前の第 1 段で最優先にする

N1 は棚卸しの 4 章の候補に追加するか判断する段階で、評価は未実施。再学習の前にやるなら、N2 と同じ第 1 段（V5 の 1,142 列に足す）で同時に評価できる。v6-features・feature-cross-search（tp-58）と重なる部分: ラップ予想（tp-55）の入力には「同日の先のレースのラップ」と「コース別の直近の傾向」が入っているが、通過順・枠の偏りの実測を勝率モデルの特徴量にした記録は決定ログに無い。v6 の結論が出てから重なりを確認して N1 に着手する。

5. 予想家の書式から見えたこと

  • 観点の大半は文章で書かれ、数値化されていない。数値化している型（独自指数、想定オッズ対必要オッズ、進路クリア利得、熱負荷のような独自の指標名）は、同じ観点を指標に名づけたもので、効果の検証結果は付いていない。
  • 観点が事後に足される。外れた後に「大衆的な思い込みでペナルティを二重に付けていた」「〜を一貫して評価に組み込むべきだった」と観点を書き換える記述が複数あった。観点が増えるのは当たりやすさの証拠ではなく、後知恵の可能性がある。
  • 同じ観点でも向きが割れる。前走の不利は「買い材料」と「その不利が今回消えるかが肝」の両論があり、同じ週・同じ競馬場の内外の有利不利も書き手によって逆の読みになっている。データで決めるしかない論点。
  • 記事は出走前に書かれ、馬体重とパドックは「当日確認」と明記しているものが多い。T-60 に馬体重が出てから予測する現行の運用と同じ前提。
  • 市場との比較（必要オッズ）で買い目を決める型は、当システムの期待値・推奨馬券の層と同じ位置づけ。確率の予測精度は特徴量側の問題で、ここは別。
