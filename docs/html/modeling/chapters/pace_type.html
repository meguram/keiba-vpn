展開タイプ（ペース × 隊列の凝縮度）と、展開シナリオごとの各馬の確率（tp-61）

2026-10-21、ユーザー依頼（画面担当経由）。『逃げ・先行が向くのは、ハイペースでなく、かつ差しが決まりにくいペース（馬群が凝縮したスローは差しが決まりやすい）。その粒度でペース分析を』『向いた馬・不向きな馬が、様々な展開で優位になる予測を』『ハナを取りたい馬が複数いると単純なハイになりやすい。ペースの中の細分化を、レースラップの分析で確立』『ラップの分け方を、ネット上の文献から MECE に把握』。学習は 2020〜2023 年、選択 2024 年、確認 2025 年、2026 年はテストセット②（最終確認のみ）。市場オッズ・人気は特徴量に使っていない。

要点.
  • ご指摘の仮説は実測で支持された。ただし効くのは『ペース』と『隊列の凝縮度』の 2 軸の組み合わせで、ラップの細かい型（中緩み・加速の長さ）は脚質別の成績に上乗せしない。 2020〜2025 年の約 1.9 万レース（実測、2026 年は含めない）で、3 着内率を脚質ごとの平常値との比で見ると、スロー・縦長は逃げ 1.34／追込 0.71、スロー・凝縮は逃げ 1.17／追込 0.94（信頼区間は重ならない）。ミドルでも縦長は逃げ 1.15／追込 0.79、凝縮は逃げ 0.86／追込 1.10 と逆向き。ハイ・凝縮は逃げ 0.64／追込 1.44 で最も差し寄り、ハイ・縦長は脚質差が小さい（逃げ 0.86／追込 1.11）。
  • 馬単位の LogLoss（学習 2020〜2023 → 検証 2024・2025）で、位置取りだけのモデルに対し、ペース 3 段階は 勝率 −0.00125・複勝 −0.00255、隊列の凝縮度（連続値）を足すと −0.00239・−0.00433。凝縮度の追加分はペース 3 段階の追加分と同程度で、文献のラップ型 6 つに分けても 3 段階に上乗せしない（−0.00132・−0.00259）。
  • 文献の分類を軸に分解して MECE の規則にした（軸A 前後半のバランス → 軸B 中盤の緩み／軸C 加速の長さ → 軸E 隊列）。全レースがちょうど 1 つの型に入り（規則の網羅をテスト）、6 型の頻度は 5.8〜36.5%。データ駆動のクラスタ（k-means）とは一致が低い（ARI 0.14）。『文献の型で足りる』ではなく、成績を分けるのは『ペース 3 段階 × 隊列 3 段階』。
  • ハナを取りたい馬が多いほどハイ寄りという仮説は、方向は支持（条件を揃えて、直近 5 走の 1 角先頭率が高い馬が 1 頭増えるごとに前半 3F が約 0.15 秒速い）。ただし 2 頭から急に変わる閾値は無く、1 頭目から効き、ハイ（上位 25%）になる割合は 0 頭 24% → 1 頭 27% → 2 頭 32% → 3 頭以上 34% と、2 頭いても 7 割はハイにならない。事前予測の増分は小さい（ペース LogLoss −0.0039、隊列は 0）。
  • 事前（前日〜T-60）に出せるか: 隊列は出せる、ペースは 3 段階の UI 判定より明確に良いが限定的。 2024・2025 年（学習 2020〜2023）のペース LogLoss は 現行 UI の 3 段階 1.046 → 0.995（正解率 48.0 → 49.2%）、lap_forecast（tp-55）0.985、両者を混ぜて 0.977〜0.985。隊列は事前分布 1.080 → 0.959（正解率 52.5%）。9 通りの展開の当たり率は 26%（最頻でも約 19%）。2026 年（テストセット②、学習 2020〜2025）でも保たれた（ペース 0.980・隊列 0.942）。
  • 展開シナリオごとの各馬の確率は、表示・説明用。最終モデルの確率に『想定位置取りの効果』をシナリオごとに足してレース内で合計を戻す。展開が当たっていた場合の上限（オラクル）は 複勝 −0.0005、勝率 −0.0003〜−0.0004（2026 年は −0.00006）と小さく、事前の確率で重み付けすると ±0.0001 以内（精度は変わらない）。最終モデルが既に展開・脚質の特徴を持つため、精度向上ではなく『この馬は展開次第で何が変わるか』を見せる情報として使う。

6. 展開シナリオごとの各馬の確率（scenario_forecast）

方式: 最終モデルの勝率・連対率・複勝率（p）に対し、シナリオ（ペース p × 隊列 q）ごとに logit p_s = logit p + φ(想定位置取り)·(B_pace[p] + B_shape[q]) を足し、レース内の合計を勝率 1・連対 2・複勝 3 に戻す。φ は（想定位置取り−0.5, その 2 乗, 欠損）。係数は 2022〜2025 年の実測の展開で最尤推定（L2 正則化）。『出走馬ごとの展開への適性（過去の成績を展開別に見た履歴）』も足して試したが、上乗せは無かった（オラクルの LogLoss が同じ）ので入れていない。

  • 事前の確率で重み付けした確率は、最終モデルの確率から ±0.00015 以内（精度は変わらず、悪化もしない）。したがってこの確率を馬券の判断（EV）には使わない。表示・説明用。
  • 馬ごとに『展開の感度』（9 通りの勝率の logit の標準偏差）、最も有利な展開、ペース別の印（◎○）を返す。感度は位置取りの極端な馬ほど大きく、中団の馬は小さい。

8. 限界と次の一手

  • 隊列の凝縮度は最終コーナーの通過順位の記法（約 99% のレースで読める）に依存し、『差の数』は馬身そのものではない（'-' は 1 馬身以上）。馬群の幅を距離（m）で持つデータは無い。
  • 事前に出せるのはペースが約 49〜51%、隊列が約 53%、9 通りでは 26%。展開は確率として見せ、1 つに決め打ちしない。
  • 書籍・学術論文・JRA 公式の用語集は未調査。note の解説記事の範囲での整理である。
  • scenario_forecast は精度向上にならなかった。出走馬ごとの『展開への適性』（過去走を展開別に見た履歴）も上乗せしなかったため、展開の効果は位置取りでほぼ説明される。次に試す余地は、馬体・脚質を細かく分けた適性（追込の中でも長く脚を使うタイプ／瞬発タイプ）と、進路ロス（棚卸しの候補 2・6、馬ごとの区間ラップ）。
