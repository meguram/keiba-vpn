めぐ指数の印（好走に値する馬）と、過去走の集約方式の比較（tp-66）

ユーザー依頼（2026-10-21）:「めぐ指数の観点から、好走に値する馬の選別をしてマーキングしてほしい。ただし、過去のめぐ指数の挙動を分析したうえで、一番効果のある取り方（近 N 走の同条件平均か、最高値か、別か）を反映してほしい」。指数は絶対指数 megu_index_v3a_abs_robust（status ok）。評価の期間は、選択 2022〜2023 年、確認 2024 年、最終 2025 年、2026 年はテストセット②（選んだ規則の確認だけ）。モデルの確率は 2022〜2024 年が V5（LightGBM 単体）の out-of-fold、2025〜2026 年が最終モデルの予測。市場の値（人気・払戻）は評価にだけ使い、指標には使わない。スクリプト: tp66_lib.py / tp66_eval.py / tp66_rules.py、API: megu_mark.py。

1. 結論

  • 最も効く取り方は v3b（直近 5 走を、新しい走ほど重い加重 Huber で。低信頼の走は重み半分）。レース内の順位の判別力（3 着内に対する AUC）が選択 0.672・確認 0.673・最終 0.668 と、直近 1 走・平均・最高・中央値・同条件の平均/最高より高く、3 期間とも同じ順位。単純な「最高値」（0.641・0.640・0.636）や「5 走の平均」（0.640・0.644・0.638）は劣る。
  • 同条件走だけの平均は、V5 に足せる情報が最大（3 着内の LogLoss が V5 に対して −0.00039、区間 −0.00055〜−0.00024）。ただし同条件の走がある馬は 7 割だけで（v3b は 86%）、2025 年（最終モデルへの当てはめ）では −0.00010 と区間が 0 を跨ぐ。単独の並べ方としては v3b に劣る（AUC 0.642）ため、主役にはしない。
  • 印の規則（採用）: v3b がレース内 1 位で、そのクラスの突破ライン（class_benchmark）以上＝めぐ◎、2〜3 位で突破ライン以上＝めぐ○。◎は 79% のレースに 1 頭付き、3 着内率 47.9% / 47.5% / 48.0% / 47.7%（選択 / 確認 / 最終 / テストセット②）、出走馬全体の平均に対する倍率 2.13 / 2.09 / 2.14 / 2.10。○は 1 レースに平均 1.1 頭で、倍率 1.67 / 1.66 / 1.66 / 1.68。4 期間とも変わらない。
  • 正直な位置づけ: 表示用の補助。V5 の確率に足せる新しい情報は小さい。V5 の確率の最上位 1 位の倍率は 2.74 / 2.80 / 2.83（人気 1 位は 2.80 / 2.86 / 2.84）で、◎（2.05 前後）より高い。v3b を V5 に足した LogLoss の差は、3 着内 −0.00018（区間 −0.00030〜−0.00007、2022〜24 年の年を 1 つ外す当てはめ）だが、2025 年は +0.00007（区間 −0.00011〜+0.00026）で確認できない。V5 が低評価（4 位以下）の馬を◎○の上位から拾っても倍率は 0.94〜1.09（無作為並み）、6 位以下では 0.65〜0.79（無作為より悪い）。つまり「人気以上の好走」を見つける印ではなく、V5 が高い馬の裏付けとして見る印。複勝の払戻回収率も 0.81〜0.85 で市場並み（控除率の範囲）。
  • 大差負けの下限（同じレースの勝ち馬 − 40 点）は、絶対指数（robust）ではほとんど効かない（走の 0.007% にしか掛からない）。下限を入れた版と入れない版で順位・倍率は同じ。API では使わない（勝ち馬の指数が要るため）。

4. 印の出し方と使い方

  • 出さないとき: 出走が 6 頭未満のレース、そのクラスの突破ラインが無いレース（クラスが読めない・基準の表に無い。評価期間では約 18%）、過去走のめぐ指数が無い馬（初出走・指数が計算できない馬）。理由は megu_mark.unavailable（突破ライン未満・上位 3 位より下のときは reason）に入る。
  • API: /api/race/{id}/predictions の各馬に megu_mark（key = top / good / null、label、value（v3b の集約値）、margin（突破ラインとの差）、line、rank、z、n_runs、reason、unavailable）。規則は config/megu_mark.json、計算は src/pipeline/inference/megu_mark.py（compute_marks）、expected_megu.attach_expected_megu から呼ぶ。環境変数のフラグは無し（表やめぐ指数が無ければ何も付かない）。
  • 画面: めぐ指数の専用テーブルに「めぐ印」の列（◎は橙の塗り、○は橙の縁。押さなくても順位が分かる）、並び替え「めぐ印」、凡例（上記の注意書き）。印の根拠（レース内の順位・集約値・突破ライン比）はツールチップ。出馬表の行には出さない。
  • excusable（不利などの一過性の低下）の除外はしない: megu_excusable（tp-69）で、判定した走を集約から除くと次走予測が悪化したため。API の expected_megu.recent[i].excusable* は「参考: 一過性の可能性」の表示用で、印の計算には使わない。

5. 限界

  • V5 を上回る情報は確認できていない。印は「めぐ指数の観点で、直近の走が良い馬」を示す説明用で、予測・馬券判断の根拠は AI の確率と期待値。
  • 突破ラインは過去の水準（2023〜2025 年の 2 着馬）で、評価は各年の前年までの基準を使った。実運用の基準（3 年分）とは少し違う。
  • 2025 年・2026 年のモデルの確率は最終モデルの予測で、2022〜2024 年の out-of-fold とは別物。V5 への追加の説明力は、2022〜24 年の当てはめと 2025 年で符号が揃わない（上の注意）。
  • 評価に使った期間では、3 着内率の安定は 4 期間（テストセット②を含む）で同じだが、②の選択には使っていない。
