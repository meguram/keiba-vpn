騎手の乗り替わり（有力↔非有力）に期待値はあるか

2026-10-22、ユーザー質問『有力ジョッキーへの乗り替わり、およびその逆で期待値が取れるものがないか』への回答。 資料: 馬具・条件替わり（tp-32、JOCKEY 群）・騎手・調教師の分析と回収率（tp-59）・馬券で回収率 100% を超える余地の探索（tp-36）・決定ログ。 回収率は『1 出走（1 点）に 100 円』。区間はレース単位ブートストラップ。選択は 2021〜2024、test 2025 は最良の数セルの評価 1 回、2026 年はテストセット②（選択に使わない。記述のみ）。市場オッズは払戻の計算と比較にだけ使い、特徴量には使わない。

要点（先に答え）.
  • 期待値が取れる乗り替わりの型は見つからなかった。事前に列挙した 38 セル × 単勝・複勝 = 76 本のうち、選択期間（2021〜2024）で平均利益が正になったものは 0 本。White の Reality Check の p = 1.00、Holm 補正後の最小 p = 1.00。回収率の区間の下限が 100% を超えたセルは無い。
  • 主な 4 型（NE・EN・EE・NN）の単勝・複勝回収率は（選択・2025・2026 を通して）65〜87% で、継続騎乗（単勝 72%・複勝 74%）や全体（約 70%）と区別できる優位は無い。有力への乗り替わり（NE）は 人気になりすぎも過小評価もされていない（オッズ帯の期待払戻との差は単勝 -2.8 円/100 円、複勝 +1.6 円）。
  • モデル（V4 の勝率）に対する実績の比は、NE が選択 1.05 → 2025 0.94 → 2026 1.01、EN が 0.96 → 1.02 → 0.97 と、1.0 の周りを年ごとに上下するだけで、方向が続く型は無い。モデルはすでに乗り替わりの影響を織り込んでいる。
  • 『逆』（有力→非有力）も同様。人気が下がって妙味が出る、という形跡は無い。唯一、選択期間で有意に悪かった層は『有力→非有力で、前走 1〜3 着の馬』（単勝 63%・複勝 71%、オッズ帯の期待を単勝 -17 円下回る。76 本中でも Holm 後に有意）だが、2025・2026 は期待並みに戻った（単勝 73%・83%）ので、『避ける』根拠としても採らない。
  • 凍結する候補は無い（tp-59 の手順では、選択期間の Holm 補正後に残った候補だけを凍結して前向き追跡する。今回は残らなかった）。特徴量化も、tp-32 の JOCKEY 群（乗り替わり・格の差）が V4 に対して増分なしだった結論と整合する。

1. 事前に固定した設計

  • 有力ジョッキー: その日より前の直近 365 日（当日を含まない）の平地の勝利数の上位 N 人（同数は騎乗数、次に ID）。回収率は定義に使わない。N = 10 が主、5 と 20 は感度。jockey_id がキー（名前では結合しない）。
  • 前走騎手の格も『今日時点の』順位で測る（現騎手と同じ物差し。tp-32 の jk_rate_prev と同じ考え方）。前走が不明（2020 年以前の履歴）の出走は除く。障害は除く。
  • 型: 継続 / 非有力→有力（NE）/ 有力→非有力（EN）/ 有力→有力（EE）/ 非有力→非有力（NN）。
  • 仮説の族: 型 4 + NE・EN それぞれの層別 17（テン乗り/戻り、前走着順 3、今走人気 3、芝/ダ、新馬未勝利/1 勝以上、距離 3、同厩舎の主戦への乗り替わり、減量騎手→一般）= 38 セル × 単勝・複勝 = 76 本。結果を見てから増やさない。
  • 選択期間 2021〜2024（2020 年は 365 日の窓が埋まらない助走）。test 2025 は選んだ最良の数セルを当てて見る 1 回。2026 は記述のみ。
  • 検定: 買ったレースだけで、レース単位の利益の平均が 0 より大きいか（片側 t）。Holm 補正と White の Reality Check を併用。絶対の回収率（> 100%）と、オッズ帯の期待払戻を引いた超過払戻（市場が値付けを間違えているか）の 2 通り。
  • 減量騎手・外国人・短期免許: データに見習いの印（▲△☆）が無いため、見習い減量は『同じ性齢の最頻の斤量より 2kg 以上軽い（8 頭立て以上）』の代理指標。外国人・短期免許は ID で区別せず、勝利数の順位に任せる（短期免許は 365 日の平地勝利数が少なく、ほぼ非有力に入る。通年で上位の外国人騎手は有力に入る）。
  • モデルの予測は tp-59 の master にある V4（predictions_v3、2022 年以降）。V5/v6e の馬ごとの予測は、同じ形では持っていないので使っていない（V5 の gain の約 1% が騎手・調教師系で、結論を変える大きさではない）。

6. 限界と、次にやること

  • テン乗り（その馬への初騎乗）は 2020 年以降の履歴で判定している。それ以前に乗っていた騎手は『初騎乗』と誤判定され得る（戻りの一部が混ざる）。
  • モデルとの比較は V4。V5/v6e の馬ごとの予測を持つ表ができれば、同じセルで比を取り直せる（結論が動く可能性は小さい）。
  • ここでの回収率は『セルの馬を全部買う』形で、EV の高い馬だけを選ぶ形ではない。NE/EN に EV 条件を重ねる検証は、tp-59 の凍結規則（単勝 EV ≥ 1.5 と騎手・調教師の残差）が前向き追跡中なので、そちらの結果が出てから重ねる。
  • 『有力』を勝利数にしているので、1 年で急に有力になった騎手（若手の台頭）は遅れて有力に入る。定義を増やすと多重比較が増えるため、今回は変えない。
