期待値の水準の監査（控除率との整合）

ユーザーの疑問（2026-10-20）: 複合馬券の期待値が本当に控除率を加味した水準（約 0.8）になっているか、高く設定されていないか。2022〜2025 年の 13,041 レース（V4 の leave-one-year-out と bundle_v4_2024 の予測、確定オッズ、確定払戻）で調べた。オッズは締切後の確定オッズで、購入時点の値ではない（tp-36 と同じ限界）。

要点.
  • オッズ側は控除率どおりだった.確定の単勝は Σ(1/オッズ) = 1.260（期待 1.25）、馬連 1.294（1.290）、馬単 1.334（1.333）。確率側も勝率・連対率・複勝率・各組合せの総和が理論値に一致した（誤差 0）。『期待値の合計』を計算する式そのものに誤りは無い。
  • 『全部の期待値の平均が 0.8』にならないのは正常（市場とモデルが違うから）.モデルの確率が市場の確率と一致するときだけ EV は払戻率になる。モデルが市場より尖っている（人気薄の確率が市場より高いことが多い）と、全組合せを均等に見た平均 EV は払戻率より高く出る。実際に全組合せを 1 点ずつ買った回収率は、単勝 70.2%・馬連 58.0%・ワイド 60.5%・3連複 50.6% で、払戻率（80/77.5/75%）より低い（人気薄の過剰な人気＝favorite–longshot bias）。市場の確率を入れたときの馬連 EV の平均 0.57 は、この実現回収率 0.58 とほぼ一致する（計算は正しい）。
  • 水準が高く出ていた箇所（明らかな誤り 2 つ）.(1) 連対 EV = 連対率 ×（単勝オッズ × 1.65）は、市場の馬連プールと整合する連対の公正オッズの平均 4.44 倍で、全馬の平均が 4.08、98% の馬が EV≥1 だった。これが買い推奨度（最大の EV が 1.2 以上で『強推奨』）と買い目提案（馬連・馬単）の EV に入り、ほぼ全馬が強推奨、提案の 93% が『高』になっていた。(2) 複勝 EV の払戻に使う (下限+上限)/2 は、実際の払戻より平均で約 9% 高い（複勝の Σ(1/中央) = 3.43 ＜ 3.75）。
  • モデルの EV が実現回収率より高いのは、直したのとは別の問題（モデルが市場に勝てていない）.本番の確率 × 確定オッズの EV は、馬連で平均 1.07、実現は 0.58。EV が 1.05〜2 の帯の実現回収率は 65%〜67% で、EV に比例して上がらない（縮約係数 k は単勝 0.20・複勝 0.24・馬連 0.11・ワイド 0.10）。
  • 画面の指標は絶対水準が高い.レース価値の色分けで『オレンジ』（期待回収率 150% 以上）が 85% のレースに付き、その平均の期待回収率 228% に対し実現は 103%。順序（オレンジ＞緑＞青）は保たれるが、水準は信じられない。
  • 対応.(1)(2) は修正した（連対は『馬連プールと整合する公正オッズ』、複勝は実効オッズ = 下限 + 0.3×(上限−下限)）。縮約（EV_adj = 払戻率 + k×(EV − 払戻率)）は設定ファイル config/ev_calibration.json で用意したが、既定は無効（有効にすると買い推奨度とレース価値の判定が縮約後の値になる）。

2. 確率側の恒等式

V4 の勝率・連対率・複勝率の合計と、本番の割引 Harville（連対率・複勝率へ α を当てはめたもの）の馬連・ワイド・3連複・馬単の総和は、すべて理論値（1・2・3・1・3・1・1）に一致した（0.0 の誤差）。一方、旧経路（app.py の _compute_composite_scores）は勝率を softmax し直すため、pred_score に logit(勝率) を入れる v3/v4 の保存形式を通すと、本命の勝率が平均 1.17 倍に膨らむ（平均の絶対誤差 0.011）。この経路は影モード（shadow）の表示には使われておらず（local_predictions は勝率をそのまま使う）、v3/v4 の予測を『predict』で出すときに通さないよう注意が要る。また v3/v4 の保存形式（v3_payload）は連対率・複勝率を place_prob / show_prob に入れるが、推奨ポートフォリオ（BettingOptimizer）は top2_prob / top3_prob を探していたため、predict に切り替えると α が連対率・複勝率に当てはまらず既定値になる状態だった。両方のキー名を読むように直した（本章の検証は連対率・複勝率へ当てはめる本来の形）。

8. 直したことと、直していないこと

  • 直した（既定で有効）: 連対 EV を『馬連プールと整合する公正オッズ』（market_top2_fair_odds、λ = 0.9、払戻率 0.775）に。複勝 EV の払戻を実効オッズ（place_effective_odds、下限 + 0.3×(上限−下限)）に。画面の API には place_odds_eff を追加し、place_odds_avg（表示用の平均）は残した。
  • 直した（キー名）: _RankContext が place_prob / show_prob も連対率・複勝率として読む（v3/v4 の保存形式で α を当てはめるため）。
  • 用意した（既定で無効）: src/utils/ev_calibration.py と config/ev_calibration.json。有効にすると buy_recommendation_tier（買い推奨度）と value_level（レース価値の色）が縮約後の EV で判定する。
  • 直していない: 買い目提案（race_bet_suggestion）の組合せ券の『EV』は、構成馬の単独 EV の平均という近似のまま（実オッズが無い時点で出すため）。推奨ポートフォリオ（BettingOptimizer）は実オッズ × 割引 Harville の正しい EV。EV の高い順に上位を選ぶ以上、選ばれた買い目の EV は選択バイアスで高めに出る（winner's curse）。

9. 限界

  • オッズは締切後の確定オッズ。購入時点のオッズ（T-60・T-15）で出る EV は、確定オッズに向かって動く分だけ異なる。
  • 3連複・3連単は過去の確定オッズが無く、較正できていない（3連単のバックフィル後に再検証）。
  • k は 2022〜2025 年の当てはめで、モデルが更新（v5 など）されれば変わる。有効にする前に、更新後の予測で当てはめ直すこと。
