確率の較正（予測と実績の差）— 市場と組み合わせて人気馬の「来ない」の過小評価を縮め、期待値の信頼性を上げる（tp-70）

依頼（2026-10-21）: 『現行の複勝確率は、人気馬の来ないを過小に見積もっている（予測 4〜9% の馬が実績 15〜17%）。この差分は期待値計算の大きな障害になる。実測値と予測値との差分が大きすぎる。改善したい』。市場のオッズ・人気はモデルの特徴量にはしない。較正と馬券の判断にだけ使う（Benter 型ブレンドと同じ位置づけ）。2026 年はテストセット②で、較正器の選択・係数には使わず最終確認だけ。

要点. ずれの原因は『モデルが市場から離れるほど自信過剰』で、実績はモデルと市場の間（食い違いの両端でモデル寄り 0.34〜0.48）にある。logit(p_cal) = a + w1×logit(p_model) + w2×logit(p_market) をレース内で合計 1/2/3 に合わせる較正（勝率の係数: モデル 0.31・市場 0.76）で、生に対し LogLoss は勝率 −0.0049・連対 −0.0073・複勝 −0.0076（2023〜25 年、2026 年は −0.0077/−0.0114/−0.0124）、人気区分別のずれ・低確率の人気馬のずれ（7.4pt→1.6〜3.0pt）・EV の信頼性（0.31→0.05〜0.08）・組合せ券の確率が改善する。ただし 個々の馬の見分け（人気馬の低確率層は較正後も約 16% 来る）は直らず、2026 年は勝率・連対でモデルが市場に追加情報を持たない。頑健に 100% 超と言える馬券は見つからない。導入はフラグ（KEIBA_PROB_CALIBRATION=1、既定オフ）つきの提案まで。

8. 導入案（本番反映はしていない）

  • 係数: config/prob_calibration.json（2022〜2025 年の V4 OOF で当てはめた、目的ごとの 3 係数と人気区分別 6×3 係数。再作成は python -m src.scripts.data.tp70_fit export --base base.parquet --out config/prob_calibration.json）。既定は勝率=ブレンド(C3)、連対・複勝=人気区分別(C6)。
  • 適用: src/utils/prob_calibration.py の calibrate_entries(entries, odds_by_horse, market_is_real=True)。フラグ KEIBA_PROB_CALIBRATION=1（既定オフ）のときだけ有効。8 頭未満・単勝オッズが全頭揃わない・オッズが予測オッズ（モデル由来で独立な市場ではない）のときは何もしない（従来の確率）。
  • 差し込み位置: src/api/local_predictions.py のエントリ生成ループの直前（pw, p2, p3 = … の行）と、src/api/app.py の prob_list の直後（ライブ採点）。較正後の確率を win_prob/top2_prob/top3_prob に入れ、元の確率は win_prob_model/top2_prob_model/top3_prob_model に退避して API で両方返す。以降の EV・印・買い判断・推奨・割引 Harville は、そのまま較正後を使う。UI は『AI 予測の確率』（モデル）と『市場補正後の確率』（EV・印・推奨に使う）を並べて出す。
  • 二重較正の整理: tp-49 の EV 単調回帰（config/ev_calibration.json）は生の EV 用。フラグ有効時は、較正後の確率から作った EV でcalibrate_ev.py を当てはめ直す（またはフラグ有効時は tp-49 を恒等に）。そのままだと二重に補正する。
  • 消印: しきい値 8% は生の V4 確率で設計した。フラグを有効にするなら、較正後の確率で tp67 の手順（Clopper-Pearson 上側限界）をやり直す。
  • V5: V4 の OOF で当てはめた係数を V5 の 2025 年予測（final_eval_v5）に適用しても V4 と同じ改善（複勝 LL 0.4039→0.3971、V4 は 0.4047→0.3974、人気区分別のずれも同じ形）。V5 は V4 と同じ方向のずれなので係数は共用できる。V5 の LOYO OOF が揃ったら当てはめ直す。（この確認の係数は 2025 年を含めた当てはめで、評価は甘い。差は V4/V5 間の比較として読む。）
  • オッズの時点: 係数は確定オッズで当てはめた。T-60/T-15 のオッズで使うと、市場の情報量が少ないぶん市場側の係数が大きすぎる。直前オッズ（T-10/T-5/T-2）が貯まったら、時点別に当てはめを比べる。
  • ドリフト監視: 週次の drift_monitor に『較正後の ECE（人気区分別）とモデル−市場差』を足す（tp70_fit compare の指標）。係数の再当てはめは、警告（連続 2 週）が出たときに実行。
  • ロールバック: KEIBA_PROB_CALIBRATION を外して API を再起動（コードは変更しない設計）。

9. 結論（正直な整理）

  • 縮まる部分: 人気区分別の平均のずれ（1 人気 +5.6pt → −2.3〜−0.3pt、低確率の人気馬 7.4pt → 1.6〜3.0pt）、LogLoss（生に対し勝率 −0.0049／連対 −0.0073／複勝 −0.0076）、EV の信頼性（|予測−実現| 0.31→0.05〜0.08）、組合せ券の確率（−1〜3%）、◎の勝率（+1.6pt）。2026 年も同方向。
  • 縮まらない部分: (1) 個々の馬が来るか来ないか（人気馬で確率が低い馬が約 16% 来る）。(2) 2026 年の勝率・連対ではモデルが市場に追加情報を持たない（C3 でも市場と同等）。モデル側の情報が弱っている（調教データの欠損など、drift 診断の主因）ことは較正では直らない。(3) 100% 超と頑健に言える馬券は見つからない（単勝の較正後は区間下限 82〜94%、複勝 C6 の閾値買いは下限 96〜98%）。
  • 推奨: フラグ付きで導入して、画面は『AI 予測の確率』と『市場補正後の確率』を併記（ユーザー判断）。複勝 EV（C6）の閾値買いは前向き追跡へ。
