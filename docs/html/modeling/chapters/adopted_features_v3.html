採用している特徴量（アンサンブル v3・301 列）

現行の最終モデル（アンサンブル v3）が使う特徴量を、意味のあるグループに分けて示す。数は、ホストの final_v3/bundle_2025/bundle.json にある 7 メンバーの feature_cols の和集合（301 列）を、列名の接頭辞ごとに数えたもの。採否の根拠は 確定事項ログ（§N）。調査全体は 調査の全体像。最終更新: 2026-10-17。
