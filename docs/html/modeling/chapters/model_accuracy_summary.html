モデル精度の総括（train / valid / test）

これまでに作った予測モデル（アンサンブル v1〜v4）の精度を、学習に使ったデータ（train）・調整に使ったデータ（valid）・最後に一度だけ見るデータ（test）で並べた総括。あわせて、予測確率の帯ごとに実際はどれだけ起きたか（較正表）を載せる。各実験の数値の正は 確定事項ログ（§N）、調査の全体は 調査の全体像、特徴量の採否は 特徴量調査の総覧。最終更新: 2026-10-19。

1. 読み方

  • train: 最終モデルが学習に使った 2020〜2024 年の 235,458 行（17,230 レース）を、同じモデルでもう一度予測した精度（in-sample）。モデルが学習データをどれだけ覚えているかの目安で、実力の評価には使わない。
  • valid: 2022〜2024 年を 1 年ずつ「その年を除いて学習したモデル」で予測した精度（leave-one-year-out＝LOYO）。特徴量の採否やモデルの選択に使った。
  • test 2025: 2020〜2024 年だけで学習したモデルで 2025 年（3,455 レース・47,497 頭）を予測した精度。選択に使わず、最後に評価した。実力に最も近い数値。
  • 指標: LogLoss は予測確率の外れ具合（小さいほど良い）。AUC は「実際に起きた馬を、起きなかった馬より上に並べられる確率」（大きいほど良い、0.5 がでたらめ）。基準の一様予測は全馬に 1/頭数（勝率）などを割り当てた場合。
  • valid と test は年が違うので、数値の大小は単純には比べない（test 2025 は valid より易しい年だった可能性がある）。

3. 過学習の読み方

  • train と test の差（test − train の LogLoss）: v3 は勝率 +0.01370、連対 +0.01248、複勝 +0.01151。v4 は +0.02031 / +0.01863 / +0.02197 と、v3 より 1.5〜2 倍大きい。v4 は 1,135 列・5 つの種（seed）・補助損失つき NN と、モデルが学習データを覚える余地が大きいため。
  • それでも test は改善している: 差が広がっても、test の勝率 LogLoss は v3 0.21039 → v4 0.20740（決定ログの paired bootstrap で差 −0.00303、95% 上限 −0.00216）。学習データへの当てはまり（train）の改善（v3 0.19669 → v4 0.18709）より小さいが、未知の年でも効いている。
  • valid と test の差: v4 は valid 勝率 0.20936 に対し test 0.20740 と、test の方が良い（v3・v2・v1 も同様）。valid に選択を寄せた楽観はなく、2025 年が全体にやや易しい年だった可能性が高い（原因は未検証）。
  • train の AUC は v3 0.860 → v4 0.882、test は 0.823 → 0.831。train の伸びが test の伸びの約 3 倍で、今後さらに列やメンバーを足すほど、train と test の差は広がりやすい。採否は引き続き valid と paired bootstrap で決め、train の改善は根拠にしない。

4. test 2025 の使用回数

2025 年の test は、v1（tp-06）・v2（tp-06b）・v3（tp-06c）・v4（tp-06d）の4 回、モデルの精度の評価に使った（各回の記録は決定ログ §8・§9・§30・§34）。以降、この年での特徴量やモデルの選択はしない。2026 年は学習にも評価にも使っていない（データが未完全）。

5. 予測値のレンジ別の成績（較正表）

予測確率の帯（「勝率 0.10〜0.20 と予測した馬」など）ごとに、実際にどれだけ起きたかを見る表。予測が現実と合っているかを確かめる。対象は最新の v4（v3 は末尾に折りたたみ）。データは test 2025（2020〜24 学習・一度だけの評価）と valid 2022〜24（LOYO）の 2 つ。

5.1 帯の決め方と列の意味

  • 帯は固定の境界で切った: 勝率は 0.02・0.05・0.10・0.20・0.30・0.50、連対率は 0.05・0.10・0.20・0.30・0.50・0.70、複勝率は 0.10・0.20・0.30・0.50・0.70・0.85（各帯は「下限以上・上限未満」）。分位ではなく固定にしたのは、「予測 0.1〜0.2 の馬」のように意味を読めるようにするため。頭数が 400 未満の帯には※少数を付けた（誤差が大きい）。
  • 平均予測: その帯の馬の予測確率の平均。実際の発生率: その帯の馬のうち、実際に 1 着（連対率は 2 着以内、複勝率は 3 着以内）になった割合。予測 − 実際が正なら予測が高め、負なら低め。95% 信頼区間は発生率の誤差の幅（Wilson 法）。区間に平均予測が入っていれば、その帯の予測は現実と合っている。
  • 単勝・複勝回収率: その帯の馬を毎回 100 円ずつ買ったとして、払戻の合計 ÷ 投資額（確定払戻から計算、払戻が取れたレースのみ。取得率: 単勝 13,804/13,824 レース、複勝 13,609/13,824 レース）。オッズは予測に使っていないので、市場とは独立に予測した確率の帯でどれだけ払戻があったかを見る参考値で、買い目戦略の評価ではない。複勝は払戻が桁をつなげた形式のレースがあり、分け方が一意に決まるものだけを使った。

5.4 読み方

  • 全体として予測は現実とよく合っている。多くの帯で平均予測と実際の発生率の差は 0.01 以内で、信頼区間に平均予測が入る（最上位の帯だけ 0.02〜0.04 の差）。test と valid の両方で同じ傾向。
  • 最上位の帯はやや高めに出る。勝率 0.50 以上は test で予測 0.584 に対し実際 0.541（予測が高め、頭数 333 と少なく区間は広い）、valid では逆に 0.577 に対し 0.593。複勝率 0.85 以上は test・valid とも予測がやや高め（test 0.910 → 0.873、valid 0.914 → 0.898）。極端に高い予測（勝率 0.5 以上、複勝率 0.85 以上）は、数字より少し割り引いて読む。
  • 最も低い帯もわずかに外れる。複勝率 0.10 未満は test・valid とも予測がやや高め（予測 0.045 → 実際 0.040 前後）。頭数が多い帯なので、小さくても差は本物。
  • 回収率は、おおむね全帯で 80〜90% 台（単勝・複勝の控除率に近い）。予測が高い帯ほど回収率が高い、という関係は見えず、予測確率だけで買って儲かる帯はない。これは確定オッズ（市場）が同じ情報をすでに織り込んでいることと整合する（決定ログ §10・§20・§23 の結論と同じ）。唯一、勝率 0.02 未満・複勝率 0.10 未満の最低帯は 50% 前後と低く、大穴を買うほど損という傾向。最上位帯は valid で 91〜99% と高めだが、test では 85〜93% で、頭数が少なく安定しない。
  • この表は「予測確率を、確率としてどれだけ信じてよいか」を見るもの。馬券の期待値は、予測確率と投票時点のオッズの差で決まる（回収率の検証は時点別オッズの蓄積後に取り直す、決定ログ §30）。

6. 未掲載・今後

  • v3・v4 の区分別（芝・ダート、距離、頭数、障害）と確信度別（予測 1 位の馬の確信度ごとの的中率）の内訳は、本章では未掲載。v2 までは総合実験結果の章にある。必要になったら、保存済みの test 予測（final_eval_v3|v4/test2025_predictions.parquet）から同じ形で出せる。
  • 年別（2022・2023・2024・2025）の精度の並びも未掲載（年によって難しさが違うため、valid と test の差を読むのに役立つ）。
  • v1・v2 の train は、学習済みモデルを保存していないので算出できない（再学習すれば出せるが、現行の判断には使わない）。

7. 計算方法・実行記録

  • train の再予測: python -m src.scripts.data.accuracy_summary --version v3|v4。最終バンドル（final_v3/bundle_2024、final_v4/bundle_v4_2024、2020〜2024 年で学習）を読み込み、学習に使った行（2024-12-22 までの 235,458 行）をEnsembleBundle.predict で再予測して、LogLoss と AUC を計算。バンドルと学習表は読み取りのみ。実行は 2026-10-19、ホスト（stg）で nice -n 15・4 スレッド・直列。所要は v3 が約 5 分、v4 が約 8 分。
  • 較正表と valid・test の再計算: python -m src.scripts.data.accuracy_calibration。test は final_eval_v3|v4/test2025_predictions.parquet、v4 の valid は tp27/ens/v4_e2.parquet、v3 の valid は各メンバーの OOF を ensemble_v3/ensemble_spec.json の重みで合成。着順と払戻は data/page_reference/tables/<年>/race_result_flat.parquet。
  • 出力（ホスト）: data/local/modeling/training_pipeline/accuracy_summary/ の train_v3.json、train_v4.json、calibration.json。
