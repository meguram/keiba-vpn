数値の前提（2026-10-16 時点）: このレポートの精度・回収率は、2026-10-15 の track_bias 先読みリーク修正（同日の後のレースの結果が当日傾向の特徴量に混ざる不具合）より前の LayerA・特徴量で出した値です。修正後の表で影響を測ったところ、勝率 LogLoss の差は +0.00003（95% 上限 +0.00011）で影響は無視できる大きさでした（確定事項ログ §24）。この数値も相対比較の結論も、そのまま使えます。確定事項は 学習パイプライン確定事項ログ を参照。

1. 結論

  • 現行パイプライン（v2（新特徴量 + アンサンブル v2））の test 2025（2020〜2024 年で学習、3,455 レース・47,497 頭を一度だけ評価）の最終精度: 勝率 LogLoss 0.2124（AUC 0.817）、連対率 LogLoss 0.3318（AUC 0.809）、複勝率 LogLoss 0.4172（AUC 0.802）。一様予測は勝率 0.2588・連対率 0.4104・複勝率 0.5168。
  • 予測 1 位の馬が勝つ割合 30.8%（ランダムなら 7.3%）、連対する割合 50.1%、複勝圏に入る割合 62.5%。勝ち馬が予測上位 3 頭に入る割合は 63.2%。
  • v1（tp-06）は 勝率 0.2135 / 連対率 0.3332 / 複勝率 0.4189。追い切り評価・厩舎コメントの特徴量とアンサンブル v2 で、3 指標とも有意に改善した（§3.5）。
  • 確率は「レース内で合計 1・2・3 にそろえる」処理を最終段で必ず適用する（これだけで勝率 LogLoss が約 0.0026 改善）。
  • 馬券の強化学習（tp-08、test 2025、確定オッズ）: 控除率を上回る優位は見つからなかった（回収率は 100% 未満）。自由に見送れる設定では全レース見送りに落ちる。1 レース平均の賭け金に下限（予算の 50%）を課した最良の方策の回収率は 88.5%（95% 信頼区間 86.0〜91.2%）（取消馬の不具合を直した再評価〔tp-09〕では 88.3%・複勝のモデル 1 位 84.5%。差は 0.3 ポイント以内で結論は同じ）。単純な基準（複勝のモデル 1 位 84.6%）より +3.9 ポイント（95% 信頼区間 +1.7〜+6.4）有意に高く、単勝 1 番人気（78.0%）を大きく上回るが、損失を小さくする配分であって、利益が出る賭け方ではない。詳しくは §4。

4. 馬券最適化の強化学習（tp-08）

訂正（2026-10-16）: 下の tp-08 の数値は、買い目の表で取消・除外の馬（単勝オッズ = -3.0）を「オッズ 1.0 の本命」として扱っていた不具合を含む補正前の値です。tp-09 で同じ設定を再評価した結果は、RL 基本 88.3%（95% 信頼区間 85.7〜91.0%）、複勝のモデル 1 位 84.5%、馬連のモデル 1 位 86.6%（補正前 88.5% / 84.6% / 86.8%）で、差は 0.3 ポイント以内。結論（確定オッズでは控除率を上回る優位が見つからない）は変わりません。表の各区間・差の信頼区間は再計算していません。

予測（v2）の勝率・連対率・複勝率から、割引 Harville で単勝・複勝・馬連・ワイド・馬単の各組の確率を作り、市場の暗黙の確率と Benter 型でブレンドする。1 レースを 1 ステップとし、候補の買い目への賭け金の配分（予算 1 = 1R の予算、残りは見送り）を方策勾配で学習する。報酬は実際の払戻 − 賭け金。学習 2022〜2024（ハイパーパラメータは 2023・2024 を評価年にした Optuna）、test 2025 は一度だけ。オッズは締切後の確定オッズで、購入判断の時点の値ではない（楽観側に偏りうる）。三連複・三連単はオッズが無く対象外。
