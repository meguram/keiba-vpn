特徴量調査の総覧（採用・不採用・保留と今後の調査）

これまでに行った特徴量・前段モデル・モデル構造の調査を、概要・結果・採否つきで 1 か所にまとめた一覧。数値の正は 確定事項ログ（各行の「節」列、§N）で、ここは総覧として要約している。現行モデルの特徴量そのものは 採用している特徴量、調査全体の流れは 調査の全体像。最終更新: 2026-10-19（モデル別のまとめを追加）。

1. 読み方

  • 評価指標: 勝率（p_win）の LogLoss（予測確率の外れ具合。小さいほど良い）の差。負が改善。例えば −0.00100 は LogLoss が 0.001 下がったこと。比べる相手（基準）は行ごとに違うので、行の注を見る。
  • 採用の基準（主に 2026-10 以降の調査）: 95% 信頼区間（paired bootstrap＝同じレースで対にして何度も取り直した幅）の上限が 0 未満、効果が 0.0002 以上、連対・複勝の悪化が 0.0002 以内。初期（tp-03〜06）は「全 fold で悪化せず、平均が改善し、改善幅が閾値以上」。試す群が多いと偶然の改善が混ざるため、第 1 段（valid 2022・2023）と第 2 段（2024 と新しい seed）で確認し、最終は累積（tp-27）とアンサンブルで確かめる。
  • 評価に使う年: valid は 2022〜2024 年。test 2025 年は最終評価で数回だけ見て、特徴量の選択には使わない。2026 年は学習にも使わない。
  • 採否の記号: 採用＝現行モデル（v3 または v4）に入っている / 不採用 / 保留・進行中・未検証。
  • 共通ルール: 市場オッズ・人気は特徴量にしない。統計量は「そのレース日より前のデータだけ」（as-of）で作り、先読み（将来の結果が過去行に混ざること）のテストを付ける。騎手・調教師・馬・種牡馬・馬主は ID をキーにする。

3.6 M6 荒れ度の予測（tp-30）

  • 荒れ度（log 3 連複配当・log 勝ち馬人気・log 3 着以内の平均人気・−人気と着順の順位相関の平均）を、レース条件とメンバー構成から予測。R² 0.13（オッズなし）／0.20（確定オッズ代用）、荒れ上位 20% の AUC 0.67／0.71。
  • M1 の特徴量としては不採用（文脈列 −0.00009〜+0.00003、温度調整 +0.00013）。買い目の幅（3 連複のフォーメーションを荒れ度で変える 16 戦略）も、同点数の固定と有意差なし（reality check p=0.39／0.99）。副次: 3 連複は予測確率の上位 n 点のほうが同点数の箱より回収率が高い（10 点 0.833・20 点 0.823・20 点の箱 0.748）。
  • 今後: 実オッズでの再検証。

3.7 M7 出遅れ確率（G6）

  • 代理ラベル（SmartRC のテン 1F の外れ値・初角の位置）での統計 50 列＋確率予測 5 列は、valid 2022〜24 で −0.00003（上限 +0.00017）で不採用。妥当性: スタート指数との Spearman −0.55、備考の「出遅」との AUC 0.73、馬ごとの再現性（split-half）0.20。
  • 備考の「出遅」を実ラベルにした版（直近 3 年 20,386 頭、ラベルのある走 31.9 万）: ラベルのある走は「その後も走った馬」に偏る（2022 年は勝率が 13.5% 対 3.8%）ので、学習はラベルのある走だけ・検証は全員にラベルのある 2024 年に限った。22 通りのうち第 1 段（2024-01〜06）の最良は p_slow の −0.00073（上限 −0.00019）だが、第 2 段（07〜12・新 seed）は −0.00005（上限 +0.00040）で再現せず不採用。馬ごとの偶奇相関は 0.59、p_slow の AUC は 0.70〜0.76。スタート指数は 2024 年以降の一部のみで学習には使えない。章 slow_start_real_label。
