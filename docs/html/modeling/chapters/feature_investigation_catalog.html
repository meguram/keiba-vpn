特徴量調査の総覧（採用・不採用・保留と今後の調査）

これまでに行った特徴量・前段モデル・モデル構造の調査を、概要・結果・採否つきで 1 か所にまとめた一覧。数値の正は 確定事項ログ（各行の「節」列、§N）で、ここは総覧として要約している。現行モデルの特徴量そのものは 採用している特徴量、調査全体の流れは 調査の全体像。最終更新: 2026-10-19。

1. 読み方

  • 評価指標: 勝率（p_win）の LogLoss（予測確率の外れ具合。小さいほど良い）の差。負が改善。例えば −0.00100 は LogLoss が 0.001 下がったこと。比べる相手（基準）は行ごとに違うので、行の注を見る。
  • 採用の基準（主に 2026-10 以降の調査）: 95% 信頼区間（paired bootstrap＝同じレースで対にして何度も取り直した幅）の上限が 0 未満、効果が 0.0002 以上、連対・複勝の悪化が 0.0002 以内。初期（tp-03〜06）は「全 fold で悪化せず、平均が改善し、改善幅が閾値以上」。試す群が多いと偶然の改善が混ざるため、第 1 段（valid 2022・2023）と第 2 段（2024 と新しい seed）で確認し、最終は累積（tp-27）とアンサンブルで確かめる。
  • 評価に使う年: valid は 2022〜2024 年。test 2025 年は最終評価で数回だけ見て、特徴量の選択には使わない。2026 年は学習にも使わない。
  • 採否の記号: 採用＝現行モデル（v3 または v4）に入っている / 不採用 / 保留・進行中・未検証。
  • 共通ルール: 市場オッズ・人気は特徴量にしない。統計量は「そのレース日より前のデータだけ」（as-of）で作り、先読み（将来の結果が過去行に混ざること）のテストを付ける。騎手・調教師・馬・種牡馬・馬主は ID をキーにする。
