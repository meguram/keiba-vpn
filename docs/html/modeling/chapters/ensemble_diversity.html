アンサンブルの幅出し（ランダムフォレスト・決定木・別の目的関数）とメンバー別・条件別のチューニング — tp-63

ユーザー要望: 今使っているモデル（LightGBM・NN）で幅を広げられないか。シンプルなランダムフォレスト（決定木）をアンサンブルに使えないか。さらに、レース質や全体特徴量を持つ学習器ごと、レース条件（コース・馬場など）ごとにハイパーパラメータを調整する余地。

要点.
  • 幅を広げて基準（効果 ≥ 0.0002・上限 < 0）を満たすメンバーは無かった。 V5 の 7 メンバーに足したのは、sklearn のランダムフォレスト（浅い・深い）、浅い決定木の袋詰め、単一の決定木、LightGBM のランキング（rank_xendcg）、芝ダ別の専門モデル、直近 3 年だけ・半減期 2 年の重みの LightGBM、ロジスティック回帰、レース質（ペース段階）別の専門モデル、レース質の事前確率を入力に足した LightGBM。現行の合成（勝率 weighted_logit、連対・複勝 greedy）では、どれも重みが 0 になり、増分は 0.00000（レース質別の専門モデルを実測の段階で選んだ「オラクル」だけが連対・複勝に重みを得て −0.00015）。
  • L3 型の合成（現行 + クロス対象 LR の logit 平均）の上で効くのは木系だけ: 浅い決定木の袋詰め（深さ 4、150 本）を足すと V5 の L3 比で勝率 −0.00012（上限 −0.00006、前進 −0.00011）、木 3 種（袋詰め・浅い RF・深い RF）を同時に足すと −0.00013（上限 −0.00007）、全 8 種を同時に足すと −0.00016（上限 −0.00005）と、連対・複勝も −0.0002 前後。どれも効果量 0.0002 に届かない（境界の少し下）。LightGBM 系の変種・線形・レース質別は L3 の上で ±0.00002 以内。
  • 木のメンバーは単独でも弱くない: 袋詰め 0.2172、浅い RF 0.2144、深い RF 0.2154（V5 の NN・線形は 0.2112〜0.2177、GBM は 0.2098〜0.2101）。ただし合成との残差相関は 0.987〜0.991 と高く、足りない部分は小さい。
  • V5 の 7 メンバーの多様性は NN・線形側にある: LightGBM・XGBoost の勝率 logit 相関は 0.986〜0.998（実質同じ）。1 本外して劣化するのは線形の +0.00023 が最大で、他は +0.00004 以内。『平均からのずれ』の実効次元は勝率で 1.6。
  • 条件別・レース質別のチューニングに旨味は見えない（専用モデルはどれも L3 の上で ±0.00002、実測のペース段階を知っていても −0.00015 で上限 −0.00004）。ハイパーパラメータは 220 列時点の調整（Optuna 40 試行）のままだったが、V5 の 1,142 列での感度を掃引すると、簡易設定では『葉 7・feature_fraction 0.5』が −0.0003〜−0.0007 見えたものの、フル品質で作り直すと勝率 +0.00017 の悪化（V5 の設定は平坦な最適付近）。条件別でも最適設定の向きは同じ。詳細は第 4 節。

1. 評価の枠と、これまでに済んでいた範囲

  • 土台: V5 の 7 メンバーの OOF（valid 2022・2023・2024 の 140,865 行）。現行の合成（勝率 weighted_logit、連対・複勝 greedy）と、L3 型（勝率・連対を『現行 + クロス対象 LR』の logit 平均、複勝は現行。tp-51 の S11e）が基準。追加メンバーは V5 と同じ 1,142 列、年の前進（検証年より前の全年）で学習した OOF。
  • 採否は既定の基準（95% paired-bootstrap・レース単位の上限 < 0、効果 ≥ 0.0002、連対・複勝の悪化 ≤ 0.0002）。LOYO と前進の両方を出す。test 2025・2026 年は使っていない。市場オッズ・人気は使っていない。

5. 結論

  1. 『幅を広げる』余地は小さい。木系（浅い決定木の袋詰め・ランダムフォレスト）は単独で NN・線形に並ぶのに、V5 の現行合成では重み 0。L3 型の合成の上では勝率 −0.00004〜−0.00012（全 8 種同時で −0.00016、上限 −0.00005）と一貫して負だが、採用基準の効果量 0.0002 には届かない。L3 自体が境界（V5: LOYO −0.00024、前進 −0.00017）なので、木を足しても『境界の少し上』にとどまる。
  2. 効かない理由: 7 メンバーのうち GBM 4 本は実質同じ予測（logit 相関 0.986〜0.998）、木系を足しても合成との残差相関は 0.987〜0.991 のまま。多様性は NN・線形に偏り、足りない軸（目的関数・面・期間・レース質）を足しても、ラベルの雑音が残差の大半（残差相関 0.99 超）を占めるため、メンバー側では取れない。
  3. 推論コスト: 袋詰め 3.4MB、浅い RF 8MB、深い RF 21MB、LightGBM 変種は 1 本 25MB 前後（V5 のバンドル 168MB に対し、木 3 種で約 +33MB、全 8 種で約 +140MB）。いずれも許容目安（+230MB）以内だが、勝率 −0.00016 のために 8 モデルを増やす価値は小さい。
  4. v6 への提案: 次の最終学習（v6）で L3 を採用する場合に限り、『木 3 種を L3 の入力に足す』（約 +33MB、勝率 −0.00013、前進も同じ）を任意の追加として検討。単独では採用基準に届かないので、v6-features の評価で別の増分が出たときの『加算候補』にとどめる。現行の合成の重みを V5 のまま使うなら、木を足しても変わらない。
  5. メンバー別・条件別のチューニングは不要: V5 の LightGBM の設定は 1,142 列でもほぼ最適（調整後フル品質の再学習は対照より勝率 +0.00017・複勝 +0.0010 悪化、L3 比 −0.00001）。最適設定の向きは面・距離帯・馬場・クラス・頭数のどれでも同じで、条件別に変える利得は見えない。レース質の特徴を持つ学習器・レース質別の専門モデルも L3 の上で +0.00001、実測の段階を知っていても −0.00015（上限 −0.00004）で基準未満。
