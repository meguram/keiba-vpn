最終追い切りパターンの結論（コース別を含む）

2026-11-11 時点。最終追い切り（レース週の平日で最も良い調教）を、場所（坂路・ウッド・ポリ）× ラップ種別／4F 時計の帯で分類した『パターン』が、勝率・複勝率とどう結びつくかをまとめる。主な集計期間は 2020〜2025 年（調教の記録が読めた出走の割合が 8 割前後以上の年）。2026 年は使っていない。市場のオッズ・人気は使っていない。障害は除く。

結論（先に）.
  • パターンそのものには、前の期間から後の期間へ続く差がある。栗東坂路の A2/A3/A1 は勝ち・3 着以内に偏り、栗東坂路 B1、美浦坂路 X/B1、美浦ウッド（北）の遅い帯は偏らない。
  • 「コース特注の調教パターン」を立てて、コース（芝/ダート × 距離帯）ごとに数字を持つ意味は、予測の上ではほぼない。コース別のセルの値をそのまま使うと、パターン全体の値より後の期間を外す（2020〜22 → 2023〜24 で有意に悪い）。パターン全体の値へ強く縮めると、ほぼ同等になるだけ。
  • ただしコース固有の差が全くないわけではない。3 着以内の構成比で見ると、前後の期間で同じ向きに続くコース固有の差が小さく残る（相関 0.26 / 0.36）。続きやすいのは「上乗せ」より、噛み合わない組み合わせの割り引きの側。
  • これらを馬券の期待値に使えるかは未検証。
  • 2016〜2019 年の調教の取り直しは進行中（残り約 2 日）。終わったら 2016 年以降で再集計する。

1. 何を見たか

パターンは『所属・場所|ラップ種別』（坂路。A1〜X）、または『場所|4F 時計の 2 秒帯』（ウッド・ポリ）。2 つの向きで見た。

  • 向き A: そのパターンの馬は、無作為に選んだ場合に比べて勝つ・3 着以内に入る割合が何倍か（lift。レース単位で数える。1 = 無作為並み）。調教師の基準を引いた rel も出す。
  • 向き B: 3 着以内に入った馬の側から見て、そのパターンの構成比が、全出走の構成比に比べて高いか低いか（比 = 3 着以内の構成比 ÷ 全出走の構成比）。馬単位。

4. 向き B: 3 着以内の馬のパターン構成はコースで違うか

『特定のコースで 3 着以内の馬を集めれば傾向が見えるはず』という見方を、馬単位で確かめた。3 着以内の構成比は、全コースでほぼ共通の形をしている。

  • 栗東坂路 A2/A3/A1 は、どのコースでも 3 着以内に偏る（比 1.14〜1.93）。例: ダ~1200 の A3 は 1.93、芝~1200 の A3 は 1.93。
  • 美浦坂路 X・B1、栗東坂路 B1 は、どのコースでも偏らない（比 0.45〜0.77）。例: 芝1400-1600 の美浦坂路 X は 0.49。
  • 距離が長いコース（芝2200-2400・ダ1900~）では、栗東のウッド（Cウッド）の W50〜53.9 の帯が比 1.2〜1.3 に上がる。芝2500~ は函館ウッド・美浦ウッド（北）の W50〜53 台が上位（ただし 3 着以内 30〜50 頭台で、z は 1.6〜2.1 と弱い）。

5. 結論の読み方

  • 「コース特注の調教パターン」という強い意味での特注（あるコースだけ特別に効く）は、確認できなかった。多くのコース差は、パターン全体の効果を超えない。
  • 確かめられるのは弱い形: パターンが噛み合わないコースでの割り引き（栗東坂路 B1 の芝1400-1600、栗東の Cウッド W52〜54 台のダート短距離 など）。割り引きの側は 2 回とも同じ向きで残った（上乗せの側は 1 回目で消えた）。
  • 使い道を作るなら、パターン全体の値を土台に、コース差を強く縮めた小さな補正として足す形。V4 以降の予測へ足したときの増分は、まだ測っていない。

6. 限界

  • パターンは粗い（ラップ種別 A1〜X、時計の 2 秒帯）で、コースの特徴（坂・直線の長さ・馬場）と対応する細かい形（後半の加速の仕方など）は見ていない。
  • 距離が長いコースはセルが小さい（芝2500~ は 347 レース）。長距離での傾向は、まだ確かめられていない。
  • 向き B は所属（栗東・美浦）を揃えていない。所属がコースの好成績と結びついている分が、パターンの差に混ざっている可能性がある（例: 栗東坂路が全体に強い）。
  • 向き B の z は、ポアソン近似で過大。順位の目安にだけ使い、有意性の判断には使っていない。
  • 2016〜2019 年は調教の記録が少なく（2016 年の被覆 9% → 2019 年 57%）、集計に含めていない。
