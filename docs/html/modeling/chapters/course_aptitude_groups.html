期待とずれた馬のグループ差分によるコース適性（tp-29）

ユーザー提案: 『期待外れ（人気馬の凡走）』と『期待以上（人気薄の好走）』の 2 つの馬のグループの統計的な差を、コースへの相性の数値にできないか。

グループの定義. G1（期待外れ）= 期待順位 1〜3 位で、着順 6 着以降、かつ 3 着馬との着差（走破タイム差）が 0.3 秒以上。 G2（期待以上）= 期待順位 6 位以降で 3 着以内、または 4 着以降でも 3 着馬との着差が 0.2 秒以内（3 着以内とみなす）。 除外 = 着順 ≤ 0（取消・除外・中止・失格）、走破タイム ≤ 0 か欠損、期待順位が無い馬、3 着馬が定まらないレース。 期待順位は市場版 = 人気（過去レースのラベルを作る材料としてだけ使い、当日の人気は特徴量に使わない）と、モデル期待版 = v3 の OOF 勝率の順位（市場を一切混ぜない対照。OOF のある 2022〜2024 年のみ）の 2 通り。
コースは 3 階層（k1 場×面×距離×内外、k2 場×面×距離帯、k3 面×距離帯）。属性は種牡馬・母父・騎手・調教師の ID、脚質、馬番位置・枠、年齢・性別、斤量・馬体重・増減、前走間隔、クラス・距離の変更、同コース経験。 各コース×属性について G2 と G1 の出現率を縮約付き対数オッズ比で比べ、Fisher 検定 + BH-FDR（10%）で有意なものだけを使う。さらに『他のコース全体での G2−G1 の差』を引いたコース固有の超過（差の差、Wald 検定 + BH-FDR）も測る。 年 Y の行は『年 Y より前のラベル』だけで作った統計で採点する（先読みなし）。馬自身の G1/G2 履歴は日付が厳密に前の走だけを数える。

結論

  • 『G2 と G1 の差』の大半は、コースの特徴ではなく『人気馬と人気薄馬の一般的な違い』だった。有意な属性の多くは騎手・調教師・父で、どのコースでも G1 側に有力騎手・有力厩舎、G2 側に格下の騎手・厩舎が出る（人気の構成を映している）。この差だけで特徴量を作っても勝率予測は改善しない。
  • 『コース固有の超過』（他のコースの差を引いたもの）で有意に残るのはごく少数（k3 で 22、k2 で 7、k1 で 6）。内容はほぼ『脚質 × 面』（ダート短〜中距離で逃げ・先行が期待外れに多い、芝で逃げ・先行が期待以上に多い など）で、概形・距離の違いで説明がつく。
  • 人気を制御しても、適性スコアが『期待以上』『期待外れ』を当てる力は小さい（下表）。馬自身の G1/G2 履歴のほうが、コース由来のスコアよりやや効く。
