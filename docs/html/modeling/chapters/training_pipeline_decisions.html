49. 過去走の展開利と、次走の期待展開とのずれ（tp-64、結論: 方向は仮説どおりだが V5 への上乗せは基準に届かない見込み）

51. 確率の較正（予測と実績の差）の改善（tp-70、結論: 市場との対数線形ブレンドの較正で LogLoss・人気別のずれ・EV の信頼性が改善、個々の馬の見分けは直らない）

ユーザー指示 2026-10-21『現行の複勝確率は人気馬の来ないを過小に見積もっている。この差分は期待値計算の障害。改善したい』。章 prob_calibration_gap、スクリプト tp70_diag / fit / ev / exotic / marks / cond / report、モジュール src/utils/prob_calibration.py、係数 config/prob_calibration.json。

確定事項

  • 診断: 全体の平均は合っているが（ECE 0.002〜0.007）、人気区分別に系統的にずれる（複勝、1 人気は実績が予測より 5.9pt 上、10 人気以下は 1.8pt 下。3〜5 人気で予測 3〜10% の馬が実績 13〜29%）。モデルと市場の食い違いが大きいほど、実績は市場寄りに戻る（モデルの自信過剰）。モデルは市場に LogLoss で負けており、2026 年は全月で拡大（勝率 +0.004〜+0.013）。
  • 較正: logit(p_cal) = a + w1·logit(p_model) + w2·logit(p_market)（市場は単勝オッズ→Harville）をレース内で合計 1/2/3 に合わせる。前年までで当てはめるウォークフォワードで、生に対し LogLoss 勝率 −0.0049 [−0.0055, −0.0043]・連対 −0.0073・複勝 −0.0076（2023〜25 年）、2026 年 −0.0077/−0.0114/−0.0124。市場単独にも 2023〜25 年は全目的で勝つが、2026 年は勝率 +0.0003 [−0.0002, +0.0009]・連対 −0.0005 で同等（複勝は −0.0040 で勝つ）。人気区分別ブレンド（C6）は連対・複勝で僅かに良い（−0.0002／−0.0005）。GBM・食い違い項・ローリング再当てはめは実質差なし。複勝オッズを足しても改善しない。
  • 低確率の人気馬（1〜5 人気で生の複勝確率 10% 以下）: 生 7.5%／実績 14.9% が較正後 16.5〜17.9%。EV の信頼性: |予測−実現| 単勝 0.31→0.05〜0.08、複勝 0.19→0.03〜0.06。組合せ券の LogLoss −2〜3%。◎の勝率 32.2%→33.8%（2026 年 29.8%→33.0%）、★は 7,039→2,051 頭。
  • 馬券: EV 上位の購入の的中率は 3〜5 倍になるが、単勝の較正後の区間下限は 82〜94%。複勝 C6 の EV≥1.0〜1.2 は実現 101〜108%（下限 96〜98%）で、凍結して前向きに追跡する候補どまり。100% 超は頑健には言えない。
  • 導入案（提案のみ・本番未反映）: KEIBA_PROB_CALIBRATION=1（既定オフ）。8 頭未満・オッズ欠損・予測オッズのときは何もしない。API は元の確率（*_model）と較正後を両方返し、EV・印・推奨は較正後を使う。tp-49 の EV 較正は当てはめ直し、消印のしきい値も較正後の確率で設計し直す。V5 の 2025 年予測にも同じ係数で V4 と同じ改善。

申し送り

  • 縮まらない部分: 人気馬の低確率層は較正後も約 16% 来る（消印で 1〜5 人気 10% 以下を示せなかったのと同じ）。2026 年は勝率・連対でモデルが市場に追加情報を持たず、調教データの欠損（drift 診断）など入力側の問題は較正では直らない。
