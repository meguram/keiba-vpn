  • 控除率（単勝・複勝 20%、馬連・ワイド 22.5%、馬単 25%）を上回る優位は、確定オッズに対してモデルからは取り出せなかった。強化学習の方策が学んだのは「低控除で人気寄りの複勝・ワイドに分散して、損失を最小にする」配分で、利益が出る賭け方ではない。
  • 確定オッズは購入時点のオッズではない（締切後の値で、判断に使うオッズが結果的に有利な値になっている分、回収率は楽観側に偏る）。2026-10-17 以降に蓄積される T-60/T-15 のスナップショットで再検証する。
  • UI の「推奨馬券」の根拠として使うなら、「期待回収率 100% 超」を約束する表現は避け、「損失を抑える配分」と読めるようにする。期待回収率が高く出る買い目（穴馬の馬単・馬連）は実績が悪いので、期待値のしきい値だけで選ばない。
