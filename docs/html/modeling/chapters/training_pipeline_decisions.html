35. ドルメロ流（8 年周期）の活性値は予測に効かなかった

コード: src/scripts/data/dormello_bakeoff.py（tp-16 と同じ手順）、src/research/pedigree/dormello_activity.py。結果: data/meta/dormello/bakeoff_vs_base.csv。日本語圏の「テシオ理論」のうち、中島国治氏が紹介した「ドルメロ流」（種牡馬の誕生時点を 0 として 8 年周期で活性値が変わる）を、予測に使えるかの観点で検証した。

確定事項

  • 活性値の定義（年単位の近似）: 活性値 = (対象馬の受胎年 − 祖先種牡馬の生年) mod 8。受胎年は誕生日の 340 日前、無ければ生年の前年。余りが 1〜7 は流派によらず同じ値。余りが 0 は「0（ドルメロ流）か 8（自分流）か」が流派・記事で食い違うため確定させず、要検討ゾーンとして手入力できるシート（zone_review.csv）に出した。
  • 特徴量 8 列（馬ごとに固定の情報で、レース日以降は使わない）: 父・母父の活性値、3 代以内の最大活性値（優先祖先）とその世代、優先祖先が父か、ゼロ活性の個数、父のゼロフラグ、生年が分かる祖先の数。祖先の生年は netkeiba・Wikipedia・Wikidata から補い、生年が分かる組は 99.95%（3 代以内で 99.7%）。
  • 対照実験: 周期を 7・9・10 年に変えた同じ特徴量でも測り、8 年だけで効くかを見た。

解釈と申し送り

  • 不採用。8 年も対照の 7・9・10 年も、勝率の差は信頼区間（±0.00013〜0.00020）の中で 0 と区別できず、採用基準（上限 < 0、効果 ≥ 0.0002）を満たさない。連対・複勝はむしろ悪化側で、8 年だけが特別に効く証拠はない。tp-16 の近交係数（IB、差 −0.00001）と同様、血統まわりは既存の血統特徴量（種牡馬 ID×条件など）で説明される分が大きい。
  • この結論の範囲: 年単位の近似で、0 の組は未確定のまま扱った。優先祖先の「特性」（どの祖先の適性が伝わるか）や、牝馬側（基礎体力・空胎の持ち越し・連産の隔年）は入れていない。日付（月日）が揃えば 0/8 の境界を日付で判定できる可能性はあるが、年単位の特徴量に全く差が出ていないため、期待は小さい。
  • 根拠の面でも、検証した範囲では統計的な裏付けは見つからず（記事・座談会とも事例ベース）、生物学的な機構も確認できていない。モデルには組み込まない。要検討ゾーンのシートと生年月日のデータは、今後の再検証用に残す。
