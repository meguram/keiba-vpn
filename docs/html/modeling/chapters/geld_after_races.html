去勢明け 2 戦目以降の成績（tp-32 GELD の拡張）

tp-32 の GELD は『去勢明け初戦』だけを扱った（特徴量としては不採用）。ここでは去勢明けの 1・2・3・4–5・6+ 戦目ごとに、成績・回収率・現行モデルの予測とのずれ・去勢前との対応あり比較・層別を測り、特徴量化の見込みを簡易に評価する。再現: python -m src.scripts.data.geld_analysis run → chapter。

要点.
  • 初戦は明確に弱く、2 戦目から戻る。 同条件のセ馬一般との複勝率の差は 1 戦目 -7.4 → 2 戦目 -1.5 → 3 戦目 +2.2 → 4–5 戦目 +2.7 → 6+ 戦目 -0.4（ポイント）。同じ馬の 1 戦目→2 戦目でも複勝率の差が +4.2 [+1.7, +7.1] 改善する。
  • 現行モデルは初戦は少し過大評価、2 戦目は過小評価。 モデルの複勝率との差（2022–25）は 1 戦目 -2.3・2 戦目 +3.7。2 戦目の過小評価は 2023–2026 の各年で +5 前後（2026 年は記述のみ）で向きが揃うが、年ごとの区間は 0 をまたぐ。
  • 回収率に優位はない。 去勢明け 1 戦目の単勝回収率は 35 [19, 55]%・複勝 60 [41, 83]%（基準の牡馬一般 72%・74%より低い、買わない側の根拠）。2 戦目以降の合計は単勝 68 [55, 82]%・複勝 80 [73, 87]% で 100% を下回る（3 戦目の単勝 109% のように点推定が 100% を超える戦目もあるが、区間が [59, 167] と広く有意でない）。
  • 特徴量化の増分は小さい。 現行モデルの確率に『去勢後 N 戦目』の補正を足しても、2022–24 で当てはめ test 2025 で評価した対数損失は ±0.0002 以内で区間が 0 をまたぐ（採用基準に届かない）。既に gd_n_since 等の候補列があり、新規列を作る価値は薄い。

1. 定義とデータ

  • 対象: 2020–2026 年の芝・ダート（障害を除く）320,018 走・39,407 頭。
  • 去勢明け 1 戦目 = 直前の出走が牡で今回がセの最初の出走（1,466 頭）。以降を 2, 3, … 戦目。性別の表記は牡・牝・セの 3 種だけで揺れはなく、セ→牡の戻りは 0 件。
  • 最初に見えた出走が既にセの馬（763 頭）は去勢の時点が分からない（2020 年より前に去勢）ので、N 別の集計から除いて『セ馬一般』の比較対象にだけ使う。
  • N 別の走数: 1 戦目 1,466, 2 戦目 1,242, 3 戦目 1,020, 4-5 戦目 1,576, 6+ 戦目 4,480（2020–26 年の合計）。この章の N 別の表は 2020–2025 年（回収率とモデルとの差は予測のある 2022–2025 年）。2026 年は記述統計のみ。
  • 『同条件』= 芝ダ × 距離帯（1400/1700/2000/2500 で 5 区分）× クラス × 年齢（6+ 区分）× 休み明け（間隔 84 日以上）の平均（200 走未満のセルは粗いセルへ）。比較プールは 2025 年までの牡馬一般 / セ馬一般（自分自身と去勢明け 1–5 戦目を含めない）。
  • 現行モデルの勝率・連対率・複勝率は betting/tp36/frame_all.parquet（2022 年〜、ホールドアウトの予測）。市場オッズは回収率の計算にだけ使い、特徴量にはしない。回収率は『その馬の単勝（複勝）を 100 円ずつ買った場合』で、区間はレース単位のブートストラップ 1,000 回の 95%。

7. 結論と注意

  • 去勢明けは 1 戦目が最も弱く、2 戦目から戻り、3–5 戦目は同条件のセ馬一般を少し上回り、6 戦目以降は一般のセ馬と同じ。『2 戦目以降に特有の持ち越し』は見えず、初戦の反動が抜けるだけと読める。
  • 現行モデルは 1 戦目をやや過大評価、2 戦目をやや過小評価（約 +5 pt、年をまたいで同じ向きだが区間は広い）。3 戦目以降のずれは小さい。
  • 回収率は 1 戦目が低い（単勝 35%・複勝 60%、区間の上限も 100% 未満）。2 戦目以降は合計で 100% 未満で、区間の下限が 100% を超える層はない（層別で単勝回収率の高い層は走数 100 前後でばらつきが大きい）。
  • 注意: 去勢は不振のあとに行われるため、去勢前との比較には平均への回帰が含まれる。去勢の時点が分かるのは 2020 年以降に牡として走った馬だけ（旧来のセ馬は『時点不明』）。層別は多重比較。
