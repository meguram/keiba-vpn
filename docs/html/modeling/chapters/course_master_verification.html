要点: 周長・最後の直線の長さ・コース全体の高低差は、3 つの独立収集（JRA 公式 / netkeiba・競馬ラボ・Wikipedia / JRA-VAN・Wikipedia・bakendo）が 106〜107 行で許容誤差内に一致した。 食い違いの大半は定義の違い（ポケットから本線へ合流する曲線をコーナーに数えるか）で、一次資料での再確認（第 2 ラウンド）で誤りだった値を特定して訂正した。 最後の直線の長さは、実レースの「最終コーナーからゴールまでの順位変動」との相関（芝 0.62、ダート 0.84）でも独立に裏づいた。

ラウンド内容

4. 実データとの照合（第 3 ラウンド）

  • コーナー数: レース記録の通過順位の記録点の数（最頻値）は、C の値と 86 行中 80 行が一致。残りは記録の上限が 4 つであること、新潟芝2000 が内外混在（記録で外回り約 52%・内回り約 48%）であること、直線コースの記録点が 1 つであることで説明できる。
  • 最後の直線の長さ: 「最終コーナーからゴールまでの順位変動（頭数で規格化）」との相関が、芝 0.62（33 コース）、ダート 0.84（23 コース）。距離帯補正後も同じ。独立した裏づけ。
  • ゴール前の坂: 200m ラップの最後の遅れとの相関は −0.07（ダート）、−0.14（芝）で、裏づけにならなかった（距離・展開の影響が大きい）。坂は文書の一致（JRA 本文・図、JRA-VAN、Wikipedia）で確認した。
  • 内部整合: 直線 > 周長 の行なし。距離 / 周長 は 0.61〜2.16。芝の直線の順位（新潟外 658.7 > 東京 525.9 > 阪神外 473.6 > 中京 412.5 … 福島 292.0 > 札幌 266.1 > 函館 262.1）は既知の事実と一致。

5. 確認できていない項目・注意

  • 確定できなかった値は null にしてある: 中京芝3000 と 阪神芝1800 外 の最初のコーナーまでの距離、中京ダ1200・芝1400 の 3 コーナーまで（競馬ラボの 380m は転記ミスの疑い）、新潟芝1000（直線）の幅員。
  • 推定を含む値（確信度 medium）: 阪神芝1600 外 444m、阪神芝3000 内 354m。一次資料に数値がない。
  • コーナー半径はどの資料にも数値がない（定性表現のみ）。
  • 競馬ラボのコース解説は会員制のため、競馬ラボの値そのものは一次資料では検証できていない。
  • 2020〜2025 年のレース記録には内回り / 外回りの区別がない。同じ（競馬場・面・距離）に内外がある行（京都芝1400・1600、阪神芝1400、新潟芝1400・2000 など）は、特徴量では混合として扱う（新潟芝2000 だけは記録から割合が分かる）。
  • ゴール前の坂の位置・高低差のうち、図の画像処理で得た値は精度が低い（±0.1〜0.3m、位置 ±数十 m）。

6. 実形状（OpenStreetMap）との照合（第 4 ラウンド）

ユーザーからの指摘（スタートが特殊な位置にある、内回り・外回りで走るコース自体が違う、中山の芝外回りはおむすび型、東京2000m は専用の位置から出る）を受けて、コースの実形状を保持する形に作り直した。 OpenStreetMap の芝・ダート・障害コースの面（内外の帯と引込み線を含む）を骨格化し、周回路・ゴール・コーナー・各距離のスタートと経路を求めて、マスタの数値と突き合わせた （アトラスは実形状の図。データは data/meta/course_master/geo/、帰属は © OpenStreetMap contributors / ODbL）。

照合結果

7. 走行ルートの監査（第 5 ラウンド）

ユーザーから『アトラスの走行ルートに違うものがある。東京芝2000m のスタートなど』との指摘を受け、全 107 コースの図のスタート位置・通る区間を、独立した記述と突き合わせた。 独立した記述は、複数の第三者の資料（コース解説の最初の文など）を、調査者の手元で突き合わせたもの。資料の文章そのものは、著作権と利用規約への配慮から、公開リポジトリには含めない（手元のみで保管し、監査表には出典名と判定だけを残す）。収集A（JRA 図からの導出）は引込み線のコースで定型文のため、他の資料があるときは数えない。 表の『判定』は、図のスタートの区間（ゴール前の直線 / 3・4コーナー / 向正面 / 1・2コーナー / ゴール後の直線）が記述と合うか、最初のコーナーまでの距離が合うか。入力と結果は geo/start_descriptions.json・geo/route_audit.json。
