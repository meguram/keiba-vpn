クラス別の基準めぐ指数（突破ライン）

ユーザー依頼（2026-10-21）:「○歳XXX」というレベル感のクラスで、これを超えていればこのクラスは突破できそう、という基準めぐ指数が見たい。指数は絶対指数 megu_index_v3a_abs_robust（1点＝0.1秒、斤量55kg換算。めぐ指数 v3a）。集計期間は 2023〜2025 年（低信頼の指数・障害を除く）。

1. 結論

  • 基準はそのクラスの「2着馬」の指数で作ります。クラスごとに、2着馬の指数の中央値（そのクラスの標準的な水準）と、下位25%（突破ライン）を出します。2着馬は、めぐ指数の基準タイム自体が「2着馬の補正後タイムの平均」で作られていて物差しが揃うこと、勝ち馬のような大差勝ちの上側の裾が無いことから採りました。
  • 基準以上の馬は、未満の馬より勝ちやすく、3着内に入りやすい（2025年、基準は2023〜24年で作成）。ランダムに比べた勝率の倍率は、基準以上 1.48 倍・未満 0.77 倍（差 0.63〜0.79、レース単位の95%区間）。3着内率の倍率は 1.41 倍と 0.89 倍。
  • 勝ち馬基準・2着以内・3着以内でも、判別力は同等（区間が重なる）。2着馬は四分位幅が最も小さく、基準以上の馬の割合も極端でない（約66%）ため採用しました。
  • 突破を保証するものではありません。1走の指数のばらつきは約±10点（約1秒）あり、基準以上でも勝つ馬は 10.6% です。
  • 面（芝/ダ）は11のクラスで分け、距離帯は17の組合せで分けました（親との中央値の差が2点以上で、n≥30 のときだけ）。時期（前期・後期）は2歳・3歳限定戦で中央値が約2点違いますが、分けていません。

2. 基準の定義

  • クラスの正規化: race_class・grade・race_name から「年齢（2歳・3歳・3歳以上・4歳以上）× クラス（新馬・未勝利・1勝・2勝・3勝・OP・L・G3・G2・G1）」を読む。全角数字・表記ゆれを広く読み、年齢が読めないグレード戦はクラスのみで持つ。読めなかったのは障害の324レースだけ（障害は対象外）。
  • 突破ライン = 2着馬の指数の下位25%。最小件数は 30。セルが薄い・差が小さいときは親（面なし→年齢×クラス→クラスのみ）の基準を使う。使った階層は API の level に入る。
  • データ: 2023〜2025 年の 2着馬 9,061 走。再生成は python -m src.scripts.data.class_benchmark_build --years 2023,2024,2025 --basis second --out config/class_benchmark.json、検証は --evaluate --build-years 2023,2024 --eval-year 2025。

5. 画面での使い方と限界

  • 馬柱の上にクラスの基準（例:「3歳以上2勝クラス・ダ: 2着馬の中央値 54／突破ライン 50」）、各馬に「超えている／届かない 最高 62 ≥ 50」のバッジ、突破ライン以上の走に緑の数字と▲、出馬表の「直近指数」の列でも緑で出す。基準が無いレースは何も出さない。
  • クラスの基準は過去の水準（2023〜2025年）で、年や季節による水準の変化は含まない。
  • 障害は対象外。年齢が読めないグレード戦は、クラス全体の基準を使う。
