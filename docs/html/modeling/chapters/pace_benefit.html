過去走の展開利（展開に助けられたか）と、次走の期待展開とのずれ（tp-64）

2026-10-21、ユーザー提案『実際のレース結果をもとに、展開的に楽だったかを確かめて特徴量にできないか。展開が楽でパフォーマンスが高かった馬は、次走で展開が苦しくなりそうなときに好走率が下がるかも』。展開タイプ（tp-61）の実測ラベルを、過去走側に使う。スクリプト: tp64_build / tp64_hyp / tp64_eval / tp64_overlap、純粋関数 src/pipeline/features/tp64_pace_benefit.py、テスト tests/pipeline/test_tp64_pace_benefit.py。

要点.
  • 『展開利』は定義できて、標本外でも当たる。（セル = ペース3×隊列3 の 9 通り, 脚質）ごとに『その脚質の平均より着順がどれだけ良かったか』を、その年より前の年だけで推定し（縮約つき）、各走に当てはめた。次の年の走に当てはめて実際の着順の良さと比べると、相関 0.12〜0.14・回帰の傾き 0.97〜1.11（ほぼ 1 ＝ 単位が校正されている）。標準偏差は着順の 3.6〜3.9 パーセンタイル、全走の約 38% が ±3 パーセンタイル以上（恵まれた／不利）。
  • 仮説の半分は支持、半分は検出できない。V5 の OOF 確率に対する残差（実績 − 予測）で見ると、直近 1〜3 走で展開に恵まれていた馬ほど、V5 の複勝確率は過大（前走の展開利 上位 20% − 下位 20% = 複勝 −1.05 ポイント [−1.7, −0.44]、直近 3 走平均 −1.27 ポイント [−1.9, −0.62]。2022〜24 年、レース単位ブートストラップ）。一方、今走の期待展開利（事前のセル確率 × 脚質）そのものは残差と結びつかない（上位 − 下位 +0.22 ポイント [−0.34, +0.80]）。『恵まれた後に苦しい展開で下がる』という交互作用は、前走が好走の馬の 2×2 で方向は仮説どおり（恵まれ好走・今走が不利 −0.16 ポイント vs 今走が有利 +0.25 ポイント、不利でも好走・今走が有利 +0.79 vs 不利 −0.90）だが、区間は 0 を跨ぐ（差 −0.4 [−2.5, +1.5]、+1.7 [−1.1, +4.4]）。
  • V5 への増分は採用基準に届かない見込み。V5 の OOF への残差補正（LOYO、再学習なし）は全構成で Δ ≥ 0（ノイズ列の対照と同程度）、分位ごとの残差を完全に補正できたとしても改善の上限の目安は複勝 −0.00005・勝率 −0.00009 程度（基準 0.0002）。LightGBM に列として足す本評価は、ホストの共有スロットが埋まって順番が回らず未実施（第 5 節に実行コマンド）。重複: 展開利そのもの・ずれ・期待展開利は既存列と相関 0.19 以下の新規情報だが、補正後の着順・位置は既存列とほぼ同じ。

1. 展開利の定義（as-of）

  • セル: 実測のペース（スロー／ミドル／ハイ）× 隊列（凝縮／並／縦長）の 9 通り（tp-61 の race_cls.parquet の pace_cls・shape_cls。しきい値は tp-61 が 2020〜2023 年で固定）。脚質: その走で実際に取った位置 early_norm（0=先頭〜1=後方）を 逃げ ≤0.15／先行 ≤0.35／差し ≤0.65／追込 に分ける（tp-61 と同じ）。
  • 展開利 = −（そのセル×脚質の平均 fin_pct − その脚質の全体の平均 fin_pct）× n/(n+150)。fin_pct は 0=1着〜1=最下位（頭数に依存しない）。単位は『着順のパーセンタイル』で、正 = 展開に恵まれた。8 頭立て以上のレースだけで推定。
  • as-of: 対象レースの年を Y とすると、係数表は『Y より前の年』の結果だけで作る（2020 年の行は係数なし＝欠損、2021 年は 2020 年のみ）。過去走の展開利も、この表（Y 年版）を当てはめる。したがって、対象の年の結果は係数にも入らない。対象の走自身の結果が自分の特徴に入らないことは、書き換えテストで確認（test_features_do_not_use_own_result、test_table_excludes_target_year_and_later、test_prior_year_rows_unchanged_by_future）。
  • 展開補正後の着順 = fin_pct + 展開利（恵まれた分だけ悪く見直す）。

2. 今走の期待展開利

  • 今走の展開セルの事前確率 P(セル) は、レース前の量（tp-61 の pre.parquet: 想定隊列・先行頭数・ハナ主張馬・コース傾向など）から、年ごと leave-one-year-out の 9 クラス LightGBM で作る（tp-55 のラップ予想と同じ作法。2026 年は 2020〜2025 年で学習）。9 通りの LogLoss は事前分布 2.13 → 1.94〜1.96（2022〜2025 年、tp-61 の積 1.958 と同水準）。実運用では tp-61 の pace_type.py が同じ入力から出す確率に置き換える（本章の表は shared_cache/race_quality/tp64_pcell.parquet に race_id キーで置いた）。
  • 今走の脚質 = 直近 3 走の通過位置の平均から分類（馬柱の想定位置取りが無い学習行でも出せる）。期待展開利 = Σセル P(セル) × 係数表[セル, 今走の脚質]。ずれ = 前走（または直近 3 走）の展開利 − 期待展開利（正 = 恵まれた後に苦しい）。

3. 仮説の検証（V5 の OOF に対する残差）

V5 相当の OOF（v6/eval/oof_d_CY_BEST、valid 2022〜2024 年、約 14.1 万行）の確率に対する残差（実績 − 予測確率）を、レース単位のブートストラップ（1,000 回）で。『前走が好走（fin_pct ≤ 0.30）』の馬を、前走の展開利（恵まれ ≥ +3pt／不利 ≤ −3pt）× 今走の期待展開利（上位 1/3／下位 1/3。しきい値は 2022〜2023 年で固定）に分けた 2×2。

  • 恵まれ好走で『今走が不利 − 有利』= 複勝 −0.4pt [−2.5, +1.5]、不利でも好走で『今走が有利 − 不利』= +1.7pt [−1.1, +4.4]（勝率は +2.0pt [+0.08, +4.1]）。差の差（恵まれ好走の不利 − 有利）−（不利でも好走の不利 − 有利）= 複勝 +1.3pt [−2.3, +4.5]、勝率 +1.9pt [−0.6, +4.3]。方向は仮説どおりのものが多いが、4 グループに割ると標本が小さく、区間は 0 を跨ぐ。2024 年だけ（同じしきい値）では複勝の差が +0.3pt／+1.0pt で、勝率は恵まれ好走の不利 − 有利が −1.9pt [−4.3, +0.5]。
  • 連続値で見ると（前走好走に限らない全馬）: ずれ（前走の展開利 − 今走の期待）の上位 20% − 下位 20% = 複勝 −1.24pt [−1.89, −0.62]（2024 年だけ −1.09pt [−2.17, +0.03]）、勝率 −0.40pt [−0.83, +0.07]。前走好走に限ると −1.18pt [−2.41, +0.19]。
  • 効いているのは前走側（V5 の過大評価）: 5 分位の残差（複勝）は、前走の展開利で +0.59／+0.16／+0.07／−0.35／−0.46pt（上位 − 下位 −1.05pt [−1.70, −0.44]）、直近 3 走平均で +0.60／+0.24／−0.03／−0.10／−0.67pt（−1.27pt [−1.94, −0.62]）。今走の期待展開利は −0.13／−0.17／+0.10／+0.14／+0.08pt（上位 − 下位 +0.22pt [−0.34, +0.80]）、レース内相対も +0.41pt [−0.17, +1.05] で 0 を跨ぐ。多変量（標準化した複勝残差への回帰係数、1SD あたり）は 前走 −0.30pt [−0.59, +0.01]、直近 3 走平均 −0.24pt [−0.54, +0.04]、期待展開利 +0.09pt、レース内相対 +0.15pt（区間はいずれも 0 付近）。2024 年だけでは前走 −1.07pt [−2.25, +0.12]、直近 3 走平均 −0.93pt [−2.03, +0.24]（同方向で区間が広がる）。

解釈: V5 は『展開に助けられた好走』をある程度は織り込んでいるが（前走の着順だけでなく位置取りや上がりの列があるため）、完全ではなく、直近の展開利が大きい馬の複勝確率を約 1pt（平均 21% に対し約 5% の相対）過大に付けている。『今走が苦しくなる』側は、期待展開利そのものの精度（セル確率の LogLoss 1.94 と脚質の事前の粗さ）が低く、独立に検出できる大きさではない。

5. V5 への増分

LightGBM に列として足す本評価（構成 d の 1,142 列 + pb_*、valid 2022〜2024 年・seed 0,1）は未実施。ホストの共有スロット（同時 3 本）が約 1 時間半、他の評価で埋まったままで順番が回らず（待ち行列に約 10 本）、先行指標が採用基準（0.0002）に遠く届かないため、待ち行列から取り下げた。実行する場合は python -m src.scripts.data.tp64_eval run PB_ALL（約 40 分、heavy_run 経由、基準は v6/eval/oof_d_CY_BEST）。以下は再学習なしの 2 つの先行指標。

6. 結論と限界

  • 『展開に恵まれた好走は割り引く』方向は実測で支持されるが（V5 の複勝確率が 1pt ほど過大）、『今走が苦しい展開だと下がる』という交互作用は、4 グループに割った標本では区間が 0 を跨ぎ、検出できない。
  • 先読み: 係数表はその年より前の年のみ、特徴は各走より前の走のみ（書き換え・切り詰めテストで確認）。今走の脚質は過去走の位置から、展開確率はレース前の量から作る（結果を使わない）。2026 年は選択に使っていない。
  • 限界: (1) 展開利は『セル×脚質』の平均着順の差で、馬自身の能力・ペースの質の違い（同じスローでも前半の速さ）は見ていない。(2) 今走のセル確率は 9 クラスで LogLoss 1.94 と粗い。(3) 2020 年の行は係数がなく欠損、2021 年は 1 年分の係数で粗い。(4) 追走の楽さ（tp-54 の実測 Y）は、本章では未使用（展開利が通過ラップの楽さの粗い代理）。
  • 共有: レース質のラベルは tp-61 の出力（tp61/race_cls.parquet）を使い、今走のセル確率だけを data/local/modeling/shared_cache/race_quality/tp64_pcell.parquet（race_id キー、README 付き）に置いた。血統グループ×レース質（tp-60）と同じ定義の上で組み合わせられる。
