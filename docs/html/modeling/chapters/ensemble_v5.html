アンサンブル v5 の構成選択と最終学習

要点（構成の選択）. 6 構成を valid 2022〜24 の LightGBM（V4 の 1,062 列に累積）で比べた。(1) tl_ を再取得版にするだけで勝率 −0.00045（上限 −0.00027、3 年とも負）。(2) CY（tp-40）を足すと −0.00018（上限 −0.00001）で効果量の基準 0.0002 に僅かに届かないが、初出走 −0.00121（上限 −0.00044）・新馬戦 −0.00174 と履歴の浅い馬に集中する。(3) ALL_BEST（tp-38）を CY に足すと −0.00018（上限 +0.00001）、RL_C（tp-42）を足すと −0.00018（上限 −0.00001）で、どちらも単独では基準に届かないが、b に対する累積では d（CY+BEST）−0.00036（上限 −0.00016）、e（CY+RL_C）−0.00036、f（全部）−0.00050（上限 −0.00026）といずれも基準を満たす。(4) f を d に重ねる増分（RL_C、−0.00014、上限 +0.00003）と e に重ねる増分（BEST、−0.00014、上限 +0.00005）は有意でない。採用: d = V4 + tl_ 再取得版 + CY + ALL_BEST。理由: V4 に対し −0.00082（上限 −0.00056）・連対 −0.00095・複勝 −0.00180、3 年とも上限が負、初出走 −0.00292（上限 −0.00173）。f との差は有意でなく、RL_C は発展中のめぐ指数に依存するため複雑さに見合わない（保留のまま）。
