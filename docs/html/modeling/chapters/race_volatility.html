荒れやすいレースの分析（tp-30）

レースの「荒れ」を結果から定義し、(1) どんな条件で荒れるか、(2) 事前に予測できるか、(3) 予想の特徴量に寄与するか、(4) 馬券の買い目の幅の決め方に寄与するかを分析した。対象は JRA の 2020〜2024 年（17,272 レース）。馬券の評価は valid 2022〜2024 の v3 OOF（10,061 レース）。test 2025・2026 年は使っていない。

市場情報の扱い. 予想モデル（勝率予測）の特徴量にはオッズ・人気を入れない（「モデル用」）。馬券の幅の決定にだけ、購入前のオッズ構造を使う（「馬券用」。履歴は確定オッズで代用しており、購入時点の T-60/T-15 ではない）。荒れの正解（事後指標）は結果から作る。

結論

  • 荒れやすさは事前にある程度予測できる。モデル用（オッズなし）でも荒れ度の R² 0.13、荒れ上位 20% の AUC 0.67、予測上位 20% の中の実際の荒れ割合は基準の 1.7 倍。馬券用（確定オッズの構造を足す）は R² 0.20、AUC 0.71、2.0 倍。
  • 荒れやすい条件: 出走頭数が多い（15 頭以上）、未勝利・条件戦より上位クラス（オープン・3 勝クラスで荒れやすい）、短距離、小倉・新潟・福島（ローカル場）、開催後半の番組（10〜12R）。逆に 11 頭以下、未勝利戦、東京の芝中距離、2000m 以上は堅い。
  • 確率の温度調整（荒れやすいレースほど平らに）は効かない。v3 の確率はすでに、荒れ度に応じた散らばりをほぼ織り込んでいる。
  • 予想の特徴量（文脈列）への寄与は下の表のとおり。
  • 馬券の幅: 荒れ度の帯で 3連複の点数やフォーメーションの広さを変えても、同じ平均点数の固定戦略に対して回収率・最大ドローダウンの改善は確認できなかった（reality check で有意でない）。一方、買い目を『3連複の予測確率の上位 n 点』で選ぶと、同じ点数の箱・フォーメーションより回収率が高い（これは荒れ度とは別の効果）。

6. 注意・限界

  • 2024 年の一部の払戻データは、複勝・ワイドのセルが連結されて分解できない（例: numbers=3168、payout=330120540）。単勝・馬連・3連複・3連単は問題なし。複勝・ワイドは該当レースを除いて集計した。パーサー側の確認が必要。
  • 馬券用の荒れ度は確定オッズで代用している。購入前（T-60/T-15）のオッズの蓄積後に再評価する。
  • 試した戦略数は 16（荒れ度で幅を変える）＋固定 20 弱。多重検定は reality check で見ている。
  • 3連複の予測確率は上位 n 点の累積確率が実際の的中率よりやや低い（過小評価）が、較正は概ね取れている。
