めぐ指数 v3a（レーティング指数の改善と本番反映）

めぐ指数（ユーザー独自の、馬の能力を表すレーティング指数）を作り直し、2026-10-19 に本番へ反映した記録。旧版で見つかった問題、改善の工程と合格基準、反映の範囲、使い方、限界をまとめる。運用の手順は めぐ指数 v3a の本番反映 手順書。調査全体の中での位置づけは 調査の全体像、特徴量調査の総覧、v3 の特徴量は 採用している特徴量（v3）。

1. 目的と定義

  • 役割: 指数 1 の差が、走破タイム 0.1 秒の差を表すレーティング。成長曲線の縦軸、「想定めぐ指数」、特徴量に使う。
  • 式: 指数 ＝ 50 ＋（基準タイム − 換算後タイム）× 10。換算後タイムは、走破タイムからペース・馬場・斤量の補正を引いたもの。全馬を斤量 55kg に換算する（性別・年齢によらず、もし 55kg を背負っていたらの値）。
  • 基準タイム（par time）: コース・距離・馬場状態の区分・クラスごとの、2 着馬の補正後タイムの平均。
  • コード: src/pipeline/megu_index/（compute.py、v3a.py、v3a_build.py、recompute.py）。モデル一式（基準タイム表・月別オフセット・中心の定数・係数）は config/megu_v3a/ が正本。

3. 改善の工程

工程 1: 改善余地の調査（読み取りのみ）

次走予測（過去走の指数の指数加重平均で次走の勝ち馬を当てる対数尤度の改善量。2025 年、2022〜24 年で当てはめ）で、現行 0.0964 が、斤量・馬場・ペースの 3 補正を直すと 0.206、世代と年水準のオフセットを足すと 0.230 になる見込みだった。距離スケールは「1 点＝0.1 秒の固定」が最良（距離別の標準化・比率換算は悪化）。

工程 2: 実装と、別ディレクトリへの再計算（v3a）

項目v3a の方式
斤量全馬 55kg 基準、係数 0.05 秒／kg（2000m 換算）。候補 0 / 0.05 / 0.1 / 0.2 を 2022〜24 年で選んだ（0 と 0.05 は誤差の範囲。固定効果の 0.025 に近い 0.05）
馬場差同日・同場・同面の他レースの補正前残差の中央値（leave-one-race-out、LORO）。足りない日だけクッション値・含水率にフォールバック（他レースで作れた走が 99.9〜100%）
ペース芝のみ、上限 3 秒（候補 0 / 1.5 / 3 / 5 / 8 のうち 3 が最良）
基準タイム世代×クラス×コース（薄いセルは親へ縮約）。季節は月別オフセットで補う
二本立て相対（megu_index_v3a。同世代・同クラスの 2 着馬が 50）と絶対（megu_index_v3a_abs_robust。1 勝クラス・3 歳以上を基準にした単一基準のスピード指数型）。予測用の下側圧縮列 _feat も付く
丸め[-30, 130]（[0,100] だと下側の大敗が 1.9% 張り付いたため）
障害行を残し、状態を steeplechase、指数は空欄

途中で、基準タイムの馬場フォールバック（L5）が、当日だけの計算で別の行に値を書き込む不具合（年一括で 344 行／312,817 行＝0.1%）を見つけて直した（par_time_resolve.py）。

4. 使い方

  • 成長曲線: 既定の軸は絶対指数（斤量 55kg 換算）。KEIBA_GROWTH_AXIS で軸を差し替えられる。信頼度の低い点（megu_v3a_low_confidence）には印が付く。
  • 特徴量にするとき: 予測に効かせる特徴は相対指数または _feat。絶対指数は、同クラス内の次走予測で相対より劣る（0.2245 対 0.2468）ので、成長の形（軌跡・ピーク年齢）に使う。megu_v3a_low_confidence（約 11%）と steeplechase は除外か重み下げ。
  • 今週のAI予測の「想定めぐ指数」: 過去 5 走の絶対指数の指数加重平均（0.65 倍ずつ、低信頼の走は重み半分）。条件の変化（面・距離・クラス・休み明け・競馬場・馬齢）は、2020〜2024 年で学習した補正を足し、変化が大きいほどレンジを広げる。2025 年で検証して、平均絶対誤差は 9.88（補正なし）から 9.35 点、相関は 0.670 から 0.700。1 走の指数のばらつき（約 ±10 点＝約 1 秒）が大きいので、「想定」であって予測ではない。
  • v4 との関係: v4 の 1,135 列に、めぐ指数由来の列は含まれない。履歴特徴量に同じ情報が入っているため、v4 への上積みはどの改善案でもほぼ 0 だった（最大 +0.0001、区間は 0 を含む）。めぐ指数の強化は、予測精度の向上というより、成長曲線と解釈のための改善。

5. 限界・未確認・今後

  • 斤量の真の係数は、騎手との交絡が残るため特定できていない（0.05 は「予測で横ばいの範囲」と固定効果の推定 0.025 の間の値）。
  • ペース補正の上限（3 秒）の最適値、世代オフセットの前向き評価（期間外での検証）は未確認。
  • 馬場差の LORO は、その日の全レースが確定してから計算できる。確定結果は数日遅れる（金曜の weekly-update ごろ）ため、直近の週末分の指数は反映が遅れる。レース前日に使うデータには、直近の走が未反映の馬がいる。
  • 日次の計算（工程 4-4）は、金曜の weekly-update 後に動作を確認する（未確認）。
  • 基準タイム表は 2020〜2025 年の固定。将来年の水準の扱い（年×面のオフセットは後ろ向きの自己推定のため、将来年では使えない）の運用ルールは、実データがたまってから見直す。
  • 低信頼フラグは約 11%（基準タイムのサンプル 15 未満、馬場差が TSI フォールバックなど）。
  • 別の作業での利用: tp-39（成長曲線の特徴量化）などが、この指数を入力に使う。仕様を変えるときは通知する。
  • レースレベルの特徴量化（めぐ指数からレースの強さを定義して特徴量にする案）の検証は進行中。結果は決定ログ・特徴量調査の総覧に追記する。
