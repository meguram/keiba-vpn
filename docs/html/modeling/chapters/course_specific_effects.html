コース特注の要因（tp-31）

各コース（場×面×距離×内外）で、全体と効き方が違う特徴量を探し、効果のあるものは導入する。V4 アンサンブル（v4_e2）の予測残差を、コース×属性で系統的に説明できるかを調べ（監査）、そのうえでコース特注の特徴量を作って V4 の LightGBM に足した増分を測った。

要点. 第 2 段で採用基準を満たした群はありませんでした。V4 には何も足しません。 V4 の予測残差はコース×属性でほぼ説明がつかない（6,755 セル中、BH 有意 35、再現あり 33。前の年で推定したセル効果で補正しても次の年の LogLoss は ±0.0001 以内）。 コース特注の差は、V4 がすでに持つ情報（b_aff_*、場×面×距離別の枠・脚質の表 course_draw_post、種牡馬×条件、厳密コースの騎手・調教師の成績）でほぼ吸収されている。

1. 異質性の監査（V4 の予測残差がコース×属性でずれているか）

対象: V4 アンサンブル（v4_e2）の valid 2022〜2024 の予測 140865 行。厳密コース 131。残差 r = 実際の1着 − 予測勝率。予測はレース内で合計 1 に正規化されているので、レース内の残差の合計は 0。そのため z はレースを単位にしたクラスター頑健な値（Σs/√Σs²、s = レース内のセルの残差の合計）を使い、多重検定は BH-FDR 5%。『再現あり』は、2022+2023 の符号が 2024 でも同じ向きで |z|>1。

2. 候補の特注特徴量の増分

3. コース別の温度（p^b をレース内で再正規化）

コースごとに確率の尖り具合 b を前の年で選んで次の年に当てると、LogLoss は 平均 +0.00060（2023）、+0.00027（2024）（正 = 悪化）。対象 8 コース（走が 3,000 行以上のコース）。コース別の温度調整は使えない。

4. 結論

  • V4 は、コース特注の効きをすでに吸収している。コース×属性の残差は、検定でも、前の年からの補正でも、特徴量としての追加でも、基準を満たさなかった。
  • 残るコース特注の差は、特定の騎手・調教師・父が特定のコースで V4 の期待より悪い／良いというセルで、件数が小さい（80〜140）。個人の癖としては面白いが、将来の予測には再現しない。
  • tp-15（概形類似）、tp-26（成績連動コースの転移）、tp-29（期待外れ・期待以上の差分）と合わせ、コース特注の特徴量は V4 に追加しない。
