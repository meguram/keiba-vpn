1. 結論

  • test 2025（2020〜2024 年で学習、3,455 レース・47,497 頭を一度だけ評価）の最終精度: 勝率 LogLoss 0.2135（AUC 0.814）、連対率 LogLoss 0.3332（AUC 0.806）、複勝率 LogLoss 0.4189（AUC 0.800）。一様予測は勝率 0.2588・連対率 0.4104・複勝率 0.5168。
  • 予測 1 位の馬が勝つ割合 30.0%（ランダムなら 7.3%）、連対する割合 49.9%、複勝圏に入る割合 62.3%。勝ち馬が予測上位 3 頭に入る割合は 62.8%。
  • 確率は「レース内で合計 1・2・3 にそろえる」処理を最終段で必ず適用する（これだけで勝率 LogLoss が約 0.0026 改善）。
  • 市場オッズとの比較は未実施（絶対的な強さは、市場の暗黙の確率との差で判断する）。
