拡張ラベルのめぐ AI

最終更新: 2026-11-28。担当 model-relabel。研究だけで、本番のモデル・前向きの記録の版（prereg_2026_r2・rc6）は替えていない。2025・26 年は開いていない。 仕様は config/model_relabel/spec.json（成績を見る前に版を重ねて固定。最後は mr-10）、記録は docs/operations/model_relabel/。

結論
  • 勝ち馬から 1/2 馬身以内の馬も 1 にする勝ちの拡張ラベルは、本物の 1 着の当たりを良くしなかった。市場と組んだときの上乗せ（Benter の 2 段）は、むしろ減った（v5bag の 2022〜24 で +0.0018 悪化）。
  • 複勝の拡張ラベル（3 着馬から 1/2 馬身・1 馬身以内）も、本物の 3 着内の当たりを良くしなかった。1 馬身の版ははっきり悪くなる。
  • 大敗の馬への罰（重み w・3 値の順序）を足しても、上の 2 つは変わらなかった。
  • 本命決着のレース（1〜3 着がすべて 3 番人気以内、8.9%）を学習から除くと、複勝の Benter の上乗せが約 11% 増えた（2022〜24 で −0.00058 nats/頭、Bonferroni の区間でも 0 より下）。単体の当たりはほぼ変わらない。
  • 市場の logit と |ρ| ≥ 0.5 の 108 列を外しても、市場に足す上乗せは劣らなかった。単体の当たりは下がるので、本番のモデルを替える根拠ではない。
  • 本番への反映はしない。反映を考えるなら、統括役とユーザーの承認と stg を通す。

罰と選びの指標

  • P-w: 大敗の負例の重みを w ∈ {1, 2, 4}。P-ord: s = logit(P(拡張の正)) + κ·log P(大敗でない)、κ ∈ {0.5, 1}。
  • 選びの指標 Lλ = 本物のラベルの対数損失 + λ·大敗の −log(1 − p̂)。λ = 0.5 が主、1.5・0 が感度。木の設定は v5bag・v6e のまま固定し、選ぶのは w・κ・本数・較正だけ。元のラベルの基準も同じ手順で作り直した。

分けと評価

  • 時間の順: 年 t は t より前の年で学ぶ。外側 2019〜21 で選び、2022〜24 は採否の 3 つの比べ（spec の confirm_plan）だけを 1 回読んだ。
  • 評価の行は、平地で全頭の市場の q がそろったレース。物差しは本物の 1 着・3 着内の当てはまりと Benter の 2 段（確定の q と組み、t−1 年で当てて t 年で数える）。回収率は数えない。
  • 開催単位の分けは未実施。ラベルの拡張が効かず、報告だけの分けを足しても結論が変わらないため（統括役の判断）。

C3 の読み（なぜ効くか・大きさ）

  • 大きさ: 2022〜24 の複勝で、市場だけの損失から 2 段で下がる幅は、基準 0.00514 に対して本命決着を除いた版が 0.00572（+11%）。2 段の中の AI の重み a は 0.47 → 0.49、市場の重み b は 0.57 → 0.56。単体の上位 3 頭の 3 着内率は 0.5211 → 0.5214 で、ほぼ同じ。
  • 読み（仮説）: 人気どおりに決まるレースは、市場がそのまま正しい例である。学習に入れると、AI は市場と同じ「人気の馬が来る」形を多く学び、市場に足す情報が薄まる。除くと、市場と重ならない情報（人気薄の 3 着内）を学ぶ比重が上がる。直接の検定はしていない。
  • 勝ちでは同じ効きは出ない（2019〜21 で base_nc は単体 +0.0045 悪化、Benter も +0.0009 [+0.0004, +0.0015] 悪化）。複勝だけの効きとして読む。

4. 結果: 特徴量の版

  • 血統のダートの 4 列（v5bag_ped − v5bag）: 勝ち・複勝とも単体・Benter の区間が 0 をまたぐ。効きは見えない。4 列の作りは 2016〜24 の成績を見て凍結したものなので、選んだ期間の中の比べ。
  • 市場を確実に外す版（v5bag_mf − v5bag、追い切り評価の 3 列と course_type を外す）: 2019〜21 の勝ちで単体 +0.0074 [+0.0038, +0.0109] 悪化し、「劣らない」を通らない。2022〜24 は +0.0017 で 0 をまたぐ。内訳（追い切り評価か course_type か）は分けていない。追い切り評価は新馬の欠けが学習 30%・本番 0% のずれがあり、効きの一部はずれを含む。
  • 漏れの列 s_* を外す版（v5bag_mfs − v5bag_mf）: 勝ちで単体 +0.015（2022〜24 は +0.036）、Benter +0.002〜+0.006 悪化。s_* は後の年の着順が入る上流の学習なので、この効きの一部は楽観。
  • 市場の logit と相関の高い列を外す版（mfc − mfs）: |ρ| ≥ 0.5（108 列）は Benter が劣らない（C1）。|ρ| ≥ 0.3（259 列）は 2019〜21 で複勝の Benter が +0.0004 悪化し、勝ちの単体は +0.048 悪化する。

5. 注意

  • 中止・失格の馬: 学習の表 X は完走馬だけ（layer_a_dataset.py:167）。本物の行は作れない。群の表（train_table・前段 S3・TL・aux・CY・BEST・factory ほか）がほとんど完走馬の行だけで作られ、レース内の相対の列（約 280 列）は中止の馬を入れると完走馬の値も変わるため。そこで感度で扱った。戻さない・ラベル 0 で戻し予測はレースの最小・中央の 3 通りで、単体の比べはすべて向きがそろった。Benter の比べには中止の馬の感度が無い（中止の馬に市場の q が無い作りのため）。作り直しは 12/1 以降の train-serve-skew の仕事。
  • 漏れの列: v5bag の列にも s_* と、2021-12 までの全体の当てはめの族（sr_・f3_・f2_・e_・pc_）がある。ラベルどうしの比べは同じ列で行うので効かないが、値の水準は楽観に寄る。
  • v6e の代理: 束の 7 本のうち xgb_extras_ped の 1 本（乱数 1 本）。市場の判定を確かめていない 148 列（tl_・wc_・mtl_・rb_ など）が残る。主の判定は v5bag。
  • 前向きの登録 prereg_dirt_mat5 の比べの相手は、凍結の v5bag のまま。
  • データの点検は docs/operations/model_relabel/dataset_check.md（重複 0・取り込みの誤りの写し 2 レース・障害・初出走ほか）。独立の点検役の指摘への直しは spec の mr-7〜mr-9。
