## 現状の実装（2026-09-30時点）

- `/betting`: 馭券戦略ページ
- `POST /api/betting/optimize`: レース予測 + オッズから馬券ポートフォリオ最適化（単勝/複勝/馬連/ワイド/馬単）
- `/api/betting/pair-odds/{race_id}`: 2連系オッズ取得（GCSに無い場合はスクレイピングを実行）

## 目標（推測）

ユーザが「どの馬券をどう組み合わせれば期待値が最大化されるか」を自分で考えなくても、
予測+オッズから自動で提示してもらえること。最終的にユーザの馬券購入判断を後押しする
ことが目標と推測される。

## このラインまで実装できたらブランチを消してよい

- 主要な馬券種（単勝/複勝/馬連/ワイド/馬単）すべてで、ユーザが提示された最適化結果を見て
  実際に購入判断に使えるレベルの精度・説明性がある
- オッズ取得に失敗してポートフォリオが提示できない、という事象が稀にしか起きない
- 上記が実現できていれば、ユーザ向けの実装は完了したとみなせる
